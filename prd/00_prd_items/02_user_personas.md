# 사용자 유형과 기대 경험

<!-- release-document: reference -->

<a id="문서-설명"></a>

## 사용자 유형을 읽는 기준

한 사람은 대상에 따라 참가자·호스트·클럽 회원·판매자·구매자일 수 있다. 아래는 기획 관점의 분류이며 서버 역할 값 목록이나 전 기능의 허용표가 아니다. 먼저 행동하는 사람과 결과를 받는 사람을 나누고 대상과의 현재 관계를 확인한다.

**비로그인 방문자**와 회원에게 연결된 **동반 게스트**를 구분한다. 동반 게스트는 독립 회원 계정이 아니며 책임 회원의 예매·출석·변경 흐름에 연결된다. ‘게스트’라는 단어 하나로 공개 탐색과 동반 참여를 합치지 않는다.

<a id="1-사용자-유형"></a>

## 역할별 목적과 검토 조건

| 사용자 관점 | 하려는 일 | 현재 확인할 조건 |
|---|---|---|
| 비로그인 방문자 | 공개 활동을 탐색하고 가입 여부 판단 | 공개 조회와 로그인 필요 시점, 가입 후 원래 목적지 복귀 |
| 신청자·납부 대기자·참석자 | 신청·납부·참여·취소 | 승인·정원·대기열·실제 참석·환불의 서로 다른 상태 |
| 동반 게스트의 책임 회원 | 동반 예매·체크인·변경·소명 | 게스트 수와 책임, 허용된 변경·금전 경로 |
| 호스트·공동호스트 | 모집·회차·참가자·출석·반환 운영 | 현재 주최권과 유효한 위임, 명령별 권한 |
| 클럽 회원 | 게시글·사진·모임·활동 제도 이용 | 현재 회원 자격·차단·공개 조건과 활동 제도 상태 |
| 클럽 운영진·소유자 | 가입·운영·역할·기금 관리 | 위임과 소유자 전용 행동, 역할 제한·소유권 이전 |
| 정기모임 등록자·회차 운영자 | 코스 등록·회차 참석·출석·종료 | 고정/가변 유형, 등록과 실제 회차, 변경된 호스트 책임 |
| 작성자·판매자·구매자 | 플랜 제작·상품 판매·구매 활용 | 콘텐츠 공개·심사·판매·현재 구매 권리와 소유자별 환불 책임 |
| 데이팅 당사자 | 후보·매칭·대화·만남 | 본인확인·프로필 활성·공개 범위·현재 관계·차단 |
| 제공자·부담자·수취자 | 계약·분담·이행·정산·회수 | 계약 당사자와 실제 돈의 원천, 정산 확정·지급의 차이 |
| 신고·문의·분쟁 당사자 | 문제 접수·자료 제출·결과와 이의 확인 | 원천별 관할·기한·열람·처리 상태 |
| 플랫폼 관리자 | 허용된 심사·제재·금전·개인정보 작업 | 관리자 인증·작업별 권한·재인증·운영 관문. 클럽 운영진과 별개 |

기능 연결은 [175개 기능 목록](05_feature_definitions.md), 실제 허용 조건은 [역할별 행동 표](07_role_action_matrix.md)와 [권한 정책](../03_policy_prds/permission_policy_prd.md)을 따른다.

## 이용 상황별 기대 경험

| 상황 | 설계할 경험과 확인할 결과 |
|---|---|
| 처음 온 사람 | 공개 정보와 가입 필요 시점을 이해하고 가입·로그인 뒤 목적을 이어감 |
| 반복 참가자 | 원래 찾던 활동에 신청한 결과와 남은 납부·확인·참석 조건을 알 수 있음 |
| 숙련 호스트 | 모집·신청·참석·입금·출석·정산의 현재 차이와 처리할 대상을 구분 |
| 클럽 운영 담당 | 현재 위임 범위와 소유자 전용 행동을 알고 권한 변경 후 결과를 재조회 |
| 판매자·제공자·수취자 | 승인·이행·매출·정산·지급·반환을 각각 추적 |
| 민감 기능 이용자 | 현재 공개·동의·차단·중지 범위와 보존되는 기록을 이해 |
| 오류나 응답 유실을 겪은 사람 | 확정 실패·결과 불명·부분 처리를 구분하고 중복 행동 없이 복구 |

이 표는 설계 목표다. 관측 없이 경험이 달성됐다고 기록하거나 심사된 상품·인증된 상대의 품질·안전을 보증하지 않는다.

<a id="3-사용자-관계-도식"></a>

## 역할이 겹칠 때의 판단

현재 계정 → 대상과의 관계 → 유효한 위임 → 대상 상태·공개 범위 → 해당 명령의 조건 순서로 확인한다. 운영자 역할이 모든 참가·조회 권한을 항상 덮는 보편 우선순위를 두지 않는다.

- 클럽의 역할 변경·세부 권한 위임은 현재 소유자 전용이다. 소유권 이전은 별도 절차이며 일반 위임과 수락 조건을 섞지 않는다.
- 공동호스트와 클럽 운영진의 권한은 현재 효력을 검사한다. 운영 권한 제한이 일반 회원 자격 상실이나 모든 행동 금지와 같은 뜻은 아니다.
- 차단·공개 범위는 탐색·직접 조회·운영 대상 선택 등 기능별로 적용한다. 모든 역할과 모든 경로에 같은 규칙이라고 단정하지 않는다.
- 계정 삭제 예약은 즉시 비활성화가 아니다. 예약만으로 모든 활성 행동이 차단된다고 안내하지 않으며, 현재 계정 제한과 명령 조건을 따른다. 예약 취소·실행 전 의무·후속 파기는 [개인정보·안전 정책](../03_policy_prds/privacy_safety_policy_prd.md)을 따른다.
- 버튼 노출·화면 진입·과거의 역할은 다음 명령의 허용 근거를 대신하지 않는다. 권한 변경·거절·결과 불명에서 재조회·복귀를 안내한다.
