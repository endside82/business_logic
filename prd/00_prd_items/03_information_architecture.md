## 현재 앱에서 기능을 찾는 방법

2026-11-22 앱 라우터·공통 상단·전체 메뉴 소스를 확인한 입구 설명이다. 실제 배포본·기기 확인을 대신하지 않는다.

| 입구 | 현재 코드에서 확인한 구조 |
|---|---|
| 하단 탭 | 홈 → 이벤트 → 모임 → 채팅 → 마이의 다섯 갈래 |
| 공통 상단 행동 | 검색 → 알림 → 전체 메뉴. 검색·알림은 하단 탭이 아님 |
| 전체 메뉴의 묶음 | 이벤트, 모임, 내 활동, 돈, 주최·운영, 도구, 고객센터, 설정 |
| 전체 메뉴의 노출 | 회원·주최자·현재 공개 범위·기록 조건에 맞는 항목. 검색은 보이는 항목의 이름에서 수행 |
| 메뉴 이동과 복귀 | 탭 첫 화면은 해당 탭으로 이동. 업무 화면은 메뉴 위에 열어 뒤로 돌아올 경로를 유지 |

전체 메뉴에 보인다는 사실과 대상 상세·명령 권한은 다르다. 같은 행동의 실제 입구와 현재 상태별 메뉴는 각 기능 정본에서 대조한다. [현재 출시 범위](../05_planning_artifacts/mvp_scope_matrix.md)와 [권한 정책](../03_policy_prds/permission_policy_prd.md)을 함께 본다.

## 기능을 배치하거나 바꿀 때

사용자 목적과 원천 기록의 책임을 먼저 찾는다. 공개 조회가 있는 기능에 인증·프로필 완성을 일괄 선행 조건으로 붙이지 않는다. 다른 영역의 돈·권리·정원·일정·알림·열람에 영향을 주면 해당 정책과 현재 명령 경계를 함께 검토한다.

번호를 바꾸거나 도메인을 늘리기 전에 기존 [영역별 목적](04_domain_purposes.md)과 [기능 정본](05_feature_definitions.md)을 확인한다. 분류도 화살표로 서버 호출·쓰기 권한·실제 후속 작업을 추정하지 않는다.
