# 서비스 개요

<!-- release-document: reference -->
> **문서 구분: 제품 이해를 위한 요약.** 2026-11-22 현재 정본과 대조했다. 소스 대조·제품 실행·실제 공개는 구분한다. 현재 실행 순서는 [앞으로 할 일](../../../docs/plan/NEXT_WORK.md)을 따른다.

<a id="1-한-줄-정의"></a>

## 제품 정의

사이숲은 관심사에 맞는 오프라인 모임을 발견하고 참여하며, 클럽 관계와 후속 운영·정산·안전 절차를 이어 가는 커뮤니티 서비스다. 전체 제품에는 플랜 마켓·데이팅·제공자 거래도 포함하지만 문서와 코드의 존재가 현재 공개를 의미하지는 않는다.

<a id="2-제품이-해결하는-문제"></a>

## 사용자의 문제와 제품의 역할

| 사용자의 문제 | 관련 제품 책임 | 구분할 경계 |
|---|---|---|
| 원하는 활동을 찾기 어려움 | 홈·검색·이벤트·클럽·관심인으로 탐색과 재방문을 연결 | 대상별 공개·접근 권한이 다르며 한 검색이 모든 영역을 같은 조건으로 찾는 것은 아님 |
| 참여와 운영 절차가 분산됨 | 신청·승인·정원·대기열·교통편·출석·일정 변경을 연결 | 신청 승인·납부·실제 참석·체크인과 모집 마감·활동 종료는 각각 판단 |
| 돈의 책임과 결과가 불명확함 | 직접 송금·지갑·환불·모임 정산·수익·기금의 원천과 상태를 구분 | 신청·승인·지급·실제 입금·반환을 한 가지 완료로 합치지 않음 |
| 활동 후 관계를 이어가기 어려움 | 클럽 활동·마일리지·스탬프·일정·관심인·후기로 후속 이용을 지원 | 활동 점수·무료 포인트·신뢰점수는 다르며 모든 피드백이 모든 추천으로 이어지는 것은 아님 |
| 문제 상황의 통제권이 부족함 | 동의·공개 설정·차단·신고·문의·분쟁·자료 관리 경로를 제공 | 본인확인·심사·점수는 안전 보증이 아님. 접수·제재·보상·파기를 구분 |

## 현재 공개 범위와 확인 상태

첫 출시의 무료 모임·클럽·정기모임, 주최자 계좌 직접 송금, 교통편·투표·마일리지·스탬프·프로필·공유 등과 플랫폼 결제·마켓·데이트·제공자 거래 같은 후속 공개 범위를 구분한다. 세부 포함·예외는 [현재 범위 검토표](../05_planning_artifacts/mvp_scope_matrix.md)에서 정본으로 연결한다.

공개 범위, 소스 구현, 기존 실행 기록, 같은 배포본에서 남은 실제 확인은 서로 다르다. 문서가 최신이거나 시험 파일이 있다는 이유로 공개 준비를 완료 처리하지 않는다. [문서 전환·대조 상태](../PRD_MIGRATION_STATUS.md)를 함께 확인한다.

<a id="3-전체-제품-흐름"></a>

## 대표 사용자 흐름

탐색·공유 링크 → 현재 접근 조건 → 대상과 행동 선택 → 필요한 신청·승인·납부 → 실제 상태 확인 → 활동·운영 → 해당 후기·정산·문의로 이어진다. 돈·후기·매칭을 모든 사용자가 반드시 거치는 순서로 그리지 않는다.

취소·권한 상실·연결 실패·응답 유실에서는 남은 의무와 현재 상태를 확인하고 원래 화면으로 복귀한다. [대표 사용자 여정](../../planner_onboarding/02_core_journeys.md)과 [상태 정책](../03_policy_prds/state_policy_prd.md)에 구체적인 경계를 둔다.

<a id="4-제품-범위"></a>

## 제품과 문서의 범위

| 집계 대상 | 현재 문서 기준 | 해석 |
|---|---:|---|
| 업무 영역 | 21개 | 제품 책임의 분류 |
| 기능 PRD | 175개 | 기능별 정본 인벤토리. 전체 공개·실행 성공 수가 아님 |
| 등록 확인 항목 | 1,654개 | 기능 목록의 등록값 합 |
| 별도 상세 시나리오 문서 | 117개 | 그 문서에서 식별한 제목 1,276개 |
| 별도 상세 원천 문서가 없는 기능 | 58개 | 해당 기능 PRD와 소스·제품 결정에서 수용 조건을 확인 |

원천은 [전체 기능 목록](05_feature_definitions.md)과 [시나리오 커버리지](../04_qa_acceptance/scenario_coverage_matrix.md)다. 등록 항목·상세 제목·도식의 집계는 서로 다르고 시험 통과율의 분모로 자동 전환하지 않는다. 도식 수와 원천은 [기능별 시나리오·도식 인덱스](../../planner_onboarding/11_feature_coverage_index.md)를 따른다.

<a id="5-별도-결정이-필요한-영역"></a>

## 결정과 다음 문서

이 개요는 제품 방향과 문서의 입구다. 세부 권한·상태·수용 기준을 이 요약만으로 확정하지 않는다. [사용자 유형](02_user_personas.md), [기능 목록](05_feature_definitions.md), [상태 정책](../03_policy_prds/state_policy_prd.md)·[권한 정책](../03_policy_prds/permission_policy_prd.md)과 해당 기능 PRD를 함께 읽는다.

기존 출시 범위를 미결정으로 되돌리지 않는다. KPI·운영 응답 기한·문구 등 변경 질문은 [결정 등록부](../05_planning_artifacts/decision_register.md)에서 현재 근거와 구분한다. 승인하지 않은 수치·담당·공개 약속을 새로 정하지 않는다.
