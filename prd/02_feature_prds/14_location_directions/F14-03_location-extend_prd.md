# F14-03. 위치 공유 만료와 연장 PRD

<!-- release-document: reference -->
> 2026-11-22 현재 소스를 기준으로 갱신했다. 구현 계약의 대조이며 새 앱 실행·운영 검수 통과 기록이 아니다.

## 현재 역할과 입구

위치 화면은 본인이 동의 중이고 내 좌표 응답에 expiresAt이 있으면 남은 시간을 초 단위로 표시하고 「+ 30분 연장」 버튼을 제공한다. 버튼 중복 실행을 막고 서버 성공 뒤 위치를 재조회한다. 만료 표시만으로 버튼이 사라지는 구조는 아니며 서버가 연장 가능 여부를 최종 검사한다.

## 최초 만료와 평소 갱신

좌표 등록의 기본 모드 FIXED_TWO_HOURS는 등록 시각에서 2시간, UNTIL_EVENT_END_PLUS_30M은 종료 30분 뒤, CUSTOM_HOURS는 1~24시간을 계산한다. 다만 세 방식 모두 최종 만료는 이벤트 종료 시각으로 제한된다. 모드 이름을 근거로 실제 종료 뒤 30분 공유를 허용한다고 적지 않는다.

customHours가 전달되면 모드와 무관하게 1~24 범위를 검사하고 CUSTOM_HOURS에서는 값이 필수다. 현재 앱은 모드·시간 선택을 전송하지 않는다. 기존 공유가 활성이고 명시적 모드 변경이 없으면 평소 GPS 갱신은 만료를 유지한다. 만료된 공유에 좌표를 다시 등록하는 동작과 기존 공유의 연장은 다르다.

## 연장 계약

POST /api/v1/events/{eventId}/location/extend의 쿼리 extendMinutes 기본값은 30이다. 서버는 입력을 1~120분으로 제한해 적용하고 200·본문 없음으로 응답한다. 호스트·활성 공동호스트·ATTENDING 참석자와 공유 설정·현재 공유 시간 조건을 검사한다. 호스트 이외는 본인 동의가 필요하고 모두 본인 공유 행이 있어야 한다.

공유 행이 없으면 LOCATION_SHARE_NOT_FOUND, expiresAt이 현재 시각 이하이면 LOCATION_SHARE_EXPIRED다. 미래 만료를 기준으로 더하고 null인 기존 자료만 현재 시각을 기준으로 삼는다. 최종값은 이벤트 종료 시각을 넘지 않는다. 이미 종료 시각까지 설정된 공유는 요청이 성공해도 실제 시간이 더 늘지 않을 수 있다.

## 종료 예고 알림

예약 작업은 1분 간격으로 커서 구간에 해당하는 30분 뒤 만료 자료를 찾는다. 이미 만료됐거나 동의하지 않은 대상은 건너뛰고 공유 식별자·만료 시각으로 중복 키를 만든다. 실패 항목이 있으면 커서를 유지하고 재시도할 수 있다. 이는 알림 생성·중복 제어의 구현이며 정확히 30분 전에 기기에 도착했다는 증거가 아니다.

## 앱 결과와 시간 경계

현재 앱은 항상 30분을 요청하고 성공 시 「모임 종료 시간 안에서 공유를 연장했습니다」를 표시한다. 실패는 일반 연장 실패 안내다. 공유 시간 밖에서는 앱도 요청을 막으며 종료 경계에 이벤트·위치 상태를 갱신한다. 평소 좌표 전송이나 연장으로 이벤트의 종료 시각 자체를 바꾸지 않는다.

## 현재 제한과 확인 범위

| 분류 | 현재 경계 | 문서 처리 |
|---|---|---|
| Risk | 현재 앱은 만료 모드를 선택하지 않으며 연장 성공이 항상 30분 증가를 뜻하지 않는다. | 이벤트 종료 상한을 명시한다. |
| 미검증 | 실제 만료 경계·푸시 도착·앱 복귀를 새로 실행하지 않았다. | 예약 작업과 실제 수신을 구분한다. |

## 수용 기준과 검증 근거

- **AC-01 기본 만료:** 기본 2시간을 적용하되 모든 모드와 연장은 이벤트 종료를 넘지 않는다.
- **AC-02 GPS 갱신:** 명시적 모드 변경 없는 활성 공유의 좌표 갱신은 기존 만료를 유지한다.
- **AC-03 연장 권한:** 현재 공유 자격·시간·설정·본인 행과 비호스트의 본인 동의를 확인한다.
- **AC-04 만료 거절:** 없는 공유와 이미 만료된 공유를 별도 오류로 거절하며 종료 상한에 도달한 성공을 시간 증가로 단정하지 않는다.
- **AC-05 요청과 표시:** 앱은 30분 요청과 중복 실행 방지·재조회를 연결하고 서버는 1~120분 범위를 적용한다.
- **AC-06 예고 알림:** 동의·미만료·중복 키·실패 커서 처리를 확인하며 실제 푸시 수신과 구분한다.
