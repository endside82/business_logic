# F02-05. 홈의 검색·알림 진입점 PRD

<!-- release-document: reference -->
> **문서 구분: 기능·설계·절차 참고 문서.** 2026-11-22 실제 공통 상단 행동·경로·인증 관문·배지 공급자와 기존 시험 목적을 대조했다. 새 앱 실행이나 외부 푸시 수신 검증 기록이 아니다. 실행 순서는 [앞으로 할 일](../../../../docs/plan/NEXT_WORK.md)을 따른다.

## 결론

홈 오른쪽 위에는 **검색 → 알림 → 전체 메뉴**의 공통 버튼 세 개를 같은 순서로 둔다. 홈만의 검색·알림 아이콘 두 개라는 과거 설명은 현재 구성과 다르다. 이 기능은 홈에서 해당 화면을 여는 입구와 돌아오는 흐름을 책임진다. 검색 결과·알림 읽기·전체 메뉴의 세부 행동은 각 기능의 정본에서 확인한다.

## 실제 입구와 로그인

| 사용자 행동 | 현재 이동과 권한 |
|---|---|
| 홈의 검색 버튼 | 현재 탭 위에 검색 화면을 쌓아 연다. 비로그인도 검색에 들어갈 수 있음 |
| 검색 안의 사람·저장 기능 | 검색 진입이 공개여도 로그인과 각 결과 권한을 별도로 적용 |
| 로그인 회원의 알림 버튼 | 현재 탭 위에 알림 목록을 쌓아 열고 본인 알림을 조회 |
| 비로그인의 알림 버튼 | 인증 관문이 알림 목적지를 돌아갈 주소로 보존하고 로그인으로 보냄 |
| 전체 메뉴 버튼 | 현재 탭 위에 전체 메뉴를 엶. 알림 목록으로 가는 버튼과 다른 목적 |

로그인 뒤에는 유효한 앱 내부 목적지로 이어진다. 계정 잠금·재동의·온보딩·출시 범위 등의 관문이 필요한 상태를 정상 로그인 완료와 같게 취급하지 않는다. 상단 버튼이 자체적으로 인증을 건너뛰거나 다른 계정의 알림을 여는 것은 아니다.

## 알림 수와 전체 메뉴의 점

알림 버튼은 알림 목록과 같은 미읽음 공급자를 사용한다. 로그인했을 때만 읽고 수가 0보다 크면 숫자 배지를 표시한다. 이 값은 서버의 현재 미읽음 수이며 기기에 도착한 푸시 개수와 같다고 설명하지 않는다. 알림 읽기·모두 읽기·푸시 처리 뒤 수의 반영은 [알림 그룹과 배지](../12_notification/F12-02_notification-grouped-badge_prd.md)의 범위다.

현재 미읽음 조회 실패는 공급자에서 0으로 바뀐다. 배지가 안 보인다는 사실만으로 미읽음이 실제로 없다고 판정할 수 없으며, 아이콘 자체는 계속 열 수 있다. 로그인하지 않았으면 미읽음 수와 전체 메뉴의 새 기능 여부를 조회하지 않는다.

전체 메뉴의 점은 새로 열린 기능 안내다. 알림 숫자와 다른 공급자·의미를 가지므로 두 표시를 같은 알림의 중복 배지로 해석하지 않는다. 새 기능 안내를 확인하는 세부 규칙은 전체 메뉴 기능의 검토 범위다.

## 복귀와 데이터 변경

검색·알림·전체 메뉴는 현재 탭을 다른 경로로 교체하지 않고 위에 쌓아 연다. 뒤로 돌아오면 아래 탭으로 복귀한다. 홈에서 검색 결과의 상세까지 다녀오는 흐름과 알림을 읽고 상세를 여는 흐름은 각각의 결과 화면을 거쳐 돌아온다.

‘홈으로 돌아오면 API 호출이 없다’는 과거 단정을 사용하지 않는다. 홈 공급자는 계정과 이벤트·클럽·플랜 카드 변경을 구독하므로, 다른 화면의 명령·계정 변경·관련 데이터 갱신에 따라 다시 읽을 수 있다. 경로를 쌓아 여는 방식과 데이터 갱신 필요 여부는 별개다.

## 현재 제한과 확인 범위

| 판정 | 항목 | 영향·다음 확인 |
|---|---|---|
| Gap | 미읽음 조회 실패와 0건 | 조회 실패가 0으로 바뀌어 상단에서는 실패와 실제 미읽음 없음이 구분되지 않음 |
| Risk | 복귀와 조회 횟수 | 탭 유지가 항상 추가 조회 0회라는 뜻은 아님. 변경된 데이터가 반영되는지를 기준으로 확인 |
| 미검증 | 실제 로그인·앱 왕복 | 기존 상단 버튼·검색/알림 상세 왕복 시험은 있으나 이번에 새로 실행하지 않음. 실제 푸시 수신 근거와도 구분 |

## 수용 기준과 검증 근거

- **AC-01 구성:** 홈에 공통 검색·알림·전체 메뉴 버튼이 같은 순서로 표시된다.
- **AC-02 공개 검색:** 비로그인도 검색 화면에 들어가고 사람·저장 등 후속 기능은 각 권한을 적용한다.
- **AC-03 알림 로그인:** 비로그인 알림 진입은 목적지를 보존해 로그인으로 연결하고 정상 완료 뒤 유효한 목적지로 이어진다.
- **AC-04 회원 배지:** 로그인 회원의 현재 미읽음 수를 사용하고 0이면 숫자 표시를 숨긴다.
- **AC-05 조회 실패:** 미읽음 조회 실패가 현재 0으로 바뀌는 제한을 명시하고 아이콘 이동까지 막지 않는다.
- **AC-06 메뉴 표시:** 새 기능 점과 알림 수를 구분하고 비로그인은 두 회원 전용 값을 조회하지 않는다.
- **AC-07 복귀:** 검색·알림·전체 메뉴와 상세를 거쳐 아래 탭으로 돌아오며 현재 데이터 변경을 반영한다.
- **AC-08 계정 변경:** 다른 계정의 미읽음·홈 상태를 재사용하지 않고 필요한 계정 관문을 적용한다.

기존 `app_top_bar_actions_test.dart`는 회원·비회원의 버튼 순서·배지·새 기능 점과 홈·클럽·마이에서의 사용을 다룬다. `entry_paths_search_notification_help_test.dart`에는 검색 결과·상세에서 검색어와 스크롤로 돌아오기, 알림 읽기·상세에서 읽은 목록으로 돌아오는 시험이 있다. 시험 목적·소스 대조를 이번 실행 통과로 기록하지 않는다.
