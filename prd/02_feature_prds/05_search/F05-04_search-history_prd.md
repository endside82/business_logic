# F05-04. 최근 검색어 PRD

<!-- release-document: reference -->
> **문서 구분: 기능·설계·절차 참고 문서.** 2026-11-22 서버·앱 소스와 기존 시험 목적을 대조했다. 새 제품 시험·실기기·외부 알림 검증 기록이 아니다. 실행 순서는 [앞으로 할 일](../../../../docs/plan/NEXT_WORK.md)을 따른다.

## 결론

최근 검색어는 앱 기기에 계정별로 보관한다. 현재 서버에는 검색 이력 조회·개별 삭제·전체 삭제 창구가 없으며 검색마다 Redis에 기록하지 않는다. 별도 검색 기록 화면도 없고 검색 화면 안의 구역에서 관리한다. 90일 서버 보관 기간이라는 과거 설명을 현재 정책으로 사용하지 않는다.

## 입구와 기록 규칙

검색 전이거나 검색칸에 포커스가 있고 입력이 비었을 때 최근 검색어를 보여준다. 검색 화면에서 검색을 실행하거나 저장된 검색을 실행하면 로그인한 계정의 기기 기록에 넣는다. 공백을 제거한 빈 검색어와 비로그인 상태는 기록하지 않는다.

최대 20개를 최신순으로 보관하고 같은 문자열을 다시 검색하면 맨 앞으로 옮긴다. 중복 비교는 정확한 문자열 비교이므로 대소문자까지 같은 검색어와 다른 표기를 구분한다. 21번째에는 가장 오래된 것을 뺀다. 시간 기준 자동 만료나 다른 기기와의 동기화는 이 저장 경로에 없다.

## 개별 삭제·전체 삭제·재검색

- 검색어를 선택하면 그 문구로 검색하고 최신 위치에 다시 기록한다.
- 항목의 삭제 버튼은 해당 검색어를 바로 지운다. 현재 항목은 일반 목록 행이며 화면 명세의 좌측 스와이프 삭제를 구현된 입구로 설명하지 않는다.
- 전체 삭제는 확인창을 거친다. 취소하면 유지하고 확인하면 해당 계정의 기기 목록을 비운다.
- 개별·전체 삭제 중 화면의 목록을 먼저 변경하고, 저장 시도가 끝나면 현재 계정의 기록을 다시 읽는다.
- 기록 조회의 로딩·오류·빈 목록은 현재 최근 검색어 구역을 숨긴다. 검색 결과 API의 실패와 기기 기록 실패는 서로 독립적이다.

## 계정·로그아웃·탈퇴

기기 저장 열쇠를 계정 번호로 구분하므로 계정 A의 검색어를 B의 목록으로 보여주지 않는다. 로그아웃은 기록 삭제가 아니며 같은 계정으로 다시 로그인하면 기기에 남은 목록을 읽는다. 비로그인은 목록을 보여주거나 기록하지 않는다.

서버 탈퇴 성공을 처리하는 앱의 계정 정리에는 해당 계정의 최근 검색어 삭제가 포함되어 있다. 실패한 기기 정리는 재시도 대상이며, 이를 모든 기기의 즉시 삭제나 서버 검색 기록 삭제로 확대하지 않는다. 상세 조건은 [즉시 탈퇴](../13_profile_settings/F13-07_account-deactivation_prd.md)를 따른다.

## 현재 제한과 확인 범위

| 판정 | 항목 | 영향·다음 확인 |
|---|---|---|
| Gap | 기록·개별 삭제 실패 안내 | 검색 실행의 기록은 기다리지 않으며 개별 삭제도 화면의 별도 오류 처리가 없음. 목록 재조회·검색 성공과 저장 성공은 다름 |
| Gap | 기기 쓰기 결과 확인 | 기록·개별 삭제는 저장 함수의 false 결과를 검사하지 않지만 전체 삭제는 실패를 예외로 처리함 |
| Risk | 연속 변경 경합 | 읽기 뒤 쓰기 경로가 직렬화되어 있지 않아 빠른 기록·삭제가 겹칠 때 최종 목록을 별도로 확인해야 함 |
| 미검증 | 실제 기기 복귀·탈퇴 정리 | 계정 분리 시험은 있으나 새 기기·저장 실패·탈퇴 이후 모든 기기 정리의 실행 증거는 아님 |

## 수용 기준과 검증 근거

- **AC-01 표시:** 검색 전 또는 포커스가 있고 입력이 빈 경우에 최근 검색어 구역을 표시한다.
- **AC-02 계정:** 로그인 계정의 기록만 읽고 비로그인은 기록하지 않는다.
- **AC-03 정규화:** 앞뒤 공백을 제거하고 빈 문구는 보관하지 않는다.
- **AC-04 순서:** 같은 문자열은 앞으로 옮기고 최대 20개를 유지한다.
- **AC-05 재검색:** 항목 선택으로 같은 문구를 검색하고 최근 순서를 갱신한다.
- **AC-06 개별 삭제:** 해당 계정의 해당 문구만 지우며 현재 삭제 버튼과 미구현 스와이프를 구분한다.
- **AC-07 전체 삭제:** 확인·취소·기기 삭제 실패 안내와 최종 재조회를 구분한다.
- **AC-08 로그아웃:** 로그아웃과 계정 전환은 원래 계정의 기록 자체를 지우지 않는다.
- **AC-09 탈퇴:** 서버 성공 뒤 해당 계정 기기 기록 정리와 실패 재시도를 확인한다.
- **AC-10 실패·경합:** 기록 저장 실패가 검색 결과를 취소하지 않음을 확인하고 동시 기록·삭제의 최종 결과를 점검한다.

기존 `search_history_device_test.dart`는 계정별 목록·빈 입력·중복 순서·20개 상한·서버 기록 창구 미호출을 다룬다. `search_screen_recent_keywords_test.dart`는 화면의 최근 검색어 구역을 다룬다. 이번 갱신은 해당 목적과 현재 소스를 대조한 기록이며 새 실행 결과가 아니다.
