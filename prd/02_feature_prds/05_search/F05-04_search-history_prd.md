# F05-04. 최근 검색어 PRD

<!-- release-document: reference -->

2026-10-29 현재 소스 대조. 차수 10에서 서버 검색 기록과 Redis 저장을 제거하고 계정별 기기 저장으로 옮겼다.

## 사용자 흐름과 저장 범위

로그인 계정이 검색을 제출하면 비어 있지 않은 단어를 기기의 최근 검색 목록 맨 앞에 넣는다. 같은 단어는 한 번만 유지하고 최대 20개를 보관한다. 자동완성 조회 자체는 기록하지 않는다. 최근 단어를 고르면 검색을 실행한다. 개별 삭제·전체 삭제는 해당 계정의 기기 기록에 적용한다.

서버 90일 만료나 기기 간 동기화는 없다. 앱 저장 공간이 초기화되면 기록은 사라진다. 계정 번호별 키로 저장해 로그아웃·계정 전환 때 다른 계정 기록이 보이지 않게 한다. 서버에 보관하는 저장된 검색(F05-05)과 구분한다.

## 확인한 구현

- `community_app/lib/core/storage/search_history_storage.dart`: `search_history.account.{accountId}`, 최대 20개·중복 앞 이동·개별/전체 삭제.
- `community_app/lib/domain/providers/search/search_history_provider.dart`: 로그인 계정에 맞춰 저장소를 읽고 변경 뒤 목록을 갱신한다.
- 서버 검색 기록 조회·삭제 API와 Redis 구현은 제거됐다. 삭제한 창구를 복구 대상이나 현행 호출 주소로 적지 않는다.

## 출시 확인

- 검색 제출·중복 단어·빈값·20개 초과·최근 항목 재검색·개별/전체 삭제.
- 같은 기기에서 두 계정 전환·로그아웃·앱 재시작·저장 공간 초기화.
- 다른 기기에 동기화되지 않으며 저장된 검색은 별도 서버 기능으로 유지.
