# F04-17. 클럽 구성 통계

<!-- release-document: reference -->
> **문서 구분: 기능·설계·절차 참고 문서.** 현재 작업 순서는 [앞으로 할 일](../../../../docs/plan/NEXT_WORK.md)을 따른다. 2026-11-22 소스 대조이며 새 제품 시험·실제 앱 이용 결과가 아니다. 이 기능은 별도 units 문서 없이 실제 소스를 기준으로 관리한다.

## 결론

클럽 회원이 ‘모임 정보’에서 회원 구성의 성별·나이대·MBTI I/E 분포를 확인한다. 운영자의 활동·가입 추이 등을 보는 ‘회원 통계’ 관리 화면과 다른 기능이다. 현재 구성 통계는 회원에게 제공하며, 비회원은 공개 클럽이라도 이 조회를 사용할 수 없다.

## 모임 정보 진입과 회원 권한

모임 홈의 정보 링크는 같은 클럽의 ‘모임 정보’ 화면으로 이동한다. 현재 구성 통계는 정보 전용 화면이면서 내부 정보 열람이 허용된 분기에 배치된다. 예전의 ‘클럽 상세 멤버 미리보기 바로 다음’ 설명으로 현재 홈의 배치를 판단하지 않는다.

서버는 요청 회원의 해당 클럽 소속 행 존재 여부를 먼저 확인하고, 없으면 FORBIDDEN으로 거절한다. 회원 역할이 OWNER·ADMIN인지와 무관하게 회원이면 집계할 수 있다. 클럽이 공개된다는 이유나 가입 신청을 했다는 이유만으로 소속 행 존재 검사를 우회하지 않는다.

이 서비스 자체는 클럽 상세를 조회하거나 클럽 상태를 추가 검사하지 않는다. 없는 소속에 대한 결과를 클럽 존재 확인 성공이나 별도의 ‘클럽 없음’ 응답으로 설명하지 않는다. 앱의 내부 정보 열람 조건과 서버의 소속 행 검사를 각각 보존한다.

## 집계 대상과 기준일

해당 클럽의 소속 행 전체에서 회원 번호를 읽고 중복 제거한다. 역할별로 특정 운영진만 집계하거나 최근 참여자만 고르는 기능이 아니다. 가입·탈퇴 후 현재 소속 행과 프로필을 다시 조회한 결과를 사용하며, 기존 화면에 전달된 값이 다른 기기에서도 즉시 사라진다고 보장하지 않는다.

나이 기준일은 Asia/Seoul의 조회일이다. 클럽 생성일·가입일·과거 월말 기준의 기록이 아니다. 동일한 구성원이라도 생일이나 프로필 변경 뒤에는 분포가 달라질 수 있다.

## 공통 집계·차원별 숨김

대상 회원 번호를 중복 제거해 전체 대상 수를 계산하고, 회원 프로필의 성별·생년월일·MBTI를 읽는다. 같은 회원의 프로필 행이 여러 개 조회되어도 처음 읽은 한 행만 사용한다. 대상 번호에 대응하는 프로필이 없으면 그 회원은 전체 수에는 남지만 차원별 응답 수에는 들어가지 않는다.

성별은 현재 값 1·2를 남성·여성으로 집계하고 그 밖의 값과 미입력은 제외한다. 나이는 기준일의 만 나이로 계산한다. 20세 미만은 ‘10대 이하’, 20~29세·30~39세·40~49세·50세 이상은 각각 해당 나이대로 묶으며, 생년월일이 없으면 나이 응답에서 제외한다. MBTI가 있으면 I·E로 나누고 미입력은 제외한다. 모든 값이 본인인증으로 검증됐는지를 집계 서비스가 검사하는 것은 아니다.

| 조건 | 응답 |
| --- | --- |
| 중복 제거한 전체 대상이 5명 미만 | 전체 표시 불가, 모든 분포 비움, I/E 분포 없음, MBTI 입력률 0 |
| 전체는 5명 이상이나 특정 차원 응답자가 5명 미만 | 그 차원만 숨김 |
| 응답자는 5명 이상이나 그 차원의 0이 아닌 분류 중 1~4명이 있음 | 그 차원 전체를 숨김 |
| 모든 0이 아닌 분류가 각각 5명 이상 | 그 차원 분포를 반환. 0명 분류는 숨김 조건에 해당하지 않음 |

성별·나이대·I/E를 독립적으로 판정한다. 예를 들어 성별 5명·4명은 성별 전체를 숨기지만 다른 차원은 별도로 표시할 수 있다. I 8명·E 0명은 I/E 응답자가 8명이므로 100%·0%를 반환할 수 있다. 전체 표시 허용이 참이어도 세 차원 모두 숨겨질 수 있다.

분포의 분모는 전체 대상이 아니라 해당 차원 응답자다. MBTI 입력률만 MBTI 입력자/전체 대상이다. 따라서 전체 10명 중 MBTI 입력자 4명은 I/E 분포를 숨기면서 응답의 MBTI 입력률은 0.4로 남는다.

## 응답과 화면 표시의 경계

응답에는 **전체 대상 수**, 전체·차원별 표시 여부, 최소 기준 5, 성별·나이대의 분류명과 비율, 선택적인 I/E 비율, MBTI 입력률이 있다. 개별 분류의 인원 수 필드는 없지만, ‘응답에 원시 인원 수가 전혀 없다’는 설명은 맞지 않는다. 전체 5명 미만일 때에도 실제 전체 대상 수는 반환한다.

화면은 허용된 차원만 가로 비율 막대와 반올림한 정수 백분율로 표시한다. MBTI 입력률 문구는 I/E 분포가 표시될 때 그 분포와 함께 표시한다. 분포가 숨겨졌다고 응답의 모든 관련 수치까지 제거되는 것은 아니다. 각 비율을 따로 반올림하므로 화면 합계가 정확히 100%가 아닐 수 있다.

전체가 숨겨졌거나 표시할 차원이 하나도 없으면 ‘구성원이 적어 통계를 표시하지 않습니다.’를 표시한다. 이 문구는 전체가 많은 경우에도 입력 부족이나 작은 분류 때문에 나타날 수 있다. 현재 기능은 최소 집단 크기로 분포 공개를 제한하는 것이며, 다른 정보와 결합해도 개인을 절대 추정할 수 없다는 보장을 뜻하지 않는다.

## 갱신·로딩·실패

앱은 클럽 접근 상태 변경을 구독해 통계를 다시 읽는 경로를 갖는다. 최초 로딩에는 작은 로딩 표시를 하고, 실패에는 ‘구성 통계를 불러오지 못했어요’와 재시도를 제공한다. 재시도는 해당 클럽 통계를 다시 조회한다. 기존 자료 갱신은 공통의 기존 내용 유지 정책을 사용한다. 이벤트 통계의 조용히 숨기는 오류 처리와 같다고 설명하지 않는다.

| 분류 | 확인 근거 | 현재 차이·영향 | 후속 확인 |
| --- | --- | --- | --- |
| Risk | 공통 집계·응답 모델 | 전체 대상 수와 숨긴 차원의 MBTI 입력률도 응답에 남음. 카운트 미반환 또는 개인 식별 불가를 보장하는 기능으로 설명할 수 없음 | 응답 수치와 최소 집단 보호의 적용 범위 검토 |
| Gap | 공통 안내 문구 | 전체 인원이 많아도 차원별 입력·분류 조건 때문에 ‘구성원이 적어’ 안내가 나올 수 있음 | 사용자에게 숨김 원인을 구분할지 결정 |

## 수용 기준과 검증 근거

- **AC-01 실제 입구:** 모임 홈에서 모임 정보로 이동한 뒤 내부 열람 허용 분기에 구성 통계를 표시한다. 운영진 전용 회원 통계 화면과 혼동하지 않는다.
- **AC-02 회원 조건:** 해당 클럽 소속 행이 있는 회원은 역할과 무관하게 조회할 수 있고, 비회원·가입 신청만 한 사용자는 거절한다.
- **AC-03 대상 범위:** 클럽 소속 회원 번호 전체를 중복 제거해 집계하며, 운영진이나 최근 활동자만의 통계로 바꾸지 않는다.
- **AC-04 기준일:** Asia/Seoul의 조회일로 만 나이를 계산하며, 가입일이나 과거 특정 시점에 고정된 통계로 설명하지 않는다.
- **AC-05 소속 변경:** 새 요청은 현재 소속 존재를 다시 검사한다. 앱의 접근 상태 갱신 경로와 다른 기기에 이미 표시된 값의 즉시 회수를 동일하게 취급하지 않는다.
- **AC-06 전체 최소 기준:** 중복 제거한 대상이 4명이면 전체 분포를 숨기되 응답의 전체 대상 수는 4로 유지한다. 5명부터 차원별 조건을 별도로 검사한다.
- **AC-07 차원·최소 분류:** 성별 5명·4명은 성별 분포를 숨긴다. I 8명·E 0명은 I/E 분포를 허용하며, 한 차원의 실패가 다른 차원을 자동으로 숨기지 않는다.
- **AC-08 응답률과 분모:** 전체 10명 중 MBTI 입력자 4명은 I/E 분포 없음·입력률 0.4를 반환한다. 성별·나이대·I/E 비율은 각각 해당 차원의 응답자를 분모로 한다.
- **AC-09 표시와 응답 구분:** 화면은 허용된 분포와 정수 백분율을 표시하며 전체 대상 수 필드의 존재를 부정하지 않는다. I/E가 숨겨지면 앱에 MBTI 입력률 문구만 따로 나타난다고 설명하지 않는다.
- **AC-10 모든 차원 숨김:** 전체 5명 이상이라도 모든 차원이 숨겨지면 현재 공통 안내를 표시한다. 이를 반드시 전체 5명 미만인 증거로 해석하지 않는다.

- **AC-11 로딩·실패·재시도:** 최초 로딩 표시, 오류 안내, 해당 클럽 통계 재시도를 제공하며 정상 응답의 소수 집단 안내와 구분한다.
- **AC-12 자료의 검증 범위:** 현재 프로필 필드 집계와 별도의 본인인증 데이터 검증을 구분한다. 기존 시험 서술을 현재 전체 기능 통과 수로 합산하지 않는다.

검증 근거: ClubDemographicsServiceTest의 비회원 거절 시 집계 미호출 및 회원 허용 시 전체 회원 번호 전달 단언, 공통 DemographicsServiceTest의 최소 기준·차원별 숨김·비율·MBTI 입력률 단언을 읽었다. 기존 2026-05-27 작성본의 ‘클럽 시험 2개·공통 시험 4개 통과·flutter analyze 클린’은 당시 서술이며 이번 실행 기록이 아니다. 위 수용 기준 전체를 새로 실행한 결과로 표시하지 않는다.
