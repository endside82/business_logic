> 현재 상태: **코드와 필요한 운영 화면 완료, 신규 이용 봉인**. 차량 배치도 부재 때문에 닫힌 상태가
> 아니며, 서명 앱 자리 경합·알림·신고 검증 뒤 개통한다.

## 제품 목적

호스트가 대절 버스를 등록하고, 모임 운영 방식에 맞게 참가자의 자리를 배정한다. 대절 버스도 승용차·
자차와 같은 차량 모델을 쓰지만 차량 주인은 없고 호스트가 운영한다.

자리 운영은 두 축을 조합한다.

| 축 | 선택 | 효과 |
| --- | --- | --- |
| 자리를 정하는가 | 지정 / 비지정 | 지정은 배치도의 자리 번호를 사용하고, 비지정은 정원만큼 순번 자리를 만들어 인원만 센다 |
| 누가 자리를 잡는가 | 호스트 전담 / 참가자 자기 선택 | 호스트는 항상 배정할 수 있고, 자기 선택을 허용한 경우에만 참가자가 빈 자리를 잡는다 |

## 시나리오 기준 수용 조건

| 시나리오 | 기대 결과 | 현재 판정 |
| --- | --- | --- |
| B-01 호스트가 대절 버스 등록 | 활성 배치도 또는 정원으로 차량을 만들고 모임별 차량 수 상한을 지킨다 | 코드 완료 |
| B-02 지정 자리 운영 | 배치도 좌석을 복사하고 기사석·통로·이용 불가 자리를 선택 대상으로 만들지 않는다 | 코드 완료 |
| B-03 비지정 자리 운영 | 정원만큼 자리 행을 만들되 번호를 좌석 번호처럼 보여 주지 않고 탑승·잔여 인원만 표시한다 | 코드 완료 |
| B-04 호스트 배정·재배정·해제 | 본인을 포함한 참석 자격자를 배정하고 타인 변경에는 사유·이력·알림을 남긴다 | 코드 완료 |
| B-05 참가자 자기 선택·이동·반납 | 허용된 참가자만 빈 자리를 잡고, 이동 충돌 시 기존 자리 해제까지 롤백한다 | 코드 완료·반납은 안전 출구 |
| B-06 동시 자리 경합 | 같은 자리에는 한 명만 성공하고 한 사용자의 두 차량 탑승을 데이터베이스도 거절한다 | 코드 완료 |
| B-07 참가 종료·차량 정리 | 취소·강퇴·탈퇴 때 자리를 회수하고 점유·신고가 남은 차량 삭제를 막는다 | 코드 완료 |
| B-08 자리 안전 신고 | 자리 점유자를 서버가 확정하고 타인 신원은 호스트와 해당 본인에게만 보인다 | 코드 완료·안전 출구 |

## 운영 준비 상태

- 표준 배치도 9종이 기준 데이터로 제공된다.
- 관리자 화면에서 목록·좌석표 조회, 복제, 이름·설명 수정, 사용 시작·중지를 할 수 있다.
- 선택 가능한 좌석이 없는 배치도는 활성화할 수 없다.
- 사용 중인 배치도의 좌석표는 파괴적으로 바꿀 수 없다.
- 호스트 본인 좌석과 자리 표시 이름이 지원된다.

## 개통 전에 남은 일

같은 출시후보의 서명 앱에서 실제 호스트와 두 참가자가 마지막 자리를 동시에 선택하고, 자리 이동·
호스트 재배정·자리 반납·역할 회수·앱 재시작·푸시 이동·자리 신고를 왕복한다. 이 증명과 책임 고지
승인이 끝나면 `TRANSPORT`를 연다.
