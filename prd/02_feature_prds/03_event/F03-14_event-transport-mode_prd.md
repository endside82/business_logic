> 현재 상태: **코드 완료, 신규 이용 봉인**. 고객·서버 기능이 없어서 닫힌 것이 아니라 서명 앱의
> 다중 역할 검증과 책임 고지 승인을 마친 뒤 열기 위해 봉인했다.

## 제품 목적

호스트와 공동 호스트가 모임에서 차량 이동을 함께 조율할지 정하고, 참가자의 자리 반납과 자차 이동을
허용할지 관리한다. 종전처럼 `없음/카풀/버스` 중 하나만 고르지 않는다. 이동 운영을 켜면 대절 버스,
참가자 승용차, 자차를 같은 모임에서 함께 사용할 수 있다.

| 설정 | 의미 |
| --- | --- |
| 이동 운영 | 차량 등록·자리 배정·승차 위치 조율을 사용할지 결정 |
| 자리 반납 허용 | 참가자가 자기 자리를 스스로 비울 수 있는지 결정 |
| 자차 허용 | 참가자가 자차로 온다고 등록할 수 있는지 결정 |

살아 있는 차량이 있으면 이동 운영을 끌 수 없다. 설정을 먼저 꺼 차량과 탑승자를 화면에서 고립시키는
상태를 서버가 막는다.

| T-02 호스트가 이동 운영 시작 | 호스트·공동 호스트만 설정을 저장하고 통합 이동수단 화면으로 들어간다 | 코드 완료 |

| T-06 자차 허용 변경 | 허용할 때만 새 자차를 만들고, 이미 존재하는 자차의 종료는 봉인·설정과 무관하게 허용한다 | 코드 완료 |

## 출시 전에 남은 일

1. 서명 앱과 실제 호스트·참가자 계정으로 설정 변경과 차량 보호를 왕복한다.
2. 차량·자리 상태 알림과 안전 신고가 실제 기기·운영 화면에서 이어지는지 확인한다.
3. 참가자 간 이동 조율의 책임 고지를 승인한다.
4. 운영 설정에 `TRANSPORT`를 추가한다.

상세 근거는 [대절 버스·카풀 통합 기능 완료 근거](../../../../docs/release-gate/evidence/MOV-01/README.md)를
따른다.
