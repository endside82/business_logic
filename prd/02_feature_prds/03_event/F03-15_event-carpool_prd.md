## 제품 목적

참석자는 남을 태울 승용차를 제안하거나, 다른 차량에 태워 달라고 요청하거나, 자차로 온다고 등록할 수
있다. 대절 버스와 별도 카풀 시스템을 쓰지 않고 모든 이동수단을 차량·자리 한 모델로 관리한다.

승용차 주인도 자기 차량의 자리 하나를 차지한다. 이 규칙 덕분에 운전자가 자기 차를 둔 채 다른 차량의
탑승자가 되는 모순을 같은 유일 제약으로 막는다. 자차는 본인 자리 하나와 0원 금액을 가진 차량이다.

## 상태와 권한

| 흐름 | 현재 규칙 |
| --- | --- |
| 승용차 제안 | 참석자 본인이 등록하면 `PENDING`. 주인이 첫 자리를 즉시 차지 |
| 호스트 결정 | 호스트·공동 호스트가 승인 또는 거절. 화면이 본 차량 버전을 함께 보내 늦은 결정을 차단 |
| 승인 | `CONFIRMED`가 되어 탑승자 배정 가능 |
| 거절·취소 | 차량 자리를 모두 비우고 주인은 자차로 복귀 |
| 자차 | 허용된 참석자 본인이 생성. 한 자리·0원·즉시 확정 |
| 승차 요청 | 참석자가 승차 위치를 남김. 아직 자리가 없으면 “태워 주세요” 상태 |
| 안전 신고 | 차량 ID에서 운전자를 서버가 확정하며, 클라이언트가 신고 대상을 바꿀 수 없음 |
