## 현재 출시 범위와 이 표의 역할

첫 출시 범위는 [현재 상황 안내의 첫 출시에서 제공할 것](../../../docs/README.md#첫-출시에서-제공할-것)을, 후속 기능은 [첫 출시를 기다리게 하지 않는 일](../../../docs/README.md#첫-출시를-기다리게-하지-않는-일)을 따른다. 확인 결과와 남은 실행 검증은 [첫 출시 기능의 확인 범위](../../../docs/development/IMPLEMENTATION_WORKBOARD.md#첫-출시-기능의-확인-범위)를 따른다. 이 표에서 별도 출시 승인이나 새로운 우선순위를 만들지 않는다.

기존 표는 17개 영역의 초기 후보안이었다. 현재 [기능 목록](../00_prd_items/05_feature_definitions.md)은 21개 영역·175개 기능이며, 기능 수는 공개 기능 수나 시험 통과 수가 아니다. 아래는 정본에 명시된 포함·후속 범위를 요약하고 개별 확인이 필요한 경계를 연결한 표다.

## 우선순위와 변경 제안

기존 P0·P1·P2는 기획 논의를 위한 분류다. 현재 실행 목록의 우선순위나 실제 공개 설정을 대신하지 않는다.

| 분류 | 후보를 논의할 때의 기준 |
|---|---|
| P0 | 핵심 사용자 가치에 필요한 범위 |
| P1 | 핵심 경험의 안정화·반복 사용 |
| P2 | 운영 효율·고급 기능·확장 |
| 보류 | 필요한 결정·입력과 재검토 조건을 먼저 명시할 범위 |

범위를 바꾸려면 대상 기능 ID, 사용자 가치, 연결된 정책·외부 의존, 수용 기준, 승인 근거를 [결정 등록부](decision_register.md)에 연결한다. 이미 포함된 기능을 과거 보류 후보만 보고 제외하지 않는다. 구현된 후속 기능의 결함을 수정하는 일과 기능을 공개하는 일도 구분한다.

## 과거 MVP 후보표 원문 보존

아래는 작성 시점이 확인되지 않은 수정 전 논의안을 2026-11-22에 보존한 것이다. 현재 우선순위·구현 결함·출시 범위의 근거로 사용하지 않는다. 특히 마일리지의 ‘호출처 부재’와 정기모임 자동 종료의 미구현 취급은 현재 정본으로 대체됐다.
