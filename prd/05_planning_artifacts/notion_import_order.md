## 전달 전 확인

[Notion용 Markdown 작성 가이드](../00_prd_items/12_notion_markdown_guide.md)에 관리 항목·도식·변경 규칙을 모아 둔다. 여기에서 같은 필드 표를 별도로 운영하지 않는다.

1. 전달 대상과 기준 커밋을 정하고 문서 목록을 고정한다. Git에서 제외한 로컬 원천 자료가 필요한 경우 전달 범위에 포함했는지 따로 기록한다.
2. [문서 전환·대조 상태](../PRD_MIGRATION_STATUS.md)를 함께 제공한다. 미검토·과거 기록·소스 대조·실행 확인을 한 가지 완료 상태로 합치지 않는다.
3. 폴더와 상대 링크를 외부 페이지의 연결 관계로 대응시킨다. 저장소 밖 문서를 가리키는 링크도 전달 대상이나 별도 참조로 명시한다.
4. 기능 ID 누락·중복, 제목·표·도식 원문, 결정 근거를 확인한다. 원천 메모로 최신 PRD를 일괄 재생성하지 않는다.

## 전달 후 기록

실제 가져오기를 실행한 경우에만 대상 공간·실행 시각·원본 버전·문서 목록과 확인 결과를 남긴다. 원본과 사본의 내용·연결·검토 상태가 일치하는지 확인하고 누락 또는 변환 실패를 기록한다. 이 절차 문서가 존재한다는 이유로 외부 전달을 완료 처리하지 않는다.
