# 02. 홈 피드 PRD

<!-- release-document: reference -->
> **문서 구분: 기능·설계·절차 참고 문서.** 2026-11-22 현재 기능 PRD와 서버·앱 소스의 대조 요약이다. 새 제품 시험·실기기·실제 위치·외부 알림 확인은 아니다. 실행 순서는 [앞으로 할 일](../../../docs/plan/NEXT_WORK.md)을 따른다.

## 결론과 기능 정본

홈은 공개 탐색과 회원별 활동을 모아 다음 행동으로 연결한다. 핵심 피드의 네 결과와 별도 회원 목록을 구분하고, 목록이 있다는 사실을 현재 상세·참가·구매 권한으로 확대하지 않는다.

## 홈에 보이는 순서와 조건

위치 거절 안내 다음에 다가오는 내 이벤트, 추천 이벤트, 곧 열리는 이벤트, 다시 만나면 좋을 사람, 인기 클럽, 찜한 이벤트, 최근 본 이벤트, 새로운 플랜을 배치한다. 내 일정·추천·사람·찜·최근 본 구역은 회원용이며 플랜 구역은 마켓 공개 범위가 열렸을 때 보인다. 빈 목록·실패·로딩을 숨기는 보조 구역과 오류를 표시하는 핵심 구역을 구분한다.

핵심 피드는 로그인 추천 10개·미래 공개 이벤트 10개·활동 클럽 5개·발행 플랜 5개를 요청한다. 내 일정은 승인·승인 후 입금 대기 신청의 앞 3개, 찜은 첫 페이지의 앞 5개, 사람 추천은 최대 10명, 최근 본 이벤트는 기기 기록 앞 10개를 현재 상세로 읽은 성공 항목이다.

곧 열리는 이벤트는 클럽 소속이 없는 독립 이벤트·정기모임 중 공개 또는 승인제 공개, 열린 상태, 숨김 제외와 미래 시작을 적용한다. 로그인 차단 호스트를 제외한다. 이벤트 추천은 본인 주최·마감 표시·이미 참여/대기·심사 대기/승인 신청도 제외한다.

## 홈에서 이어지는 실제 행동

| 선택 | 목적지·경계 |
|---|---|
| 추천 카드 | 추천 상세 중간 화면. 일반 이벤트 상세로 다시 이어짐 |
| 예정·내 일정·찜·최근 본 이벤트 카드 | 해당 일반 이벤트 상세 |
| 사람 카드 | 현재 관계·공개 조건을 적용하는 사람 상세 창 |
| 인기 클럽 카드 | 현재 화면 위의 클럽 상세 |
| 새 플랜 카드 | 플랜 상세 |
| 예정 이벤트 더보기 | 이벤트 탭을 날짜순으로 변경. 기존 필터 전체 초기화와 다름 |
| 클럽 더보기 | 클럽 목록 탭 |
| 내 일정·찜 더보기 | 마이의 내 이벤트·위시리스트 |
| 새 플랜 더보기 | 현재 탭 위에 플랜 마켓 |
| 상단 검색·알림·전체 메뉴 | 같은 순서의 공통 세 버튼. 검색은 공개, 알림은 로그인과 목적지 보존을 적용 |

카드·더보기의 경로 변경과 화면을 위에 쌓는 이동이 섞여 있다. 추천 목록에서 상세로 갔다가 보조 추천을 선택하는 경우도 따로 확인하며 모든 입구의 복귀가 동일하다고 단정하지 않는다. 찜 해제와 추천 이유 열기는 상세 이동과 별도 행동이다.

## 새로고침·캐시·실패

핵심 네 요청은 병렬로 보내고 모두 끝난 뒤 함께 반영한다. 초기와 명시적 갱신은 네 상태를 로딩으로 비워 골격을 보여준다. 모두 실패하면 전체 오류, 일부 실패하면 구역 오류를 표시한다. 비로그인 추천은 빈 성공이므로 공개 세 요청의 실패와 전체 오류 조건은 같지 않다.

홈 캐시는 계정 범위와 5분 유효 시간을 따른다. 계정 변경·명시적 캐시 무효화 전 응답은 현재 캐시에 넣지 않는다. 성공한 구역만 저장하고 다음 캐시 읽기는 실패했던 구역도 이전 목록 또는 빈 성공으로 돌려줄 수 있다. 강제 조회 두 개가 같은 세대에서 겹치는 경우는 별도 확인 범위다.

내 일정·사람·찜·최근 본 구역은 별도 공급자다. 핵심 새로고침이 이 자료를 모두 명시적으로 무효화하는 것은 아니다. 본문 재구성의 재구독과 계속 유지되는 자료, 관련 이벤트·클럽·플랜 변경에 따른 재조회를 구분한다.

## 추천의 의미와 남은 차이

이벤트 추천은 시작 시각·참여율·주최자 후기·등록 시점·거리 신호를 조합한다. 사람 추천은 함께 참석한 근거가 있는 후보 중 내가 남긴 다시 만나기 선택·공동 참석·같은 클럽·공통 관심과 취향·최근 만남을 사용한다. 사람 추천에서 상대가 나를 선택했는지를 노출하지 않는다.

추천 더보기의 기간·가격·정렬은 받은 페이지마다 적용한다. 첫 페이지가 필터로 비면 뒤의 후보를 읽을 입구가 없어질 수 있고, 페이지를 붙인 전체 목록은 선택한 순서로 다시 정렬되지 않는다. ‘이번 주’는 앞으로 7일, ‘이번 달’은 다음 달 같은 날짜까지다. 후기 점수를 ‘관심사 매칭’으로 표시하는 배지와, 알림을 등록하지 않는 빈 목록의 알림 약속 문구는 현재 차이다.

추천 상세의 ‘비슷한 추천’은 현재 이벤트의 유사 검색이 아니라 일반 추천에서 현재 항목을 뺀 목록이다. 추천 상세는 실제 상세와 보조 추천을 모두 기다리며 홈의 전체 점수 이유를 그대로 이어받지 않는다.

## 현재 제한과 검증 범위

- 홈 위치 안내와 실제 좌표 전달은 다르다. 현재 핵심 피드 호출은 좌표를 넘기지 않으며 예정 이벤트는 거리순이 아니다.
- 마켓 구역을 숨겨도 플랜 요청은 핵심 묶음에 남는다. 화면 숨김을 요청 차단으로 기록하지 않는다.
- 다가오는 내 이벤트는 상태·신청 생성순의 앞 3개이며 미래 일정순을 보장하지 않는다.
- 회원 보조 구역의 실패 숨김, 부분 실패 캐시, 같은 세대의 겹친 갱신과 출발 경로별 복귀는 각 기능의 제한 표를 따른다.
- 기존 홈 탐색·마켓 범위·캐시·기간·추천·사람 위젯 시험의 목적을 확인했다. 새 시험 실행·실제 GPS·모든 역할의 기기 왕복·외부 알림 검증은 수행하지 않았다.
