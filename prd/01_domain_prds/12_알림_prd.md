# 12. 알림 PRD

<!-- release-document: reference -->
> **문서 구분: 도메인 요약.** 2026-11-22 소스 대조를 반영했다. 현재 작업 순서는 [앞으로 할 일](../../../docs/plan/NEXT_WORK.md)을 따른다.

## 사용자 흐름과 범위

각 탭 첫 화면의 상단 알림 아이콘에서 받은 알림을 읽고 해당 업무 화면으로 이동한다. 목록과 유형별 그룹 보기 모두 다음 알림을 이어 받는다. 알림함의 설정에서는 수신 카테고리와 방해금지 시간을 바꾸며, 앱 설정에서는 기기 등록을 확인한다. OS 권한이 거부됐으면 알림함에서 기기 설정으로 안내한다.

이 도메인의 기능 PRD는 6개다. 시나리오 등록 수·과거 trace 수·위험 표 행 수를 현재 결함 수나 시험 통과율로 표시하지 않는다. 구체적인 상태·실패·복귀 조건은 각 기능 PRD가 담당한다.

## 기능별 진입점

| 기능 | 실제 입구 | 함께 읽을 조건 |
|---|---|---|
| [알림함·읽음·삭제](../02_feature_prds/12_notification/F12-01_notification-list-read_prd.md) | 상단 알림 아이콘 → 목록·업무 화면 | 읽음 실패 복구, 스와이프 삭제 실패 공백 |
| [그룹 보기·미읽음 배지](../02_feature_prds/12_notification/F12-02_notification-grouped-badge_prd.md) | 알림함의 보기 전환 | 커서 누적 합계, 그룹 카드 갱신, 1,000건 초과 집계 한도 |
| [카테고리 수신 설정](../02_feature_prds/12_notification/F12-03_category-settings_prd.md) | 알림함 → 설정 | 푸시·알림함 함께 저장, 광고 수신 동의, 12개 묶음 |
| [방해금지 시간](../02_feature_prds/12_notification/F12-04_quiet-hours_prd.md) | 알림 설정 → 방해금지 시간 | 한국 시간·자정·요일, 다른 수신 조건과 예외 |
| [푸시 기기 관리](../02_feature_prds/12_notification/F12-05_device-token-management_prd.md) | 설정 → 기기 관리 | 로그인 세션별 등록, 소유 충돌 재발급, 다른 세션 삭제 공백 |
| [OS 알림 권한 안내](../02_feature_prds/12_notification/F12-06_permission-banner_prd.md) | 알림함의 거부 상태 배너 | 설정 왕복과 실제 수신 성공 구분 |

## 공통 규칙

- 상단 배지는 계정의 미읽음 수이며 그룹 카드의 수는 지금까지 조회한 알림의 합계다. 두 수를 같은 모집단으로 취급하지 않는다.
- 읽음·모두 읽음의 실패는 해당 임시 변경을 복구한다. 스와이프 삭제 실패와 그룹 카드의 즉시 갱신에는 별도 공백이 남아 있다.
- 카테고리 스위치는 새 푸시와 알림함 기록을 함께 바꾸고, 기존 알림을 삭제하지 않는다. 광고성 정보 수신은 수신 동의와 이력도 함께 바꾼다.
- 방해금지는 시간에 따른 푸시 제한이다. 카테고리·동의·수신자·OS 권한·기기 등록은 별도 조건이며, 시간 제한을 껐다고 모두 허용되는 것은 아니다.
- 기기 등록은 로그인 세션에 속한다. 다른 회원 소유 토큰은 재할당하지 않고 기존 발송 중단·재발급으로 복구한다. 같은 회원의 다른 세션 기기 삭제는 현재 API와 화면의 결과가 어긋날 수 있다.
- 알림을 열 때 목적지의 권한과 공개 범위를 확인한다. 필요한 식별자가 없으면 안내하고, 알림이 있다는 이유로 권한을 우회하지 않는다.

## 검수와 공개 상태

확인은 실제 입구 → 알림 조작 → 대상 업무 → 결과 → 원래 화면 복귀를 기준으로 한다. 배지·목록·그룹의 수와 계정 변경을 함께 보되, 기능 요청과 상태는 소스·시험·로그로 확인한다. 화면 이미지는 배치 등 시각 질문에만 사용한다.

이번 갱신은 해당 소스와 문서의 대조다. 실제 기기 권한 왕복·운영 푸시·배포된 앱의 확인과 구분한다. 발송 작업의 재시도, 운영자의 재발송, 정산 환불 이후 통지 등은 [알림 정책](../03_policy_prds/notification_policy_prd.md)과 생산 도메인의 근거도 함께 읽는다. 전체 실행 우선순위는 위 작업 정본을 따른다.

문서별 대조 결과와 소스 버전은 [전체 문서 최신화 기록](../../verification/document-refresh-2026-11-22.json)에 있다. `units/`는 로컬 조사 참고이며 이 요약을 과거 원문으로 자동 덮어쓰지 않는다.
