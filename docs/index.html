최근 반영한 변경과 검증 범위
  • UI UX(11월 18일): 메뉴·작성·복귀 개선을 최신 앱과 API main에 통합했습니다. Android 에뮬레이터에서 실제 채팅 송수신·연결 복구·사진 선택과 임시보존·외부 링크 진입 및 원화면 복귀를 확인했습니다. Android 실기기 연결과 iOS TestFlight 설치 후 검증은 남아 있습니다. 이 반영은 원격 배포나 스토어 공개를 뜻하지 않습니다.
  • 개발: 구조 재정비는 정한 범위를 11월 6일 끝냈고 그 밖의 재정비는 하지 않습니다. 앱 시험 실패는 0이고, 앱 전체 시험은 매일 한 번 main에서 자동으로 돕니다. 11월 8일 관리자 API 계약 다섯(목록·건수·다시 보내기 키·일괄 처리·옛 경로)을 서버와 관리자 웹에 맞추고, 기능 문서 판정에서 나온 서버 수리(글 칸 길이 검사, 무결성 오류 분류, 교착 둘)를 합쳤습니다. 관리자 웹의 키 싣기와 앞 요청 안내도 합쳤습니다. 같은 날 밤 기능 문서 대조에서 나온 결정 아홉(73~81)을 권고대로 정했고, 환불 분쟁 판정 되돌림의 글과 표시, 데이트 방 30일 닫힘, 요청 검증 규약, 관리자 서버 글 칸 길이 검사를 고쳐 합쳤습니다. 같은 밤 결정의 서버·앱·관리자 웹 고침과 앱 갈래의 화면·문구 고침(제한 계정 입구, 기부 한도·메시지·알림, 플랜 연결 칸, 덧붙일 말, 서버와 같은 글자 셈, 데이트 단추 잠금, 현금 정기모임 여정 장면 등)을 모두 합쳤습니다. 앱 갈래는 사용자 지시로 조정 세션이 도로 맡았고, 같은 밤 늦게 결함 후보 둘째 묶음, 알림함·묶음 보기의 커서 조회와 안 읽은 수의 차단 상대 빼기, 원시 입력 칸 33곳의 서버 글자 셈, 열쇠 전수, 승인제 모임의 신청 메시지 칸, 나가기 확인 셋의 실제 동작 시험, 준비 시작·끝 앞뒤 검사를 합쳤습니다. 실 DB 묶음 관문은 공개 5,716건·관리자 401건 실패 0 이었습니다. 82 는 앱 규칙에 맞춰 닫았습니다. 결정 83~87 도 같은 밤 권고대로 답해, 공개 뒤에도 호스트·공동 호스트가 모임의 위치 공유 허용을 끄고 켜는 창구와 알림 둘, 정산 선입금을 출시 범위로 닫고 모임 전에 받는 돈을 참가비 선결제로 모으기, 세션이 먼저 끝나도 탈퇴 응답을 끝까지 받아 기기 기록 지우기, 기부 내역의 날짜와 시각을 서버·앱에 합쳤습니다. 호스트 받은 함의 결제·환불·정산 문의 카드도 그 모임 화면을 엽니다. 같은 밤 늦게 앱을 새 화면 패키지로 옮기고 go_router 를 18 로 올렸고, 저장소의 오류 처리를 공통 해석기 하나로 모았으며, 클럽 채팅 거절 코드를 열거로 바꿨습니다. 발송 실패 복구 여정의 앱 장면을 돌리다 찾은 웹의 먼 모임 상세 반복 조회는 11월 9일 새벽 고쳐 앱 main 에 합쳤습니다.
  • 배포: 11월 7일 서버 네 가지를 prd-20261107a로 올리고 Android 1.0.0 (14)을 내부 트랙에 배포했습니다. 내부 테스트용 임시 결제를 켰고 실제 돈은 오가지 않습니다.
