06. 결제 · 지갑

충전·결제·환불·개설권·멤버십·수익·정산의 현재 경계와 기능별 근거를 모았습니다. 2026-11-22 문서 대조이며 제품 실행 완료와 구분합니다.

이 영역의 기능별 출시 완료 기준에서 확인할 결과와 증거를 봅니다. 기능 포함 여부와 구현 완료·실환경 통과·공개 승인은 별도로 판정합니다.

이 영역의 역할과 경계

지갑은 포인트 잔액과 거래를 확인하고 충전·카드·구독·수익·정산 등으로 이어지는 입구다. 잔액의 유료·무료 구성, 사용할 수 있는 금액, 은행으로 출금할 수 있는 금액은 구분한다. 모든 서비스의 유료 행동이 지갑 안에서만 끝나는 구조가 아니다. 주최자가 직접 받은 계좌이체와 그 반환, 실제 은행 출금·외부 지급은 별도의 처리와 확인이 필요하다.

여기서는 기능 열 개의 현재 입구·조건·결과·실패·재조회를 요약한다. 모임 참가자 간 비용 정산, 클럽 운영비, 정기모임 결제, 마켓 상품, 출금과 미수금의 전체 계약을 대신하지 않는다. 목적지 공개 범위와 결제 기능 제한도 지갑 화면을 열 수 있는지와 별개다.

결제·환불·정산을 읽는 순서

잔액과 최근 거래에서 시작해 거래 상세로 원인을 확인한다. 충전은 주문과 확정을 나누고, 결과 불명은 새 충전과 구분한다. 자동충전은 저장한 잔액 임계값이 실행 조건이라는 옛 설명을 사용하지 않는다. 현재 실행은 결제 부족액을 기준으로 카드·월 한도·진행 중 충전 상태를 판단한다.

참가비는 신청별 서버 금액으로 결제하고, 취소 전 예상액과 실제 취소에서 상태·시각을 다시 판정한다. 계좌이체 반환 대기를 지갑 환불 완료로 표현하지 않는다. 옛 고정 24시간·12시간 안내는 모임별 정책·귀책·일행 추가 결제·잔여 원금 계산과 별개다.

수익은 완료 정산의 실수령액 집계와 최근 정산 행을 구분한다. 정산 목록 요약은 목록 필터의 합계가 아니다. 거절 정산에 이의를 접수해도 정산은 거절에 남고, 운영자가 승인한 뒤 대기로 다시 연다. 예상일·다음 재시도 시각·지급 완료 증거를 구분한다.

우선 확인할 제한

주제현재 문서에 기록한 차이
충전 완료 표시서버가 보류 상태를 성공 응답으로 반환하는 경로와 앱의 완료창 판정 차이
카드·자동충전사용 불가 카드의 기본 지정·선택, 삭제된 카드가 남은 설정, 임계값 안내와 부족액 실행의 차이
거래 파일CSV가 목록 유형 필터를 쓰지 않고 종료 자정 포함 범위도 다름
잔액·요약 조회일부 조회 실패가 0원·부족으로 표현되고 재조회 범위가 화면마다 다름
개설권합산 수량과 첫 항목 만료 안내, 신규 구매와 미확인 구매 재시도 조건의 차이
개인 멤버십다시 시작 확인 가격과 현재 청구 가격, 혜택 조회 실패·재시도, 유예 경과와 배치 상태 변경의 차이
호스트 정산 이의기존 이의 로딩/오류와 없음의 구분, 이미 지급된 상태와 지급 복구 충돌의 처리 차이

이 표는 발견한 차이를 정리한 것이며 코드 수정을 완료했다는 뜻이 아니다. 각 기능의 수용 기준과 제한을 함께 읽는다. 금액 정책·환불·지급의 공통 판단은 결제·정산 정책과 교차 확인한다. 공통 정책 정본은 현재 기능 근거로 갱신했으며, 보충 운영 절차의 문서 대조와 실제 운영 실행 확인은 별도로 남아 있다.
