16. 마일리지

클럽 활동에 보상하는 비현금 점수 제도다. 회원은 활동으로 점수를 쌓고 등급·배지·랭킹을 확인하며, 클럽 운영진은 정책과 적립·사용·정정을 관리한다. 지갑·결제·정산과 연결되지 않아 현금화나 환불은 없다. 핵심 기능은 2026-09-04 운영 기본 출시 목록에 포함했다. 실기기 알림과 화면 이동 확인은 출시를 막지 않는 운영 점검으로 남겨 두었다.

회원 화면, 클럽 운영 화면, 플랫폼 이상 사건 복구 화면까지 구현했고 초기 데이터베이스 정의 대조, 서버 실계정 왕복, 앱 화면 왕복과 전체 자동 검증을 마쳤다. 운영 기본 출시 목록에도 MILEAGE를 반영했다. 실제 기기에서 알림 수신과 올바른 화면 이동을 확인하는 일은 출시 후 운영 점검으로 관리한다. 사진 승인 적립은 이후 코드와 클럽 운영 화면까지 완성됐고 2026-09-05 현재 기본 브랜치 전체 회귀도 통과했다. 역할별 앱↔서버 흐름과 빈 데이터베이스 설치를 확인한 뒤 MILEAGE_PHOTO로 따로 출시한다. 시즌·고급 검토(반복 수동 적립 한 종)·이벤트별 규칙은 2026-09-05 권고안대로 결정돼 구현 전이고, 클럽별 후기 작성 기간은 만들지 않기로 확정했다.

구현 근거와 출시 순서, 감수하는 한계의 정본은 클럽 마일리지 출시 계획에서 확인한다.

점수를 안전하게 기록하는 원칙

마일리지는 돈이 아니며 지갑·정산·환불과 연결하지 않는다. 모든 점수 이동은 지우거나 덮어쓰지 않고 새 기록으로 남긴다. 잘못 준 점수는 반대 방향의 정정 기록으로 바로잡고, 사용할 때는 만료가 가까운 적립분부터 차감한다. 같은 작업을 다시 실행해도 점수는 한 번만 움직인다.

원장 — 4가지 유형, 되돌릴 수 없는 기록

모든 점수 이동은 장부에 한 줄로 남고 수정·삭제되지 않는다 — 기록 추가만 가능. 잘못된 것은 반대 부호 행으로만 바로잡는다.

유형부호의미
적립+수동·일괄·자동 적립·호스트 제안 승인으로 발생.
차감−잔액 부족 시 거절. 만료 임박분부터 먼저 소비.
정정원 기록 반대잘못 준/뺀 점수를 반대 부호 기록으로 바로잡음. 같은 기록 두 번 정정 불가.
만료−적립분의 만료일이 지나면 잔여분이 소멸.
만료가 가까운 점수부터 사용

점수를 사용할 때는 가장 먼저 만료될 적립분부터 빠진다. 어느 적립분에서 얼마가 빠졌는지도 기록해 나중에 확인할 수 있다. 만료일은 클럽 정책을 따르며 기본값은 365일이다.

제도 상태 세 가지: 미개설·운영 중·일시 중지

클럽이 F16-04 정책 화면에서 직접 시작하고 멈춘다. 상태는 세 가지이고, 운영 중이 아니면 점수가 움직이지 않는다.

  • 미개설: 클럽이 아직 시작하지 않은 상태다. 설정을 시작하기 전이면 서버가 미개설로 응답하고, 적립·차감·호스트 제안 제출이 모두 막힌다. 클럽을 만든 직후에 시작할 수도 있고, 운영하던 중에 도입할 수도 있다. 도입 이전의 활동은 소급 적립하지 않는다.
  • 운영 중: 클럽이 정책 화면에서 시작한 상태다. 적립·차감·호스트 제안이 정상 동작한다.
  • 일시 중지: 클럽이 운영하다가 잠시 멈춘 상태다. 새 적립과 사용은 막히지만, 이미 받은 점수의 만료는 원래 날짜대로 진행된다.
  • 만료일 변경은 향후 적립분에만 적용되고 기존 원장에 소급되지 않는다(미리보기에서 안내).

이 도메인의 부수효과

영향여부이유
알림서버 생성 완료적립·사용·정정·만료·등급·배지·제안 결과 알림은 만들어진다. 실제 기기 수신과 화면 이동은 출시 후 운영 점검으로 확인한다.
이벤트있음체크인·후기가 자동 적립 조건이다. 사진 승인 적립은 구현됐지만 별도 출시 전이며, 호스트 제안은 이벤트 호스트 권한과 연결된다.
결제·정산없음마일리지는 지갑·정산·회계와 연결되지 않는다. 현금화·환불 경로 없음.
감사강함모든 운영 작업이 변경 전·후 내용과 함께 감사 기록(5년 보존)에 남는다.

첫 출시에서 알고 가는 한계

출시된 핵심 기능에 다음 운영 한계가 남아 있다
  • 활동 저장 직후 서버가 중단되는 매우 짧은 구간에서는 자동 적립 신호와 실패 기록이 모두 남지 않을 수 있다. 매일 점검이 후보를 올리고 운영자가 판정한다.
  • 자동 회수 때 잔액이 부족한 건은 검토 목록에 올라오지만 전용 처리 버튼은 없다. 운영자가 수동 정정·차감 도구로 처리하고 메모와 함께 닫는다.
  • 잔액이 0인 현재 회원도 랭킹에 보일 수 있다. 출시를 막지는 않으며 랭킹 화면을 다시 다룰 때 노출 기준을 정한다.
  • 탈퇴한 회원의 프로필 카드는 현재 회원이 직접 주소로 요청하면 열릴 수 있다. 이벤트 참석자 등 다른 화면과 함께 제품 범위를 정해야 한다.
  • 등급 기준 변경 뒤 자동 재계산은 동작하지만 실패분을 다시 실행하는 앱 버튼은 없다. 실패가 남으면 운영자가 처음부터 재실행한다.
