12. 알림

알림은 그 자체로 기능이 아니라, 다른 영역에서 생긴 일을 사용자에게 전달하는 보조 흐름이다. 그래서 알림을 기획할 때 가장 먼저 정해야 할 건 “알림 화면을 어떻게 그릴까”가 아니라 “누구에게, 언제, 왜 보낼까, 그리고 누른 다음에 어디로 보낼까”다.

실제 지갑 반환이 끝난 뒤 알립니다

정산 송금·분담 취소 알림과 지갑 반환 완료 알림을 구분합니다. 완료 알림은 반환 거래의 실제 지갑 이동액이 양수일 때 양쪽 당사자에게 발송 의도를 기록하며, 원래 납부자의 환불과 수취자의 반환 방향을 구분합니다. 이동액 0과 반환 실패는 완료 통지 조건이 아닙니다.

현재 계정의 전경 푸시 처리에서 지갑·거래·정산 조회 갱신 신호를 올립니다. 누르면 유효한 분담 번호를 우선해 분담 상세, 다음으로 송금 번호의 상세를 열고 둘 다 없으면 지갑의 모임 정산 목록으로 이동합니다. 수동 은행 잔여분은 별도입니다. 발송 의도 중복 방지와 실제 기기의 한 번 수신은 같은 보장이 아닙니다. 실제 지갑 반환 완료의 알림에서 금액과 전달 경계를 확인합니다.

기존 문서에는 2026년 10월 26일 구현·자동 검사 완료 기록이 있습니다. 이번 갱신에서 그 검사를 다시 실행한 것은 아닙니다. 실제 기기의 수신·이동·지갑 갱신은 남아 있습니다. 취소·반환·결과 불명 복구와 현재 검사 기록과 남은 실패를 함께 확인합니다.

이 영역의 기능별 출시 완료 기준에서 확인할 결과와 증거를 봅니다. 기능 포함 여부와 구현 완료·실환경 통과·공개 승인은 별도로 판정합니다.

현재 이용 경로와 제한

2026년 11월 22일 소스 대조 기준으로 알림함은 상단 아이콘에서 열고, 일반 목록과 그룹 모두 커서로 이어 읽습니다. 카테고리 스위치는 푸시·알림함을 함께 바꾸며 광고성 수신 동의도 해당 스위치에서 변경합니다. 방해금지·OS 권한·기기 등록은 별도 조건입니다.

읽음 실패는 임시 변경을 복구합니다. 스와이프 삭제 실패 안내, 읽음 뒤 그룹 카드 갱신, 같은 회원의 다른 세션 기기 삭제에는 확인해야 할 공백이 남아 있습니다. 해당 기능의 위험 표를 따릅니다.

투표 결과와 주최자의 다음 행동을 알린다

공개된 모임에서 만든 참가자 투표의 시작·마감, 일정·장소 확정 결과, 주최자의 후보 선택 요청을 구분한다. 초안 참가자 투표의 공개 훅에는 시작 통지 호출이 없으므로 모든 공개 시 시작 알림을 보장하지 않는다. 참가자에게 오는 알림과 운영자가 처리해야 할 알림은 설정이 다르다. 게시글 투표에는 전용 시작·마감 알림을 보내지 않는다.

누가 받고 어느 화면으로 이동하는지는 투표 알림의 수신자와 설정을 따른다. 실제 휴대전화 수신 검사는 남아 있다.

중단 뒤에도 발송 기록으로 복구합니다

주간 요약과 수신 동의 재확인 메일의 별도 비동기 경로는 이 복구 보장에 포함하지 않습니다. 주간 요약 메일의 대상과 발송 한계를 함께 확인합니다.

업무 알림의 발송 의도를 저장하고, 운영자는 대기·실패를 조회해 유효한 작업을 재시도합니다. 가입·복구·Google 연결 번호 메일은 요청 중 발송하며 옛 링크 메일 아웃박스와 다릅니다. 일정·투표·관심인·제재 등 업무 알림과 파일·마일리지 후속 처리도 저장된 작업을 기준으로 복구합니다.

알림 기록·발송 수락·실제 수신을 구분합니다에서 재처리와 실제 수신의 경계를 확인합니다.

카테고리 스위치는 새 푸시와 알림함 기록을 함께 바꿉니다. 방해금지는 시간에 따른 푸시 제한이며 이미 생성된 알림함 기록을 취소하지 않습니다. 항상 전달하는 종류와 시간 예외는 별도 정책입니다.

관리자 재시도도 유효한 실패 작업과 현재 정책을 확인하고 처리자·사유를 남깁니다. 처리 소유권·임대 만료·다음 시도 시각을 구분하며, 생성·제출 수를 실제 도착 수로 표시하지 않습니다. 자세한 경계는 알림 기록·발송 수락·실제 수신을 구분합니다를 따릅니다.

검수할 조건과 현재 확인 범위

아래 항목은 검수 질문입니다. 모든 항목이 현재 발생 중인 결함이라는 뜻은 아닙니다. 기능별 현재 공백은 각 기능 PRD를 따릅니다.

  • OS 푸시 권한이 없는데 앱 내 알림함도 비어 있는 것처럼 보임 — OS 권한과 별도로 수신 설정·대상 조건을 통과한 인박스 기록을 표시해야 한다.
  • 딥링크 대상이 만료·삭제·권한 없음 — 빈 화면을 띄우지 말고 “이 모임은 종료됐어요” 같은 안내 화면으로 받아 준다.
  • 방해금지 시간 자정 넘김 케이스 — 23:00–07:00 같은 범위 처리 누락.
  • 로그아웃 후에도 푸시 토큰 남아 있음 — 다른 사용자가 같은 기기를 사용하면 잘못된 사람에게 알림.
  • 설정 변경이 즉시 반영되지 않음 — 변경 후 다음 알림부터 적용된다는 안내 또는 즉시 반영 보장.
  • 발송 재시도의 확인 범위 — 현재 처리는 소유자·임대 만료와 다음 시도 시각을 분리하고 현재 소유권을 확인한 결과만 종결합니다. 공급자 수락과 실제 기기 수신은 구분하며, 중단·동시 재처리의 시험 결과는 해당 버전의 근거로 확인합니다.
