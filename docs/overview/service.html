제품 정의

사이숲은 관심사에 맞는 오프라인 모임을 발견하고 참여하며, 클럽 관계와 후속 운영·정산·안전 절차를 이어 가는 커뮤니티 서비스다. 전체 제품에는 플랜 마켓·데이팅·제공자 거래도 포함하지만 문서와 코드의 존재가 현재 공개를 의미하지는 않는다.

현재 공개 범위와 확인 상태

첫 출시의 무료 모임·클럽·정기모임, 주최자 계좌 직접 송금, 교통편·투표·마일리지·스탬프·프로필·공유 등과 플랫폼 결제·마켓·데이트·제공자 거래 같은 후속 공개 범위를 구분한다. 세부 포함·예외는 현재 범위 검토표에서 정본으로 연결한다.

공개 범위, 소스 구현, 기존 실행 기록, 같은 배포본에서 남은 실제 확인은 서로 다르다. 문서가 최신이거나 시험 파일이 있다는 이유로 공개 준비를 완료 처리하지 않는다. 문서 전환·대조 상태를 함께 확인한다.

대표 사용자 흐름

탐색·공유 링크 → 현재 접근 조건 → 대상과 행동 선택 → 필요한 신청·승인·납부 → 실제 상태 확인 → 활동·운영 → 해당 후기·정산·문의로 이어진다. 돈·후기·매칭을 모든 사용자가 반드시 거치는 순서로 그리지 않는다.

취소·권한 상실·연결 실패·응답 유실에서는 남은 의무와 현재 상태를 확인하고 원래 화면으로 복귀한다. 대표 사용자 여정과 상태 정책에 구체적인 경계를 둔다.

결정과 다음 문서

이 개요는 제품 방향과 문서의 입구다. 세부 권한·상태·수용 기준을 이 요약만으로 확정하지 않는다. 사용자 유형, 기능 목록, 상태 정책·권한 정책과 해당 기능 PRD를 함께 읽는다.

기존 출시 범위를 미결정으로 되돌리지 않는다. KPI·운영 응답 기한·문구 등 변경 질문은 결정 등록부에서 현재 근거와 구분한다. 승인하지 않은 수치·담당·공개 약속을 새로 정하지 않는다.
