대표 사용자 여정과 완료 경계

2026-11-22 현재 정본을 대조했습니다. 문서 구조·실제 입구·소스 확인과 실행·공개 결과를 구분합니다.

가입과 원래 목적지 복귀

공개 화면 또는 공유 링크 → 필요한 로그인·가입 → 현재 세션 확인 → 허용된 원래 목적지로 이어진다. 가입 전 이메일 확인과 로그인 뒤의 첫 이용 설정을 구분하며 온보딩 건너뛰기가 가능하다. 취소·번호 만료·응답 유실·다른 계정 전환에서 이전 요청 결과를 잘못 반영하지 않는지 확인한다. 인증·온보딩 정본을 따른다.

여정 1. 모임 발견에서 리뷰까지

홈·검색·캘린더·공유 → 상세의 현재 접근 조건 → 신청 방식·정원·대기열·금액 확인 → 필요한 신청·승인·납부 → 실제 참석 상태 확인 → 활동·체크인 → 자격이 맞는 후기 또는 선택형 피드백으로 이어진다.

승인제와 유료 여부는 동시에 적용될 수 있다. 승인 뒤 납부 대기, 직접 송금 뒤 호스트 확인, 결제 뒤 정원·제재로 인한 참석 불가와 반환을 나누어 안내한다. 유료 참여를 항상 지갑 결제로 연결하지 않는다. 취소·반환 뒤에는 신청·참석·금전 기록을 다시 확인한다. 이벤트 정본, 상태 안내, 후기·신고 정본을 따른다.

여정 2. 호스트가 이벤트를 만들고 운영한다

실제 만들기 입구 → 초안·조건 입력 → 발행 가능 조건 → 현재 모집 상태 → 신청·대기열·입금 확인 → 일정·교통편·공지·출석 운영 → 모임 이후 필요한 후기·정산·반환을 확인한다.

모집 마감과 실제 활동 종료, 신청 승인과 참석, 참석 예정과 현장 체크인은 다르다. 일정 변경은 동의와 최종 적용을 나누고, 취소는 참가 취소와 원천별 반환을 나눈다. 권한이 바뀌거나 요청 응답이 없으면 현재 대상부터 재조회한다. 모임 종료가 모든 정산을 자동 생성한다는 뜻은 아니다. 이벤트 운영 정본을 따른다.

여정 3. 클럽 가입에서 활동과 재정까지

클럽 탐색·상세 → 가입 방식·차단·가입비 확인 → 즉시 가입 또는 승인 대기 → 현재 회원 상태 → 게시글·사진·모임·마일리지·스탬프 활동으로 이어진다. 소유자·위임 운영진·회원은 가능한 행동이 다르다.

가입 승인, 가입비 납부, 기부, 공동 비용 정산은 다른 명령이다. 모임 정산이 클럽 기금에 자동 적립되는 연결을 가정하지 않는다. 탈퇴·소유권 이전·폐쇄 때 남은 신청·반환·자료 접근도 확인한다. 활동 점수·사진 검토·스탬프와 포인트 잔액을 구분한다. 클럽, 마일리지, 권한 가이드를 따른다.

여정 4. 정산 생성과 납부

원천 모임 → 정산 초안과 지출·수입·대상 검토 → 확정 → 각자의 분담금·수취자 확인 → 공개된 수단으로 납부 또는 이체 신고 → 실제 수취자의 확인 → 현재 의무와 거래 재조회로 이어진다.

지출은 납부자에서 비용 보유자로, 수입 분배는 보유자에서 대상 수취자로 이어질 수 있다. 항상 호스트가 돈을 받는다고 설명하지 않는다. 정산 취소·송금 만료 뒤에도 지갑 반환·은행 직접 반환·미결 의무를 별도로 확인한다. 은행 확인 기록이 은행 API의 입금 검증이나 외부 반환 실행은 아니다. 모임 정산, 결제·정산 정책을 따른다.

여정 5. 플랜 작성, 판매, 구매, 활용

내 플랜 → 내용 편집·공개 → 상품 등록·후보 버전 심사 → 승인된 버전으로 판매 시작 → 구매자 탐색·구매 → 보관함·사용 권리 → 허용된 이벤트 생성·후기 또는 환불로 이어진다. 상품 등록·심사 승인만으로 판매 중이 되지는 않는다.

구매 당시 구성과 소유자별 귀속을 기준으로 중복·부분 환불·권리 회수를 확인한다. 환불 신청, 판매자·플랫폼 처리, 실제 지갑 반환·기지급 회수는 별도 단계다. 응답 유실 때 새 구매를 무조건 만들지 않고 현재 구매·권리를 확인한다. 마켓은 후속 공개 대상이며 플랜 마켓 정본을 따른다.

여정 6. 데이팅 매칭과 안전 흐름

본인확인·프로필·동의 → 공개 조건에 맞는 후보 → 호감·지나가기와 한도 → 현재 매칭 → 대화·만남 제안 → 응답·상태 변경·본인 피드백으로 이어진다. 프로필 활성·공개 범위·승인 사진·상대 관계를 따로 확인한다.

거절·후보 없음·차단·만료·재연결은 각 결과로 안내한다. 차단과 프로필 노출 중지는 구분하며 차단 해제가 옛 매치·대화를 복원하지 않는다. 만남 수락이 모든 위치 공유의 동의는 아니다. 데이트는 후속 공개 대상이다. 데이팅 정본, 개인정보·안전 정책을 따른다.

여정 7. 알림과 설정의 공통 흐름

사건과 수신 대상 → 현재 수신 정책·계정·관계 확인 → 허용된 알림함 기록과 채널 작업 → 발송 시도 → 알림함·기기에서 확인 → 현재 권한이 있는 목적지로 이동한다.

카테고리를 끄면 새 푸시와 알림함 기록을 함께 제한한다. 방해금지는 일반 푸시를 건너뛰는 조건이며 알림함 기록을 취소하지 않는다. 항상 전달하는 종류·광고 동의·OS 권한을 따로 확인한다. 공급자 수락과 기기 표시, 알림 열람과 원래 업무 성공은 다르다. 알림 정책을 따른다.

정기모임 등록에서 회차와 코스 종료까지

모임 발견·상세 → 고정/가변 유형과 현재 등록 자격 → 승인·납부 → 회차 참석·출석 확정 → 취소·환불 또는 코스 종료·정산으로 이어진다. 코스 등록과 회차 참석, 고정 코스 비용과 회차별 비용을 구분한다. VARIABLE 자동 종료는 현재 존재하며 조건을 만족해야 한다. 모임 종료 응답은 정산 행 생성이나 실제 지급 완료가 아니다. 정기모임 정본을 따른다.

신고·문의·분쟁에서 처리 결과까지

문제가 생긴 원천 → 해당 신고·문의·운영 이슈·분쟁의 자격 → 접수와 증빙 → 관할 처리·대화·필요한 이관 → 허용된 판정·이의·종결을 확인한다. 접수·경고·제재·보상·자료 보존은 각각의 기록이다. 확장 분쟁 화면의 공개 제한을 기존 환불·신고 처리와 합치지 않는다. 경고·징계, 분쟁, 고객지원을 따른다.

관심인·일정·위치와 자기 정보 관리

관심인 등록은 단방향 목록이며 상대의 공개 모임을 달력·알림으로 확인하더라도 상세 권한을 새로 얻지 않는다. 본인 가능 시간은 다른 사람에게 공개하지 않는다. 위치 공유는 동의·기기 권한·좌표 전송·조회 자격·만료를 따로 확인하고 중지 뒤의 좌표 제거와 열람 로그 보존을 구분한다.

프로필·설정에서 본인 정보 저장, 자료 내보내기, 계정 종료를 요청한 뒤 각 상태를 다시 확인한다. 삭제 예약은 즉시 탈퇴가 아니며 로그인으로 자동 취소되지 않는다. 관심인, 캘린더, 위치, 프로필을 따른다.

제공자 배정에서 실제 지급까지

서비스 제공자 배정·조건 제안 → 현재 계약 수락 → 계약금·참가자/호스트 분담 → 이행·출석·수금 조건 → 정산 확정 → 지갑 지급·필요한 사후 회수로 이어진다. 사전 준비 판정과 최종 정산 가능 여부, 정산 확정과 실제 입금은 다르다. 제공자 거래는 후속 공개 대상이며 제공자 배정·정산 정본을 따른다.

여정 검토 기준

실제 입구, 행동하는 계정과 결과를 받는 당사자, 현재 조건, 성공·부분 처리·결과 불명, 재조회와 복귀를 적는다. 예외와 경계 사례, 기능 변경 영향, 기획 QA 정책에서 해당 위험과 확인할 증거를 고른다. 문서 도식이나 탐색 맵을 실제 앱 이용 증거로 쓰지 않는다.
