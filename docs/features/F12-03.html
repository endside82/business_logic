F12-03. 카테고리별 알림 설정

알림을 역할별로 켜고 끕니다. 스위치 하나가 푸시와 알림함 기록을 함께 바꾸며, 광고성 정보 수신은 마케팅 동의도 함께 변경합니다.

12개 카테고리

이벤트, 모임 운영, 클럽, 1:1 메시지, 클럽 채팅, 결제·환불, 정산·지갑, 서비스 제공자 활동, 데이팅, 문의·안전·신고, 광고성 정보 수신, 추천으로 나눕니다. 항상 전달하는 안전·계정 권리 알림은 별도 기준을 따릅니다.

토글 한 번이 만드는 변화

한 카테고리를 끄면 새 푸시와 알림함 기록이 함께 중단됩니다. 이미 받은 알림은 남습니다. 이메일은 이 화면에서 변경하지 않습니다. 묶음 전체를 한 요청으로 저장하고, 실패하면 그 변경만 되돌린 뒤 ‘설정 변경에 실패했습니다’를 안내합니다.

묶음 안 모든 종류의 두 채널이 켜져 있을 때만 스위치가 켜집니다. 일부만 켜진 상태는 꺼짐으로 표시합니다.

광고성 정보 수신과 동의

광고 스위치는 채널 설정과 마케팅 수신 동의를 함께 바꾸고 동의 이력을 남깁니다. 변경 뒤에는 처리 결과가 알림함에 남는다는 안내를 제공합니다. 동의하지 않은 회원에게 광고 수신을 기본 켜짐으로 표시하지 않습니다.

사용자가 확인할 결과

  • 저장 후 다시 들어와도 해당 묶음의 값이 유지됩니다.
  • 실패한 변경을 복구할 때 다른 성공한 변경까지 되돌리지 않습니다.
  • 광고를 꺼도 과거 알림과 항상 전달해야 하는 절차 통지는 구분해 남깁니다.
  • 방해금지 시간 화면에서 돌아와도 카테고리 설정은 유지됩니다.

2026년 11월 22일 소스 대조입니다. 실제 기기의 푸시 수신·OS 권한과 외부 발송 성공은 별도 확인합니다.

이 기능의 출시 완료 기준

2026년 11월 22일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 현재 공개 범위와 실행 확인은 출시 상태와 근거를 따릅니다. 위의 날짜별 기존 분류는 현재 운영 설정이나 검사 통과를 대신하지 않습니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 알림 종류별 허용/해제 후 실제 발송 대상과 저장된 설정이 일치한다.
  • 필수 알림·마케팅 동의·이미 받은 알림·계정 전환을 구분하고 허용되지 않은 발송을 막는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 알림의 관련 완료 기준도 함께 확인합니다.
