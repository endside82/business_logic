F06-03. 거래 내역 조회·내보내기

본인 거래의 페이지·필터, 상세 증감·취소 누계와 CSV의 별도 범위·날짜 경계를 명시한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

결론

본인 거래를 유형·기간으로 조회하고 상세와 CSV 공유로 이어진다. 목록 조건과 내보내기 조건은 다르다. 실제 화면은 카드 환불의 별도 진행 큐를 표시하지 않으며, 거래 상태·지갑 증감 방향·충전 취소 누계를 구분한다.

목록의 입구·조건·추가 조회

지갑의 거래내역 또는 최근 거래 전체보기에서 연다. 첫 페이지는 기본 20건이며 서버가 본인 거래를 생성 시각·번호 내림차순으로 정렬한다. 같은 유형·기간을 다음 페이지에도 보내고 날짜별로 묶어 표시한다.

조건·상황현재 동작
유형전체·충전·결제·환불·정산. 각 선택은 정확한 한 거래 유형이며 모든 결제·환불 계열을 묶는 분류가 아님
기간전체·최근 7일·최근 30일·최근 3개월·직접 선택
프리셋서울 오늘에서 7·30·90일을 뺀 날짜부터 조회. 종료일은 목록 요청에 보내지 않음
직접 선택최근 365일 범위 안에서 두 날짜를 선택. 서버 목록은 시작일 0시 이상, 종료일 다음 날 0시 미만
상태 조건서버와 앱 모델·공급자는 지원하지만 현재 화면에 상태 선택기는 없음
조건 변경첫 페이지부터 재조회. 다른 종류의 조건은 유지
추가 페이지 실패이미 읽은 목록 유지와 하단 다시 시도
첫 실패·빈 결과·마지막각각 전체 다시 시도, 빈 안내, 마지막 거래 확인 문구

목록 행은 상세를 위에 열므로 단순 뒤로가기는 목록으로 돌아온다. 현재 목록에는 당겨 새로고침이 없다. 관련 자료 변경 신호로 다시 읽는 경로와 직접 재시도를 구분한다.

상세·표시·관련 행동

서버는 거래 소유자를 확인한다. 없는 거래와 다른 사람의 거래는 각각 조회 불가와 권한 거절이다. 앱은 없는 거래 안내와 일반 오류 재시도를 구분한다.

표시·행동현재 범위
금액 부호서버가 전·후 잔액으로 정한 증가·감소 방향을 사용. 유형 이름으로 추측하지 않으며 방향이 없거나 중립이면 부호 없음
상태대기·결과 확인 중·완료·실패·취소. 알 수 없는 값은 상태 확인 필요
잔액·명세유료·무료, 거래 전·후 잔액, 설명·일시, 있는 주문번호·결제 회사 거래번호와 복사
무료 만료일응답에 만료일이 있을 때만 표시. 과거 거래를 만료 상태로 바꾸지 않음
충전 취소완료 충전이고 전액 취소가 아닐 때 확인창과 취소 요청. 서버가 최종 취소 가능 조건을 판정
취소 누계충전 상세가 완료 취소 거래의 누계를 읽음. 전액 이상이면 취소 배지와 누계 표시, 취소 단추 숨김. 일부면 완료와 남은 취소 입구
관련 모임모임 선입금의 참조 모임, 관련 모임이 있는 호스트·모임 정산에만 연결
관련 클럽기부·클럽 구독 결제이고 참조 번호가 있을 때 연결
문제 접수실패 거래 또는 결제·환불·정기모임 결제 분류에 해당하면 거래 번호를 담아 문의 작성으로 연결

취소 성공 또는 서버에 반영됐을 수 있는 오류 뒤에는 지갑 자료 변경을 알리고 해당 상세를 다시 읽는다. 요청 중 계정 범위가 달라졌으면 이전 결과를 현재 공급자에 반영하지 않는다. 취소 자체의 돈 규칙과 외부 결과 확인은 포인트 충전의 범위다.

관련 모임·클럽 선택은 경로를 바꾸므로 단순 상세 뒤로가기와 같은 거래 목록 복귀를 보장하지 않는다. 서버가 결제·환불에 관련 모임 번호를 보강해도 현재 앱의 관련 모임 버튼 조건은 위 유형에 한정된다.

CSV·텍스트 내보내기

앱 상단 CSV 내보내기는 시작일이 있고 두 날짜 차이가 90일 이내일 때 요청한다. 목록 프리셋의 종료일이 없으면 서울 오늘을 채운다. 처리 중 중복 누름을 막고 받은 파일을 시스템 공유창에 넘긴다. 공유창 호출과 외부 앱의 저장 완료는 구분한다. 실패하면 오류 안내 뒤 다시 시도할 수 있다.

서버는 두 날짜 필수·역순 거절·날짜 차이 90일 초과 거절을 적용한다. 날짜 양끝을 포함하면 최대 91개 달력 날짜가 될 수 있으므로 정확히 90개 날짜라는 뜻으로 쓰지 않는다. 조회한 거래가 10,000건을 넘으면 거절한다. 상한을 확인하기 전에 목록 전체를 읽는다.

내보내기에는 유형·상태 선택값을 보내지 않는다. 선택 기간의 모든 본인 거래를 대상으로 하며 화면에 보이는 특정 유형이나 읽어 둔 페이지만 내려받는 기능이 아니다. 서버는 CSV와 텍스트 형식을 제공하고 앱은 CSV만 노출한다. CSV는 UTF-8 BOM과 날짜·유형·금액·유료·무료·잔액·상태·설명을 담는다. 텍스트의 충전·지출·환불 합계는 일부 유형만 합산하며 지갑 전체 누계와 같지 않다.

조회 거절 뒤의 복구

추가 조회를 포함한 자료 접근 거절에서는 이전 목록과 선택·권한 값을 비우고 오류를 표시한다. 기존 목록 유지·재시도는 통신 오류일 때의 복구이며, 401은 세션 처리에 맡긴다.

현재 제한과 확인 범위

분류확인한 차이·한계영향·후속
Gap유형을 선택해도 CSV는 그 기간 전체 유형을 내보냄파일 범위를 사용자에게 분명히 알리거나 필터 계약을 함께 보완할 대상
Gap내보내기는 종료일 다음 날 0시를 포함하는 Between 조회, 목록은 그 시각 미만자정 경계의 거래 포함 범위가 다름. 날짜 차이 90일과 달력 날짜 수의 차이도 함께 정리
Gap위임 조회에서 비공개 모임 거래의 유형을 비우는 서버 응답과 앱의 필수 문자열 유형이 불일치해당 응답을 앱 모델이 읽는 경로의 계약·도달성 및 오류 처리를 확인할 대상. 일반 본인 조회 성공으로 확대하지 않음
Risk일부 취소된 충전에도 확인창은 원 충전 전체 금액을 표시누계·남은 취소 가능액과 확인 문구를 맞출 대상
Risk최근 기간은 시작일만 보내며 관련 모임·클럽 이동은 원 경로를 바꿈정확한 기간 끝과 원 목록 복귀를 보장하는 설명을 금지
미검증실제 공유 파일 저장·외부 취소 확인·위임 응답·날짜 경계 실DB 재생아래 기존 시험의 확인 범위 밖이며 이번에 실행하지 않음

수용 기준과 검증 근거

  • AC-01 본인 목록: 조회는 본인 거래만 정렬·분할하며 다음 페이지에도 동일 조건을 보낸다.
  • AC-02 정확한 유형: 환불 탭을 모든 환불 계열의 합집합이라고 설명하지 않는다.
  • AC-03 기간 경계: 프리셋의 시작일·종료일 생략과 직접 선택의 양끝 날짜를 구분한다.
  • AC-04 추가 실패: 다음 페이지의 통신 오류 시 앞 목록과 하단 재시도를 유지한다.
  • AC-05 소유자와 없음: 타인 거래를 공개하지 않고 없는 거래와 일반 실패를 구분한다.
  • AC-06 증감 방향: 같은 정산·환불 유형이라도 서버가 차감이라고 하면 음수로 표시한다.
  • AC-07 충전 취소 누계: 전액 취소는 취소 배지와 누계, 부분 취소는 완료 배지와 누계를 보인다.
  • AC-08 취소 후 갱신: 성공·결과 불명 오류의 재조회와 이전 계정 결과 억제를 구분한다.
  • AC-09 내보내기 범위: 전체 기간은 기간 선택을 요구하고 선택 기간의 전체 유형을 CSV 공유창에 전달한다.
  • AC-10 내보내기 한도: 날짜 누락·역순·날짜 차이 90일 초과·10,000건 초과를 거절한다.
  • AC-11 관련 이동: 상세 뒤로가기와 모임·클럽 경로 변경의 복귀를 같은 보장으로 적지 않는다.
  • AC-12 계약 한계: 위임의 빈 유형과 목록·CSV 자정 경계 차이를 미해결로 추적한다.

기존 transaction_export_test.dart는 기간 없는 요청 차단·서울 종료일·중복 누름 억제·90일 초과 차단을 단언한다. transaction_charge_cancelled_detail_test.dart는 취소 없음·부분·전액·누계 없는 옛 응답 표시를, wallet_transaction_direction_test.dart는 증감 부호를 단언한다. 서버 TransactionExportServiceTest는 날짜 입력·건수 상한을 확인한다. 이번에는 이 시험의 목적·단언과 소스를 대조했으며 새 시험 통과나 실제 파일 저장 결과는 아니다.

이 기능의 출시 완료 기준

현재 제한과 확인 범위를 함께 판정한다.

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 현재 공개 범위와 실행 확인은 출시 상태와 근거를 따릅니다. 위의 날짜별 기존 분류는 현재 운영 설정이나 검사 통과를 대신하지 않습니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 본인 거래의 유형·기간 필터와 합계·내보내기 결과가 일치한다.
  • 페이지·날짜 경계·취소/환불·권한 없는 다운로드·파일 만료를 확인한다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 결제 & 지갑의 관련 완료 기준도 함께 확인합니다.
