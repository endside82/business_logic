F16-03. 마일리지 시즌

일정 기간마다 점수 경쟁을 새로 시작하고, 종료 시점의 순위를 보존하려는 후속 기능이다. 현재는 실제로 운영할 수 있는 기능이 아니다. 일부 데이터 구조와 화면 틀은 있지만 자동 시작·종료, 순위 계산, 종료 기록 저장과 실패 복구가 없어 핵심 마일리지와 별도로 닫혀 있다.

현재 제품 상태
미완성
핵심 마일리지와 별도 봉인
현재 이용 가능
아니오

4가지
전환·순위·기록·복구
봉인 이유 — 화면만으로는 시즌을 운영할 수 없다

날짜가 됐다고 시즌이 자동으로 시작되거나 끝나지 않고, 종료 순간의 순위도 계산·보존되지 않는다. 중간 실패를 다시 처리할 운영 수단도 없다. 이 상태에서 화면을 열면 회원에게 보이는 시즌 상태와 실제 점수가 어긋날 수 있으므로 별도 출시 범위 설정으로 앱 진입과 서버 직접 요청을 함께 막는다.

개통하려면 완성해야 하는 흐름

flowchart LR S["예정된 시즌"] -->|"시작 시각 도달"| A["진행 중"] A -->|"종료 시각 도달"| C["종료"] C --> R["최종 순위 계산·보존"] R --> X["실패 여부 확인·필요 시 재처리"]

이 흐름 전체가 하나의 기능으로 닫혀야 한다. 목록 화면이나 시즌 등록 화면이 있다는 이유만으로 개통할 수 없다. 자동 전환, 동점 처리, 종료 순위 보존과 실패 복구까지 함께 검증해야 한다.

현재 있는 것과 없는 것

구분현재 상태판단
시즌 데이터 구조·일부 화면부분 존재향후 구현을 위한 틀일 뿐, 실제 운영 완료를 뜻하지 않는다.
자동 시작·종료없음시간이 지나도 시즌 상태가 신뢰할 수 있게 바뀌지 않는다.
순위·동점 처리없음누가 몇 위인지 일관된 기준으로 확정할 수 없다.
종료 시점 기록 보존없음종료 뒤 점수가 바뀌면 과거 순위도 흔들릴 수 있다.
마감 실패 재처리없음일부 회원만 저장된 경우 운영자가 안전하게 복구할 수 없다.

봉인 해제 순서

  1. 예정·진행·종료의 시간 기준과 다음 시즌 전환 규칙을 구현한다.
  2. 점수 산정과 동점 처리 정책을 제품·운영 기준으로 확정한다.
  3. 종료 순간의 회원별 점수와 순위를 변경 불가능한 기록으로 저장한다.
  4. 마감 일부 실패를 찾고 다시 처리하는 운영 화면과 감사 기록을 만든다.
  5. 회원·클럽 운영진·플랫폼 운영자 시나리오를 검증한 뒤, 상위 마일리지가 열린 환경에서 시즌 출시 설정을 추가한다.
