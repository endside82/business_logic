F16-03. 마일리지 시즌

일정 기간마다 점수 경쟁을 새로 시작하고, 종료 시점의 순위를 보존하는 기능이다. 2026-09-06 자동 시작·마감·순위 확정·실패 복구의 구현과 로컬 검증을 마쳤다. 핵심 마일리지와는 별도 출시 대상이며, 기존 데이터 준비와 운영 배포·활성화는 아직 남아 있다.

자동 전환과 종료 기록, 정책 담당자의 재시도 화면을 실제 서버와 앱으로 확인했다. 운영 출시 목록에 시즌 값(MILEAGE_SEASON)이 아직 없으므로 회원 진입·직접 요청·자동 실행은 계속 닫힌다. 핵심 마일리지를 열었다는 이유만으로 시즌도 자동으로 열리지는 않는다.

회원과 운영진이 확인하는 흐름

  1. 예정 → 진행 중: 시작 시각이 되면 자동으로 전환한다. 다음 시즌 합계가 준비되기 전에는 미완성 숫자를 보여 주지 않는다.
  2. 진행 중 → 마감 중: 종료 시각에 회원별 기록을 확정한다. 일부 처리가 실패하면 완료한 기록은 유지하고 실패한 부분만 이어서 처리한다.
  3. 마감 중 → 종료: 모든 회원의 처리가 끝나야 최종 순위와 내 결과를 공개한다. 중간 결과를 최종 순위처럼 보여 주지 않는다.
  4. 종료 뒤: 보존한 순위는 유지한다. 뒤늦게 처리된 적립은 잔액에 반영하되 순위 미포함 지연 적립으로 따로 안내한다.

확정된 운영 규칙

구분현재 상태판단
자동 시작·종료구현·검증 완료예정·진행 중·마감 중·종료를 구분하며 준비 중인 합계는 공개하지 않는다.
순위·동점 처리시즌 적립 기준 하나양수 적립 회원에게 공동 순위 1·1·3을 부여한다. 0점 회원은 순위 없음으로 표시하며 잔액순 전환은 제공하지 않는다.
종료 기록확정 기록 보존종료 뒤 정정으로 현재 잔액이 바뀌어도 과거 순위를 다시 쓰지 않는다. 지연 적립은 별도로 표시한다.
실패 재처리클럽 정책 담당자미완료 마감·시즌 준비를 재시도하고 담당자와 처리 이력을 남긴다.

출시까지 남은 순서

  1. 검증한 코드와 문서를 같은 출시 대상으로 고정하고, 기존 클럽의 제도 설정·회원별 시즌 배정을 준비한다.
  2. 사용자용·관리자용 서버와 앱을 같은 대상으로 배포한다.
  3. 핵심 마일리지가 열린 환경에 시즌 출시 값(MILEAGE_SEASON)을 추가하고 실제 운영 환경의 전환·순위·복구를 확인한다.

구현·실제 앱 왕복·전체 회귀·빈 데이터베이스 대조의 범위는 마일리지 후속 구현 검증 기록에 있다. 이 기록을 서명 모바일 앱이나 운영 배포 완료로 확대하지 않는다.
