F02-02. 홈 새로고침

강제 갱신·5분 캐시·세대 변경·부분 실패와 별도 보조 공급자의 갱신 범위를 구분한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

결론

홈에서 당겨 새로고침하거나 핵심 구역의 재시도를 누르면 핵심 피드의 네 상태를 로딩으로 비우고 캐시를 우회해 다시 읽는다. 추천 요청은 로그인 상태에 따라 생략한다. 내 일정·사람 추천·찜·최근 본 목록은 별도 공급자이므로 모든 홈 자료에 같은 네 요청을 보낸다는 과거 설명을 사용하지 않는다.

사용자가 갱신하는 흐름

  1. 홈의 당겨 새로고침, 핵심 구역 오류의 다시 시도, 전체 오류의 다시 시도에서 시작한다.
  2. 추천 이벤트·곧 열리는 이벤트·인기 클럽·새 플랜 상태를 모두 로딩으로 바꾼다. 이때 이전 네 목록을 유지하는 새로고침이라고 설명하지 않는다.
  3. 현재 계정 범위와 로그인 여부로 조회한다. 로그인은 추천을 포함하고 비로그인은 추천을 빈 성공으로 처리한다.
  4. 캐시의 유효 여부와 관계없이 새 요청을 보내고, 네 결과가 모두 끝난 뒤 성공·실패를 구역별 상태에 반영한다.
  5. 일부 실패는 해당 구역 오류, 모두 실패는 전체 오류로 표시한다. 각 구역의 재시도도 현재 구역 하나가 아니라 핵심 묶음 전체를 다시 읽는다.

처리 표시가 끝났다는 것은 묶음의 요청들이 끝났다는 뜻이다. 모든 구역의 성공이나 실제 기기·외부 서비스 검증을 뜻하지 않는다. 숨긴 마켓의 플랜 요청도 묶음에 포함되는 현재 제한은 홈 피드 메인 조회를 따른다.

캐시와 실패 보존의 차이

홈 저장소는 네 성공 목록과 마지막 수신 시각을 최대 5분 재사용한다. 계정 범위가 바뀌면 캐시와 진행 중 응답의 세대가 바뀐다. 명시적인 캐시 무효화도 세대를 올리고 저장 값을 비운다. 이전 세대 응답은 현재 캐시에 넣지 않으며 홈 공급자는 오래된 결과 표시를 거부한다.

강제 조회 자체는 캐시 세대를 올리는 것과 다르다. 성공한 구역만 저장 값을 교체하고 하나라도 저장 값이 있으면 캐시 시각을 갱신한다. 실패한 구역에 이전 성공 값이 있으면 남고, 없으면 캐시 읽기에서 빈 목록이 된다. 따라서 부분 실패의 다음 일반 캐시 읽기는 모든 구역을 성공 값으로 돌려줄 수 있다. ‘실패 상태까지 5분 보존’이라고 설명하지 않는다.

보조 구역·변경 후 갱신·복귀

내 일정·사람 추천·위시리스트·최근 본 목록은 각각의 공급자와 계정·데이터 변경 구독을 따른다. 홈의 강제 새로고침 함수는 이들을 명시적으로 모두 무효화하지 않는다. 전체 골격으로 본문이 사라졌다가 다시 만들어질 때 재구독되는 자료와 계속 유지되는 자료가 있으므로, 항상 모두 재조회되거나 항상 그대로라고 단정하지 않는다.

클럽·이벤트·플랜 변경 후의 홈 갱신은 관련 데이터 변경 신호와 캐시 무효화 경로를 따른다. 단순히 홈으로 돌아온 경우와 실제 자료가 바뀐 경우를 구분한다. 검색·알림에서 돌아왔다는 이유만으로 강제 새로고침을 실행하거나 조회 0회를 보장하지 않는다.

수용 기준과 검증 근거

  • AC-01 입구: 당겨 갱신·구역 재시도·전체 재시도가 같은 핵심 갱신으로 연결된다.
  • AC-02 로딩: 이전 네 목록을 로딩으로 비우고 갱신 완료까지의 화면을 확인한다.
  • AC-03 계정: 비로그인은 추천을 요청하지 않고 로그인 계정의 범위로 캐시를 구분한다.
  • AC-04 강제 조회: 5분 안의 캐시가 있어도 명시적 갱신은 서버를 다시 읽는다.
  • AC-05 결과: 묶음 완료와 각 구역 성공을 구분하고 부분·전체 오류를 표시한다.
  • AC-06 부분 캐시: 실패한 구역의 이전 값 유무에 따라 다음 일반 읽기의 결과가 달라짐을 확인한다.
  • AC-07 오래된 응답: 계정 변경·캐시 무효화 전 응답을 현재 캐시에 저장하거나 화면에 적용하지 않는다.
  • AC-08 경합: 같은 세대의 두 강제 조회를 응답 순서를 바꿔 확인한다.
  • AC-09 보조 자료: 내 일정·사람·찜·최근 본 자료의 직접 갱신 여부와 재구독을 각각 확인한다.
  • AC-10 변경 후 복귀: 관련 변경 성공 뒤 캐시를 버리고 다시 읽는 흐름과 실패·단순 복귀를 구분한다.

기존 home_repository_cache_test.dart는 클럽 가입·탈퇴·수정 성공 뒤 캐시 재조회와 실패 시 유지 등을 다룬다. event_change_push_home_refresh_test.dart는 이벤트 변경 알림과 홈 갱신을 다룬다. 이것을 모든 갱신 경합이나 이번 실행의 통과로 확대하지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 홈 피드의 관련 완료 기준도 함께 확인합니다.
