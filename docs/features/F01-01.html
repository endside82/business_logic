F01-01. 이메일 가입·로그인

이메일 소유를 번호로 확인한 뒤 가입 정보를 제출하고 계정을 만든다. 가입 응답만으로 앱의 로그인 완료까지 보장되는 것은 아니다. 앱은 받은 토큰으로 내 정보를 읽고 세션을 설치한 뒤 온보딩 또는 본래 이용 화면으로 이동한다. 정상 계정·정지/차단 계정·탈퇴 계정의 결과를 구분한다.

가입 순서

로그인 화면의 회원가입 → 이메일 입력 → 인증번호 요청 → 6자리 확인 → 비밀번호·닉네임·생년월일·약관 입력 → 가입과 앱 로그인 → 온보딩 순서다. 번호 확인만으로 계정은 생성되지 않는다. 확인한 이메일은 가입 정보 단계에서 바꾸지 않으며, 뒤로 가면 이메일 확인 단계로 돌아간다. 번호의 만료·재발송·수신 제한은 이메일 인증 PRD를 따른다.

가입 검증과 중복 요청

  • 번호 확인으로 받은 가입 확인표는 60분 유효하며 제출한 이메일과 일치해야 한다.
  • 비밀번호는 영문·숫자·특수문자를 포함한 8~20자다. 공백은 특수문자로 세지 않는다. 닉네임은 2~16자이며 이미 사용 중인 닉네임은 거절한다.
  • 생년월일로 만 19세 이상을 확인하고 이용약관·개인정보 동의가 모두 있어야 한다. 성별과 마케팅 동의는 선택이다. 현재 가입 요청에는 휴대전화 필드가 없다.
  • 서버가 계정 생성을 확정한 뒤 가입 확인표 삭제를 요청한다. 닉네임 충돌 등 가입 실패는 유효한 표로 수정해 재제출할 수 있고, 같은 이메일로 계정을 중복 생성하지 못한다.
  • 가입 정보 화면은 제출 중 중복 누르기를 막는다. 표 무효이면 이메일 확인 단계로, 이메일 중복이면 로그인·비밀번호 찾기 안내가 있는 단계로 돌아간다. 다른 오류는 입력 화면에서 안내한다.

기존 계정 로그인

이메일과 비밀번호를 입력해 로그인한다. 잘못된 이메일·비밀번호는 같은 자격 증명 오류로 안내한다. 앱은 이메일 앞뒤 공백을 제거해 보내고 서버는 비밀번호를 검증한 뒤 회원 행을 잠가 상태와 비밀번호를 다시 확인한다.

정상·로그아웃 상태는 정상 로그인으로, 정지·차단 상태는 계정 제한 정보가 포함된 세션으로 처리한다. 탈퇴·탈퇴 대기 상태는 거절한다. 제한 세션의 허용 업무는 제재 적용과 제한 계정 이용의 범위로 판단한다. 예전 이메일 미인증 값만으로 서비스를 막는 별도 제한 세션은 현재 동작이 아니다.

로그인 완료와 복귀

  1. 로그인 또는 가입 요청이 성공하면 앱은 받은 토큰을 임시 시도에 보관하고 내 정보를 조회한다.
  2. 내 정보 조회까지 성공해야 현재 계정 세션을 설치한다. 신규 여부에 따라 온보딩 상태를 정리하고, 일반 진입에서는 약관 재동의 여부도 확인한다.
  3. 이동은 인증·계정 제한·온보딩·약관·보관된 이동 대상의 라우터 규칙을 따른다. 모든 성공을 홈 직행으로 설명하지 않는다.
  4. 다른 기기의 새 로그인은 기존 세션을 대체한다. 갱신·대체 안내·로그아웃의 세부 동작은 토큰 갱신과 로그아웃을 따른다.
  5. 취소되거나 계정이 바뀐 옛 로그인 시도의 늦은 응답을 현재 계정에 적용하지 않는다. 서버에 이미 성공한 가입·로그인을 앱 화면 취소가 되돌리는 것은 아니다.
  6. 비밀번호 찾기는 로그인 화면의 별도 입구다. 번호 확인 뒤 변경하며 기존 로그인·AI 연결의 해지는 비밀번호 재설정에서 확인한다.

수용 기준과 검증 범위

  • AC-01 가입 입구: 이메일 번호 확인 전 계정이 없고 확인 뒤 정보 입력·가입·앱 로그인·온보딩을 단계별로 확인한다.
  • AC-02 가입 조건: 확인표·이메일 일치, 비밀번호·닉네임·성년·필수 동의를 검사하고 선택 정보의 미입력만으로 가입을 막지 않는다.
  • AC-03 재제출: 닉네임 충돌은 입력을 고쳐 재시도하고 표 만료·이메일 중복은 적절한 앞 단계로 돌아간다. 동시 제출로 같은 이메일 계정을 둘 만들지 않는다.
  • AC-04 기존 로그인: 잘못된 자격 증명은 같은 오류로 안내하고 정상·정지/차단·탈퇴 상태를 구분한다.
  • AC-05 완료 경계: 가입/로그인 응답과 내 정보 조회·세션 설치를 각각 확인한다. 내 정보 실패에서 성공 안내만으로 로그인 완료로 판정하지 않는다.
  • AC-06 복귀: 온보딩·약관·계정 제한·원래 이동 대상의 순서를 지키고 늦은 응답이 다른 계정을 바꾸지 않는다.
  • AC-07 기기와 복구: 다른 기기 로그인으로 이전 세션을 대체하고 비밀번호 찾기에서 기존 계정으로 복구한다.
  • AC-08 실제 환경: 과거 링크 메일의 수신 기록을 새 번호 인증으로 확대하지 않고 현재 앱·서명·메일 환경의 결과를 별도로 확인한다.
