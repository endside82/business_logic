F04-14. 기부·기부 내역

1,000~1,000,000·메시지·통화·요청 키, 전체/본인 내역과 전체 요약, 7일 취소·알림·폐쇄 반환을 구분한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

현재 범위와 실제 입구

클럽 재정 화면 또는 기부 내역에서 허용된 기부하기로 진입한다. ACTIVE인 FREE 클럽의 현재 회원이 기부할 수 있다. 기부 내역은 현재 회원에게 제공하되 정본 클럽장은 전체, 운영진을 포함한 그 밖의 회원은 본인 기부만 읽는다. 기부·수령·취소 알림은 해당 클럽의 기부 내역으로 이동한다.

금액과 메시지와 통화

서버와 앱 모두 한 번에 1,000~1,000,000을 허용한다. 서버 최소 100 또는 상한이 화면에만 있다는 과거 설명은 현재 계약이 아니다. 앱 빠른 금액은 5,000·10,000·30,000·50,000·100,000이다. 선택 메시지는 서버에서 앞뒤 공백을 제거하고 빈 값은 null로 저장하며 유니코드 코드 포인트 100개까지 받는다. 앱 입력에도 100자 제한을 둔다.

서버 금전 기능이 닫힌 동안 해당 기부 지출은 무료 포인트만 사용한다. 기능이 열리면 유료부터 사용하는 지갑 지출 정책을 적용한다. 기금에는 실제 지출된 유료·무료 몫을 그대로 더하며 무료 기금은 출금할 수 없다. 앱 입력·확인 화면은 금전 기능에 따라 P 또는 원 단위를 사용하고, 비교 가능한 지갑 잔액이 있으면 잔액 초과 제출을 막는다. 서버 잔액 판정이 최종 기준이다.

생성과 결과 복구

POST /api/v1/clubs/{id}/donations는 {amount, message}와 필수 요청 키를 받아 기부 응답을 반환한다. 회원 금전 명령은 계정·명령 종류·클럽·본문에 맞는 키를 준비한 뒤 보내고, 키 준비 실패나 준비 중 계정 변경 때는 보내지 않는다. 같은 화면 세션의 같은 진행 중 의도는 결과를 공유한다. 서버는 기부 명령 영수증 경계를 거쳐 처리한다.

성공하면 기부 행 ACTIVE, 지갑 차감, 동일 통화의 기금 증가, 회계 기록이 함께 처리된다. 앱은 성공 시 입력을 초기화하고 이전 화면으로 돌아간다. 성공뿐 아니라 결과가 불명확하거나 결과를 다시 얻을 수 없는 경우에도 기금·기부 목록·요약·내 통계·넘기기 자료 및 지갑을 다시 읽도록 한다. 실패를 성공으로 표시하지 않고 동작 권한 거절이면 클럽 정보를 갱신한다.

목록과 요약의 모집단

기부 목록은 서버에서 생성 시각·ID 역순으로 반환하고 앱은 20개씩 읽어 월별로 묶는다. 상태는 ACTIVE, REFUNDED, FORFEITED이며 목록은 ACTIVE만 제한하지 않는다. 기부자 닉네임은 현재 조회 가능한 이름을 붙이고 없으면 null이며 앱은 대체 표시를 사용한다. 응답에는 원래 amount, nullable refundAmount, message, createdAt, actions.cancel이 있다.

GET /donations/summary는 현재 회원에게 클럽 전체의 기부 원금 합계·서로 다른 기부자 수·기부 건수를 반환한다. 쿼리는 상태를 제한하지 않으므로 환불 후 순액이나 ACTIVE 기부 합계가 아니다. 내역을 본인만 읽는 회원도 요약 조회의 모집단은 클럽 전체다. 앱 요약 로딩·실패 때에는 이미 읽은 목록의 금액·기부자·건수로 대체하므로 이 대체 값은 같은 의미의 전체 통계가 아니다.

본인 취소와 운영자 환불

POST /donations/{donationId}/cancel에도 필수 요청 키가 있다. 같은 클럽의 본인 기부, 현재 회원, ACTIVE 상태, 생성 후 7일 이내여야 한다. 이미 클럽을 나간 회원은 7일 이내여도 본인 취소가 거절된다. 앱 취소 버튼은 서버 actions.cancel을 사용한다.

환불은 원거래의 아직 남은 유료·무료 몫을 계산하고 미승인 출금 예약을 제외한 기금 가용액을 확인해 같은 몫으로 지갑에 돌려준다. 성공한 기부 행은 REFUNDED, 실제 refundAmount, 환불 시각을 기록한다. 단순히 화면 원금 전액을 언제나 돌려준다고 보장하지 않는다. 목록·요약·기금·지갑을 갱신하고 이미 취소되었거나 결과가 불명확한 응답에서도 관련 자료를 다시 읽는다.

운영자 환불은 별도 운영 명령으로 식별자·사유를 결박하고 대상 계정 상태·기부 ACTIVE·원거래·기금을 확인한다. 회원의 7일 취소와 같은 입구가 아니며 닫힌 기부자 계정을 허용하지 않는다. 성공 시 같은 반환 계산과 REFUNDED 기록을 사용한다.

알림과 폐쇄 반환

기부 성공 시 기부자에게 완료, 클럽장에게 수령 알림을 작성한다. 클럽장 본인 기부라면 중복 수령 알림을 만들지 않는다. 본인 취소와 운영자 환불도 기부자·클럽장에게 실제 반환액을 담아 중복 없이 알리고 운영자 환불임을 문구로 구분한다. 기부 메시지는 성공 알림에 반영한다. 이번 확인은 알림 작성·앱 목적지 코드이며 실제 푸시 수신을 뜻하지 않는다.

폐쇄 반환은 본인 취소와 다르다. ACTIVE 기부의 원거래 잔여 유료 몫은 기간과 관계없이, 무료 몫은 7일 내 기부에 한해 후보가 된다. 각 통화의 남은 기금까지 최근 기부부터 배정한다. 반환액이 있으면 REFUNDED와 실제 반환액을, 없으면 FORFEITED와 0을 기록한다. 부족한 반환액이 있다고 폐쇄가 반드시 막히는 것은 아니다. 탈퇴 계정 제외·구독 환불·가입비 등 폐쇄 전체 계산은 클럽 관리와 생명주기를 따른다.

수용 기준과 검증 근거

  • AC-01 기부 자격: ACTIVE FREE 클럽의 현재 회원만 기부하며 서버 동작 권한에 따라 앱 입구를 제공한다.
  • AC-02 금액 경계: 999와 1,000,001은 서버에서 거절하고 1,000과 1,000,000은 금액 검사에 통과한다.
  • AC-03 메시지: 서버는 앞뒤 공백·빈 값·100 코드 포인트 제한을 적용하고 저장된 메시지를 응답한다.
  • AC-04 통화 보존: 무료 전용 조건과 유료 우선 조건을 구별하고 실제 지출 몫을 기금에 반영한다.
  • AC-05 제출 키: 기부와 취소에 필수 요청 키를 붙이며 키 준비 실패·계정 변경 때 전송하지 않는다.
  • AC-06 성공 복귀: 기부 성공 후 입력 초기화·이전 화면 복귀·관련 금액 자료 갱신을 수행한다.
  • AC-07 결과 불명확: 불명확한 결과를 성공으로 표시하지 않고 관련 내역을 다시 읽는다.
  • AC-08 목록 권한: 클럽장은 전체, 그 밖의 현재 회원은 본인 내역만 읽으며 운영진 역할만으로 전체가 열리지 않는다.
  • AC-09 요약 의미: 서버 요약은 모든 상태의 클럽 전체 원금 통계이며 환불 후 순액·본인 합계와 구별한다.
  • AC-10 취소 자격: 본인·현재 회원·ACTIVE·7일 조건과 서버 취소 동작 권한을 적용한다.
  • AC-11 반환 기록: 원거래 잔여 통화와 기금 가용액으로 반환하고 실제 금액·시각·REFUNDED 상태를 기록한다.
  • AC-12 알림: 기부·취소·운영자 환불 수신자를 중복 제거하고 기부 내역으로 이동한다.
  • AC-13 폐쇄 배정: 유료와 7일 내 무료 후보를 구별하고 통화별 기금 한도에서 최근 기부부터 반환한다.
  • AC-14 이력 구별: REFUNDED·FORFEITED와 원금·실제 반환액을 구별하며 과거 E2E를 현재 통과로 합산하지 않는다.

ClubDonationServiceTest의 최소·최대·메시지 단언과 ClubFundPlanTest의 통화별 환불·폐쇄 배정 단언을 소스에서 대조했다. 시험을 새로 실행하지 않았으며 14개는 수용 기준의 수다.

이 기능의 출시 완료 기준

현재 제한과 확인 범위를 함께 판정한다.

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 사용 가능한 무료 포인트 기부와 허용된 환불이 회원 잔액·기금·거래 내역에 한 번 반영된다.
  • 중복/응답 유실·부족 잔액·클럽 폐쇄·운영자 개별 환불을 확인하며 첫 출시에서 유료 포인트 납부를 열지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 클럽의 관련 완료 기준도 함께 확인합니다.
