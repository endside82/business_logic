F15-08. 제재 집행

누적된 경고에 대해 운영진이 실제 조치를 내리는 면. 공지/주의, 이벤트 신청 제한, 역할 제한, 강제 탈퇴, 수동 잠금까지 강도가 다른 6가지 도구가 있다. 가장 강한 강제 탈퇴는 소유자만 쓸 수 있고, 제재는 사유와 함께 기록되며 나중에 철회할 수 있다.

제재 유형
6종
공지~강제 탈퇴
강제 탈퇴
소유자 단독
서비스에서 재검증
신청 차단 연동
17개 진입점
클럽+플랫폼 전역 2축, 신청 시 실시간 검사
강제 탈퇴는 실제 멤버십 제거까지 이어지고, 실패하면 자동으로 다시 시도한다

강제 탈퇴 제재가 확정되면 그 처리가 완전히 끝난 뒤에만 클럽 멤버십 제거·유료 가입비 환불·강퇴 알림이 자동으로 이어진다. 제재 기록이 확정되지 않았는데 멤버십만 빠지거나 환불만 나가는 일은 없다. 뒤따르는 처리가 실패하면 제재 기록은 그대로 둔 채 자동으로 다시 시도한다. 재시도 간격은 1분에서 시작해 6시간까지 점점 벌어지고, 다섯 번째까지 실패하면 자동 재시도를 멈춘 뒤 소유자에게 긴급 알림을 보낸다. 그다음부터는 소유자가 직접 다시 실행한다. 기한부 이벤트 신청 제한은 만료 시 자동으로 풀린다. 클럽 제재는 매일 새벽 4시에, 전체 서비스 제재는 4시 10분에 정리하며, 그 사이에 목록을 열면 이미 기한이 지난 제재는 곧바로 빠진다. 이벤트 신청 차단은 클럽 제재뿐 아니라 전체 서비스 제재(고객지원 관리자가 플랫폼 차원에서 부과한 제재)도 함께 검사한다.

사용자 시나리오

신청 제한

반복 노쇼 멤버의 이벤트 신청을 막는다

이벤트 신청 제한 제재를 걸면, 그 멤버가 이벤트를 신청할 때 이벤트 도메인이 실시간으로 검사해 막는다.

강제 탈퇴

심각 등급 멤버를 강제 탈퇴시킨다

소유자만 가능. 사유를 적어 확정하면 제재가 기록되고, 멤버십 제거·유료 가입비 환불·강퇴 알림이 자동으로 따라온다.

권한 가드

관리자가 강제 탈퇴를 시도한다

소유자가 아니면 “소유자만 가능합니다”로 막힌다. 외부에서 강제 호출해도 서버가 재검증한다.

수동 잠금

특정 멤버의 자동 등급 재평가를 잠근다

수동 잠금을 걸면 점수가 바뀌어도 자동으로 등급이 재평가되지 않는다. 해제하면 다시 평가된다.

철회

오해가 풀려 제재를 해제한다

활성 제재만 철회 가능. 강제 탈퇴 철회도 소유자만 할 수 있다.

운영자가 알아야 할 것 — 비즈니스 리스크

운영자가 알아야 할 잔여 사항
  • 강제 탈퇴 후 "구독 정리"는 대상이 없어 추가 작업이 필요하지 않다. 클럽 구독은 소유자만 가질 수 있어 일반 멤버가 보유한 구독 자체가 없고, 멤버의 금전 결속인 가입비는 강퇴와 한 묶음으로 전액 환불된다.
  • 전체 서비스 호스팅 제한은 이벤트를 여는 8개 경로에서 모두 막는다. 클럽 이벤트·반복 일정·복제 재개최·플랜 기반 개설·정기모임 개설과 회차 추가가 여기에 들어간다. 데이팅 차단은 프로필을 새로 만들거나 공개로 바꿀 때 막는다. 다만 차단을 걸 때 이미 공개돼 있던 프로필은 그대로 노출된 채 남으므로, 지금은 운영자가 따로 내려야 한다.
  • 회원이 본인에게 걸린 전체 서비스 제재를 앱에서 직접 확인한다. 어떤 제한이 왜, 언제까지 걸려 있는지 보여 주는 전용 화면이 있고, 계정 차단 안내와 제재 알림에서 그 화면으로 바로 이동한다.
  • 역할 제한은 지금 실제 효력이 없다. 제재를 걸면 기록·통지·자동 만료까지는 정상으로 돌지만, 어떤 권한 검사도 이 제재를 확인하지 않아 대상 멤버의 역할 권한은 그대로 남는다. 역할을 실제로 묶으려면 클럽 권한을 직접 조정해야 한다. 공지·주의는 알리는 것 자체가 목적이라 설계대로다.
  • 만료 자동 해제와 조회 시 즉시 만료 처리는 정상 동작한다. 클럽 제재는 매일 새벽 4시, 전체 서비스 제재는 4시 10분에 정리한다.
