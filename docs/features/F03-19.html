F03-19. 일정 변경 제안·참가자 합의 (RS-002)

호스트의 변경 내용에 따라 즉시 반영과 참가자 합의를 구분한다. 장소만 정하거나 바꾸면 바로 적용하고 알린다. 시작 시각이 60분 이상 바뀌거나 가격이 오르면 48시간 합의 절차를 거친다.

현재 변경 규칙 — 2026-11-02

공개 API fc5a69144·앱 4f80511f의 로컬 main 기준입니다. 이 변경을 포함한 새 서버·앱 배포와 기기 확인은 별도입니다.

장소 변경 자체를 중대한 변경으로 분류하던 설명은 대체됐습니다. 가격 인상 판정은 서버 계약이며, 화면에 가격 변경 입력이 있다는 뜻은 아닙니다.

사용자 흐름

  1. 호스트가 이벤트 관리에서 변경할 내용과 사유를 입력합니다. 장소는 지도에서 핀·검색·내 위치로 정합니다.
  2. 서버가 권한·현재 이벤트 상태와 변경 내용을 확인합니다. 즉시 반영 대상이면 저장하고 알립니다.
  3. 합의 대상이면 참가자가 동의 또는 거절합니다. 거절 시 참가 취소를 시도하며, 성공하면 100%·수수료 0 환불 정책을 적용합니다. 응답 성공과 취소·환불 성공은 구분합니다.
  4. 호스트가 현황에서 남은 응답을 확인하고 확정 또는 철회합니다. 미응답이나 철회된 제안이 남으면 확정할 수 없습니다. 이미 성공한 참가 취소·환불은 제안 철회로 복원하지 않습니다.

정기모임·반복 변경과의 관계

열린 오프라인 정기모임은 호스트가 운영 도구의 장소 정하기·바꾸기를 사용합니다. 코스와 아직 시작하지 않은 관리 대상 회차에 적용하고 회원에게 알립니다. 초안은 기존 수정 화면을 사용합니다. 반복 일괄 장소 변경도 장소만으로 합의 요청을 만들지 않습니다.

이 기능의 출시 완료 기준

2026년 11월 2일 갱신한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 장소 단독 변경은 합의 요청 없이 상세·참가자 알림에 반영되고, 큰 시간 변경은 합의 후 적용된다.
  • 기한·권한 변경·동시 확정·재시도를 처리한다. 거절 응답과 실제 취소·환불 결과를 구분하고, 철회가 이미 성공한 취소를 복원하지 않는지 확인한다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 이벤트의 관련 완료 기준도 함께 확인합니다.
