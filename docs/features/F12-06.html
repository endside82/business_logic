F12-06. 알림 권한 안내 배너

OS 알림 권한이 거부됐을 때 알림함에서 기기 설정으로 안내합니다. 권한 상태와 실제 푸시 수신은 따로 확인합니다.

거부 상태에서 설정으로 안내

알림함을 열거나 앱에 복귀하면 OS 알림 권한을 다시 읽습니다. 거부 상태일 때 ‘알림이 꺼져 있습니다’와 ‘허용’ 버튼을 보여 줍니다. ‘허용’은 현재 권한을 다시 확인한 뒤 기기 설정으로 안내합니다.

설정에서 허용하고 돌아오면 배너가 사라지고, 거부를 유지하면 배너가 남습니다. 별도 닫기 동작은 연결되어 있지 않습니다.

배너가 없는 상태의 의미

아직 권한을 묻지 않은 상태, 허용·임시 허용 상태, 웹이나 SDK 조회 불가에서는 배너가 없습니다. 미요청 사용자의 최초 권한 요청은 로그인 세션의 푸시 등록 흐름이 맡습니다.

이 기능은 OS 권한 안내이며 카테고리·마케팅 동의·방해금지를 변경하지 않습니다. 배너가 없다는 사실을 실제 수신 성공으로 판단하지 않습니다.

복귀 후 확인할 결과

  • 거부 상태에서 설정을 열어 허용하고 돌아오면 권한 재조회 뒤 배너가 숨겨집니다.
  • 설정을 바꾸지 않고 돌아오면 배너가 남고 다시 설정을 열 수 있습니다.
  • 허용 상태에서 OS 권한을 끄고 돌아오면 배너가 나타납니다.
  • 지원하지 않는 환경을 모바일 기기의 허용 상태로 세지 않습니다.
  • 반복 복귀 후 최종 권한과 배너가 일치하는지 기기에서 확인합니다.

권한 허용과 푸시 등록

앱 복귀 시 푸시 서비스는 현재 로그인 세션의 토큰 등록을 다시 맞춥니다. APNs 준비·토큰 발급·서버 등록과 실제 전달은 별도 조건입니다. 이 배너 자체의 서버 API는 없습니다.

2026년 11월 22일 소스 대조입니다. 실제 설정 왕복과 수신은 기기·앱 버전·발송 결과를 적은 실행 기록으로 확인합니다.

이 기능의 출시 완료 기준

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 권한을 거절한 사용자에게 필요한 안내가 보이고 설정 이동·재허용 뒤 상태가 갱신된다.
  • 최초 미결정·이미 허용·영구 거절·앱 복귀와 Android/iPhone의 차이를 확인한다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 알림의 관련 완료 기준도 함께 확인합니다.
