F02-05. 검색·알림 진입점

홈 공통 상단의 검색·알림·전체 메뉴, 로그인과 배지, 아래 탭으로 돌아오는 흐름을 구분합니다. 2026-11-22 소스 대조입니다.

결론

홈 오른쪽 위에는 검색 → 알림 → 전체 메뉴의 공통 버튼 세 개를 같은 순서로 둔다. 홈만의 검색·알림 아이콘 두 개라는 과거 설명은 현재 구성과 다르다. 이 기능은 홈에서 해당 화면을 여는 입구와 돌아오는 흐름을 책임진다. 검색 결과·알림 읽기·전체 메뉴의 세부 행동은 각 기능의 정본에서 확인한다.

로그인 뒤에는 유효한 앱 내부 목적지로 이어진다. 계정 잠금·재동의·온보딩·출시 범위 등의 관문이 필요한 상태를 정상 로그인 완료와 같게 취급하지 않는다. 상단 버튼이 자체적으로 인증을 건너뛰거나 다른 계정의 알림을 여는 것은 아니다.

알림 수와 전체 메뉴의 점

알림 버튼은 알림 목록과 같은 미읽음 공급자를 사용한다. 로그인했을 때만 읽고 수가 0보다 크면 숫자 배지를 표시한다. 이 값은 서버의 현재 미읽음 수이며 기기에 도착한 푸시 개수와 같다고 설명하지 않는다. 알림 읽기·모두 읽기·푸시 처리 뒤 수의 반영은 알림 그룹과 배지의 범위다.

현재 미읽음 조회 실패는 공급자에서 0으로 바뀐다. 배지가 안 보인다는 사실만으로 미읽음이 실제로 없다고 판정할 수 없으며, 아이콘 자체는 계속 열 수 있다. 로그인하지 않았으면 미읽음 수와 전체 메뉴의 새 기능 여부를 조회하지 않는다.

전체 메뉴의 점은 새로 열린 기능 안내다. 알림 숫자와 다른 공급자·의미를 가지므로 두 표시를 같은 알림의 중복 배지로 해석하지 않는다. 새 기능 안내를 확인하는 세부 규칙은 전체 메뉴 기능의 검토 범위다.

복귀와 데이터 변경

검색·알림·전체 메뉴는 현재 탭을 다른 경로로 교체하지 않고 위에 쌓아 연다. 뒤로 돌아오면 아래 탭으로 복귀한다. 홈에서 검색 결과의 상세까지 다녀오는 흐름과 알림을 읽고 상세를 여는 흐름은 각각의 결과 화면을 거쳐 돌아온다.

‘홈으로 돌아오면 API 호출이 없다’는 과거 단정을 사용하지 않는다. 홈 공급자는 계정과 이벤트·클럽·플랜 카드 변경을 구독하므로, 다른 화면의 명령·계정 변경·관련 데이터 갱신에 따라 다시 읽을 수 있다. 경로를 쌓아 여는 방식과 데이터 갱신 필요 여부는 별개다.

수용 기준과 검증 근거

  • AC-01 구성: 홈에 공통 검색·알림·전체 메뉴 버튼이 같은 순서로 표시된다.
  • AC-02 공개 검색: 비로그인도 검색 화면에 들어가고 사람·저장 등 후속 기능은 각 권한을 적용한다.
  • AC-03 알림 로그인: 비로그인 알림 진입은 목적지를 보존해 로그인으로 연결하고 정상 완료 뒤 유효한 목적지로 이어진다.
  • AC-04 회원 배지: 로그인 회원의 현재 미읽음 수를 사용하고 0이면 숫자 표시를 숨긴다.
  • AC-05 조회 실패: 미읽음 조회 실패가 현재 0으로 바뀌는 제한을 명시하고 아이콘 이동까지 막지 않는다.
  • AC-06 메뉴 표시: 새 기능 점과 알림 수를 구분하고 비로그인은 두 회원 전용 값을 조회하지 않는다.
  • AC-07 복귀: 검색·알림·전체 메뉴와 상세를 거쳐 아래 탭으로 돌아오며 현재 데이터 변경을 반영한다.
  • AC-08 계정 변경: 다른 계정의 미읽음·홈 상태를 재사용하지 않고 필요한 계정 관문을 적용한다.

기존 app_top_bar_actions_test.dart는 회원·비회원의 버튼 순서·배지·새 기능 점과 홈·클럽·마이에서의 사용을 다룬다. entry_paths_search_notification_help_test.dart에는 검색 결과·상세에서 검색어와 스크롤로 돌아오기, 알림 읽기·상세에서 읽은 목록으로 돌아오는 시험이 있다. 시험 목적·소스 대조를 이번 실행 통과로 기록하지 않는다.

이 기능의 출시 완료 기준

현재 제한과 확인 범위를 함께 판정한다.

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 현재 공개 범위와 실행 확인은 출시 상태와 근거를 따릅니다. 위의 날짜별 기존 분류는 현재 운영 설정이나 검사 통과를 대신하지 않습니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 각 탭 상단의 검색·알림·전체 메뉴 진입이 올바른 화면을 열고 돌아오면 탐색 상태를 유지한다.
  • 로그인 필요·권한 변경·조회 실패를 안내한다. 미읽음 계산과 아직 제공하지 않는 하단 배지 표시는 구분한다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 홈 피드의 관련 완료 기준도 함께 확인합니다.
