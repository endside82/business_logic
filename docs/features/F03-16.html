대절 버스와 자리 배정

주최자가 버스를 등록하고 참가자를 차량별로 배정한다. 버스도 카풀처럼 사람과 정원을 먼저 조율하며, 좌석 지정은 실제 버스와 맞는 도면이 있을 때만 사용한다.

차량 배정과 좌석 지정을 구분한다

방식이용 방법
차량별 배정기본 방식이다. 어느 버스를 타는지, 함께 타는 사람과 남은 정원을 보여 주며 임의의 자리 번호를 내세우지 않는다.
실제 좌석 지정운전석·통로·행과 열이 실제 버스와 일치하는 도면을 선택한다. 차량 배정은 유지하면서 세부 위치를 지정한다.
배정 주체최초 배정은 주최자·공동 주최자만 한다. 참가자의 본인 변경은 주최자가 모임 설정에서 허용한 경우에만 가능하다.
이동·정원 변경주최자가 정원과 사람의 다음 차량을 함께 정한다. 인원을 초과하거나 충돌하면 일부만 저장하지 않고 기존 배정을 유지한다.

요청·취소·종료

  • 자리 반납이나 개별 이동 희망은 주최자 조정 요청이다. 요청 제출만으로 현재 배정이 사라지지 않는다.
  • 버스 운행이 취소되면 승객은 배정 필요가 되고, 주최자가 다른 차량이나 개별 이동으로 조정한다.
  • 재배정 대상이 모두 정리되면 취소 묶음이 자동 종료된다. 모임부터 끝나면 미해결 인원을 그대로 보관하며 배정 완료로 바꾸지 않는다.
  • 모임 종료로 닫힌 의견은 주최자가 성공 처리한 요청과 구분한다. 종료된 모임에서는 배정을 바꿀 수 없다.
  • 차량별 명단은 참가자에게 공개하되 개인 승차 장소는 권한에 따라 제한한다.
플랫폼은 운송을 보증하지 않는다. 차량과 운송 준비는 모임 관계자가 진행한다. 플랫폼은 운전자의 면허·보험·차량 상태를 확인하거나 보증하지 않는다.

확인한 것과 남은 일

버스 일괄 배정·차량 이동·취소 후 재배정·지원 차량 교체를 실제 웹에서 확인했다. 추가 검사에서는 배정된 참가자의 개별 이동 요청 처리와 미해결 두 명을 남긴 모임 종료를 앱·관리자·서버에서 대조했다. 각 결과 화면을 연결했다.

남은 것은 휴대전화 화면·실제 푸시다. 좌석을 지정할 버스는 사용할 도면을 실차와 대조한다. 도면 확인 때문에 좌석 비지정 차량별 배정을 미구현으로 표시하지 않는다. 검수 순서와 완료 조건을 따른다.
