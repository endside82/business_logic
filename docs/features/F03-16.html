F03-16. 대절 버스와 자리 배정

호스트가 대절 버스를 등록하고 지정 또는 비지정 자리로 참가자를 배정한다. 호스트 전담과 참가자 자기 선택을 차량마다 정할 수 있다.

코드 완료표준 차량·운영 화면 완료실기기 검증 뒤 출시

자리 운영 방식

설정동작
지정 자리표준 배치도의 실제 좌석 번호와 위치를 사용한다.
비지정 자리정원만큼 자리 행을 만들어 누가 타는지 세되 자리 번호에는 의미를 두지 않는다.
호스트 전담호스트·공동 호스트만 참가자를 배정한다.
참가자 자기 선택참가자가 자기 빈자리를 고를 수 있고 호스트도 계속 배정할 수 있다.

완료한 보호 장치

  • 같은 자리에는 한 명만 성공하고, 이동 충돌 시 기존 자리 해제까지 롤백한다.
  • 한 사용자가 같은 모임의 두 차량 자리를 동시에 차지하지 못한다.
  • 호스트는 본인을 포함한 참석 자격자를 배정할 수 있다.
  • 타인 재배정·해제에는 사유·이력·알림이 필요하다.
  • 일반 참가자는 남의 이름을 볼 수 없고 점유 여부만 본다.
  • 참가 종료 때 자리를 회수하고, 신고가 남은 차량 삭제를 막는다.

출시 전에 남은 일

표준 배치도 9종과 관리자 화면은 완료됐다. 남은 것은 같은 출시후보의 서명 앱에서 두 참가자의 마지막 자리 경합, 자리 이동·호스트 재배정·반납, 역할 회수·앱 재시작, 실제 푸시와 자리 신고를 확인하는 일이다.
