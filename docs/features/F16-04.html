F16-04. 마일리지 정책 설정

클럽의 정책 담당자가 마일리지 제도의 시작·일시 중지, 점수 만료일과 랭킹 기준을 관리하는 화면이다. 정책을 바꾸기 전에 회원에게 미치는 영향도 확인한다. 이 화면과 서버 처리는 완료됐고 핵심 마일리지 출시 범위에 포함됐다.

현재 상태 — 클럽 운영 화면과 권한 검증 완료

미개설·운영 중·일시 중지의 세 상태와 변경 영향 확인이 실제 서버와 이어지는 화면 왕복을 마쳤다. 정책은 클럽의 정책 담당자만 바꿀 수 있으며, 플랫폼 시스템 관리자는 개별 클럽의 정책·적립·사용· 제안 승인을 대신하지 않는다.

제도 상태 = 마스터 스위치

제도가 운영 중이 아니면(미개설·일시 중지) 적립·차감·호스트 제안이 전부 막힌다. 등급·규칙·배지를 아무리 정성껏 만들어도 운영 중이 아니면 점수가 한 푼도 안 움직인다. 일시 중지 중에도 이미 받은 점수의 만료는 원래 날짜대로 진행된다. "마일리지가 안 쌓인다"는 문의의 첫 번째 점검 포인트가 바로 이 상태다.

만료일 변경

"향후 적립분에만 적용"

이미 쌓인 포인트의 만료일은 바뀌지 않는다는 점을 명확히 안내한다.

자동 적립 끄기

"향후 적립 중단, 기존 유지"

해당 자동 적립 규칙을 끄면 앞으로의 적립만 멈추고 기존 적립은 그대로 남는다.

등급별 회원 분포 추정

운영자가 알아야 할 것

일시 중지는 만료일을 미루지 않는다

일시 중지 중에는 새 적립·사용·호스트 제안이 막히지만 기존 점수는 안내된 날짜에 만료된다. 클럽이 중지와 재개를 반복해 만료일을 바꿀 수 없게 한 정책이다. 등급 기준을 바꾸면 기존 회원 등급도 자동으로 다시 계산한다. 일부 회원 처리에 실패하면 운영자가 처음부터 재실행할 수 있지만, 이 재실행은 앱 버튼이 아니라 운영 절차로 수행한다.
