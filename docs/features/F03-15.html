F03-15. 이벤트 카풀

참석자가 운전자로 지원하거나 탑승을 요청하고, 호스트가 운행을 승인한 뒤 탑승자를 배정하는 기능이다. 서버 상태기계와 참가자·운전자·호스트용 Flutter 화면, 안전 신고 진입, 배정 이력과 알림 발행까지 연결돼 있다. 다만 첫 출시에서는 이동수단 영역을 개통하지 않으므로 신규 지원·탑승·배정은 닫고, 기존 참여자의 운행 철회·카풀 이탈·안전 신고처럼 위험을 줄이는 출구만 유지한다.

카풀은 "누가 탈 수 있나"보다 "누가 누구 차에 배정됐나"가 중요하다. 운전자 지원, 호스트 확정, 참가자 배정, 배정 해제, 개별 이동 선택을 모두 분리해야 당일 혼선이 줄어든다.

2026-08-23 현재 — 코드는 닫혔지만 출시 개통은 별도 결정

운전자 지원·승인/반려·철회, 참가자 이동 선택·이탈, 호스트 배정·해제와 안전 신고가 실제 화면에서 서버로 이어진다. 서버는 참석 여부, 호스트 권한, 승인 상태, 좌석 정원, 차단 관계와 동시 변경을 검사하고 배정 변경 이력과 알림 의도를 같은 처리 안에 남긴다.

남은 일은 기능을 새로 만드는 것이 아니라 개통 조건을 증명하는 일이다. 호스트 본인 좌석 선택의 범위를 확정하고, 실제 역할별 계정과 기기에서 재배정·철회·알림·신고를 왕복한 뒤 이동 책임 고지를 승인해야 한다.

사용자 시나리오

운전자

참가자가 운전자로 지원

좌석 수와 픽업 가능 인원을 입력해 차량 제공을 신청한다. 호스트가 확정하기 전까지는 배정 대상 차량이 아니다.

호스트

운전자 확정 후 참가자 배정

호스트가 운전자를 확정한 뒤 참가자를 해당 차량에 배정한다. 픽업 가능 인원 초과 배정은 차단된다.

참가자

개별 이동 선택

카풀 요청 또는 개별 이동을 화면에서 고른다. 운전자 지원이 살아 있는 사용자는 탑승자로 동시에 등록할 수 없고, 이미 배정된 사용자는 먼저 카풀에서 나와야 선택을 바꿀 수 있다.

권한

참가자는 자기 정보만 본다

일반 참가자가 탑승자 목록을 조회하면 본인 항목만 보인다. 호스트는 전체 탑승자를 보며 운영한다.

방식 가드

카풀이 아닌 이벤트에서 진입

지원·결정·철회·신고·탑승 등록·배정 같은 변경 동작은 이벤트가 카풀 방식인지 확인한다. 첫 출시에서는 출시 범위 게이트가 신규 카풀 사용도 한 번 더 막는다.

초안 단계 전환

카풀 설정 후 버스로 바꿈

초안에서 이동수단 방식을 버스로 바꾸면 더 이상 유효하지 않은 카풀 데이터가 삭제된다. 공개 전 변경이므로 사용자에게 알림은 필요 없다.

서버 동작과 현재 Flutter 노출

동작누가무엇이 일어나는가
운전자 지원·철회참석자 본인화면에서 좌석 수·픽업 정보로 지원하고 철회한다. 이벤트당 활성 운행은 1건이며 철회 시 기존 배정도 안전하게 해제된다.
운행 승인·반려호스트·공동 호스트화면에서 대기 중인 운행만 결정한다. 오래 열린 화면의 늦은 결정을 버전 대조로 거절하고 다시 읽게 한다.
이동 선택·배정/해제참가자·호스트/공동 호스트참가자는 카풀 요청·개별 이동을 저장하고, 호스트는 승인된 차량의 남은 정원 안에서 배정·재배정·해제한다. 모든 변경은 이력으로 남는다.
운전자 안전 신고신고 대상이 아닌 참석자운전자 카드 길게 누르기로 신고 화면에 들어가며, 서버는 이벤트·운행·대상 운전자를 경로에서 확정해 플랫폼 신고 운영 흐름으로 보낸다.

운영자가 알아야 할 것

당일 혼선을 줄이는 제약
  • 확정된 운전자만 배정 대상이다. 지원만 한 운전자의 차량에는 참가자를 배정하지 않는다.
  • 픽업 가능 인원을 넘길 수 없다. 좌석 수와 픽업 가능 인원은 다를 수 있다.
  • 운행 결정과 배정 변경은 기록된다. 배정·재배정·해제 이력이 남고, 운행 승인·반려 및 배정·해제 알림은 영속 전송 대기열에 같은 처리로 기록된다.
  • 참석자와 운영자 화면을 분리한다. 참가자는 자기 이동 선택·운전자 지원·철회·이탈·신고를, 호스트는 운행 심사와 탑승자 배정을 처리한다.
  • 역할과 안전 조건을 서버가 다시 확인한다. 화면을 우회해도 참석 여부, 호스트 권한, 확정 차량, 정원, 차단 관계와 운전자·탑승자 역할 충돌을 거절한다.
  • 운영 중 종료 동작은 의도적으로 허용한다. 모집이 끝난 뒤에도 못 태우는 운행 철회와 위험한 카풀 이탈·신고를 막지 않는다.
  • 개통 전 실기기 검증이 남았다. 호스트·운전자·탑승자의 알림 이동, 재배정, 철회, 신고 종결과 책임 고지를 같은 출시후보에서 확인해야 한다.
