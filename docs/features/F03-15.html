카풀·개별 이동

참가자가 차량 지원을 제안하면 주최자가 인원과 경로를 조율한다. 먼저 누가 어느 차를 탈지 정하고, 실제 좌석 위치 지정은 필요한 경우에만 사용한다.

구현 있음웹 확인실제 환경 확인 대기

이동 조율의 책임 안내를 신청 양식에서도 보여 줍니다

이동 조율 화면뿐 아니라 차량 지원·버스 추가, 본인 차량·좌석 변경 양식에서도 참가자 사이의 조율임을 안내합니다. 플랫폼이 운전자 면허·보험·차량 상태를 확인하거나 보증한다는 뜻이 아닙니다. 현재 문구는 법무 승인 전 초안이며, 문구 승인과 휴대전화·실제 이동 검증은 별도로 남아 있습니다.

상황별 처리

상황사람과 차량의 변화
차량 지원 대기·수정·철회·미승인확정 전에는 기존 배정을 유지한다. 지원했다는 이유만으로 기존 차량에서 내리지 않는다.
지원 확정지원자가 운전자가 되고 원래 승객 배정은 해제된다. 동승 정원에는 운전자를 포함하지 않는다.
주최자 배정·해제주최자·공동 주최자가 확정 차량에 배정한다. 배정을 해제하면 배정 필요가 되며 개별 이동으로 바뀌지 않는다.
운행만 취소모임에 남는 전 운전자와 승객 모두 배정 필요가 된다. 자동 자차 복귀는 없다. 남은 사람을 모두 정리하면 재배정 묶음은 자동 종료되고 기록은 남는다.
지원 차량 교체주최자가 전 운전자와 기존 승객의 다음 차량을 함께 정한다. 새 운전자는 승객으로 중복 집계하지 않는다.
운전자의 모임 참가 취소운전자는 현재 참석 명단에서 빠지고 옛 차량은 종료된다. 모임에 남은 승객만 재배정 대상으로 남는다.
개별 이동 희망이미 배정돼 있으면 의견을 보내고 주최자 처리를 기다린다. 주최자가 개별 이동으로 처리한 뒤에만 차량 배정이 해제되며 모임 참가는 유지된다.

명단과 개인 정보

차량별 참가 명단은 공개한다. 개인 승차 장소는 본인·주최자·같은 차량 운전자에게만 보인다. 지원자를 교체하면 새 운전자에게 공개하고 전 운전자에게는 가린다. 다른 사람을 옮기거나 맞교환하려면 주최자에게 의견을 보낸다.

이동은 참가자 사이의 약속이다. 플랫폼은 운전자의 면허·보험·차량 안전을 확인하거나 보증하지 않는다. 차량 신고와 책임 안내는 계속 제공한다.

확인한 것과 남은 일

지원·운행 취소·재배정에 이어 배정 해제, 전 운전자까지 옮기는 교체, 운전자 참가 취소를 실제 웹·서버·데이터베이스에서 확인했다. 새 운전자·전 운전자·승객의 화면과 장소 공개 전환도 일치했다. 검수 결과와 화면을 볼 수 있다.

휴대전화와 실제 푸시는 미확인이다. 통과한 웹 행동을 중간에 반복하지 않고 남은 환경 확인을 진행한다. 첫 출시 범위는 유지하며 운영 배포 완료와 구분한다.
