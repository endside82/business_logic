F05-02. 자동완성 서제스트

자동완성의 두 대기 구간·후보·늦은 응답과 인기 모임 제목 태그를 구분한다. 2026-11-22 소스 대조이며 실제 앱 실행과 구분합니다.

결론

입력 중 자동완성은 카테고리와 공개 이벤트 제목을 제안한다. 입력이 없는 화면의 ‘인기 검색어’ 태그는 실제 검색 횟수 순위가 아니라 인기 모임의 제목이다. 두 목록은 근거·공개 조건·실패 처리가 다르다.

자동완성 입력과 선택

두 글자 이상에서 자동완성을 요청한다. 화면에서 300ms를 기다린 뒤 공급자가 다시 300ms를 기다리므로 현재 연결은 단일 300ms 지연이 아니다. 공급자는 새 검색어·짧은 입력·지움에서 요청 번호를 바꿔 늦은 응답을 버린다. 다만 화면의 첫 대기 구간까지 같은 보호가 적용된다고 단정하지 않는다.

앱은 최대 8개를 요청한다. 서버의 생략 기본값은 10개이며, 일치하는 카테고리를 최대 3개 먼저 넣고 나머지를 미래 시작의 공개 이벤트 제목으로 채운다. 제목 후보는 참여 인원과 번호 내림차순이다. 제한된 후보를 읽은 뒤 같은 제목을 합치므로 실제 결과가 요청 개수보다 적을 수 있다.

선택한 추천의 문구를 검색칸에 넣고 키워드 검색을 실행한다. 이벤트 번호가 함께 내려와도 추천 선택을 곧바로 이벤트 상세 이동으로 설명하지 않는다. 카테고리 추천도 그 문구로 검색하며 자동으로 카테고리 필터를 켜는 행동이 아니다.

인기 모임 제목 태그

검색 전 또는 검색칸에 포커스가 있고 입력이 비었을 때 인기 모임 제목 태그를 보여준다. 앱은 최대 10개를 요청한다. 서버는 인기 점수 목록에서 현재 공개 탐색 대상이고 종료 시각이 지나지 않은 이벤트를 골라 순위를 매긴다. 로그인 사용자의 차단한 호스트는 제외하며 제외 뒤 필요한 후보를 더 읽는다.

모임 제목을 누르면 그 제목으로 검색한다. 태그 목록은 검색어 기록·모든 회원의 검색 횟수·현재 지역의 인기 검색어 통계가 아니다. 결과가 없거나 조회에 실패하면 태그 영역을 숨긴다.

최근 검색어와 구분

최근 검색어는 계정별 기기 기록이다. 추천 결과를 받기만 해서는 검색 이력에 넣지 않고, 사용자가 문구를 선택해 검색을 실행할 때 기록한다. 추천 지움은 이미 저장한 최근 검색어 삭제와 다르다.

수용 기준과 검증 범위

  • AC-01 길이: 한 글자·빈 입력은 추천을 비우고 두 글자부터 요청한다.
  • AC-02 지연: 화면과 공급자의 대기 시간을 구분하고 연속 입력 중 이전 응답을 확인한다.
  • AC-03 후보: 카테고리 최대 3개가 먼저 오고 미래 공개 이벤트 제목으로 남은 자리를 채운다.
  • AC-04 개수: 앱 요청 8개·서버 기본 10개와 제목 중복 제거 뒤 더 적을 수 있는 결과를 구분한다.
  • AC-05 선택: 제안 문구로 검색하며 이벤트 상세 이동·카테고리 필터 자동 적용과 혼동하지 않는다.
  • AC-06 늦은 응답: 공급자의 새 입력·짧은 입력·지움 뒤 이전 요청 결과를 버린다.
  • AC-07 인기 태그: 공개 여부·종료 시각·로그인 차단 조건을 적용한 인기 모임 제목을 보여준다.
  • AC-08 공개 조건 차이: 자동완성·인기 태그·이벤트 결과에 적용되는 차단 조건을 각각 확인한다.
  • AC-09 실패: 자동완성·인기 태그 실패와 빈 결과가 현재 어떻게 숨겨지는지 명시한다.
  • AC-10 기록: 추천 조회만으로 최근 검색어를 만들지 않고 선택해 실행한 검색어만 기록한다.

기존 search_suggest_provider_test.dart는 늦은 응답·새 요청·짧은 입력·clear의 요청 번호 조건을 다룬다. 이번 작업에서 새 시험 실행이나 실제 키보드 검증을 수행한 것은 아니다.

이 기능의 출시 완료 기준

현재 제한과 확인 범위를 함께 판정한다. 아래 과거 판정 조건의 날짜를 이번 실행일로 바꾸지 않는다.

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 현재 공개 범위와 실행 확인은 출시 상태와 근거를 따릅니다. 위의 날짜별 기존 분류는 현재 운영 설정이나 검사 통과를 대신하지 않습니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 현재 입력에 맞는 제안어가 표시되고 선택하면 같은 검색어의 결과를 연다.
  • 빠른 입력·이전 응답·취소·한글 조합 중 다른 검색어의 제안이 섞이지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 검색의 관련 완료 기준도 함께 확인합니다.
