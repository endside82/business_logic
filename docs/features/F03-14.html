F03-14. 이동수단 공통 설정

호스트가 모임의 이동 운영, 참가자 자리 반납, 자차 허용 여부를 관리한다. 대절 버스·참가자 승용차·자차를 같은 모임에서 함께 쓸 수 있다.

코드 완료운영 화면 완료실기기 검증 뒤 출시

무엇이 달라졌나

종전의 “없음·카풀·버스 중 하나” 구조는 제거됐다. 이제 이동 운영을 켜고, 자리 반납과 자차를 허용할지만 각각 정한다. 살아 있는 차량이 있으면 운영을 끌 수 없어 기존 탑승자가 고립되지 않는다.

설정제품 효과
이동 운영차량 등록·자리 배정·승차 위치 조율 사용 여부
자리 반납 허용참가자가 자기 자리를 스스로 비울 수 있는지 결정
자차 허용참가자가 자차로 온다고 등록할 수 있는지 결정

완료한 시나리오

  • 설정이 없는 모임은 사용 안 함 기본값을 반환하며 조회만으로 데이터를 만들지 않는다.
  • 호스트·공동 호스트만 설정을 바꿀 수 있고 직접 API 호출도 같은 권한을 검사한다.
  • 살아 있는 차량이 있으면 이동 운영 종료를 거절한다.
  • 자차를 새로 만드는 것은 설정을 따르지만 기존 자차 종료는 봉인 중에도 허용한다.

출시 판단

기능 미구현 때문에 닫힌 것이 아니다. 고객 앱과 서버, 앱의 참가자 간 이동·무보증 책임 안내까지 완료됐다. 같은 출시 대상의 서명 앱에서 실제 호스트·참가자 설정 왕복과 알림·신고를 확인하고 책임 문구를 승인한 뒤 TRANSPORT를 연다.

대절 버스·카풀 통합 기능 완료 근거에서 전체 검증 결과와 출시 순서를 확인할 수 있다.
