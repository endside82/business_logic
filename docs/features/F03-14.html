이동수단 공통 설정

주최자가 카풀·버스를 함께 조율할지 정한다. 최초 배정은 주최자만 하며, 참가자의 본인 배정 변경은 주최자가 허용한 동안에만 가능하다.

구현 있음웹 확인실제 환경 확인 대기

주최자가 정하는 세 가지

설정이용 방법
이동 조율 사용전체 참가 명단을 보고 차량 지원을 받은 뒤 주최자·공동 주최자가 사람을 배정한다. 가는 편과 오는 편은 따로 나누지 않는다.
개별 이동 허용공동 차량을 타지 않고 각자 이동할 수 있다. 개별 이동은 차량이나 가상 좌석을 만드는 기능이 아니다.
참가자 본인 변경 허용기본은 꺼짐이다. 켜져 있어도 참가자는 본인 배정만 바꿀 수 있으며, 다른 사람의 이동과 맞교환은 주최자가 처리한다.

차량 지원자는 인원·경로를 제안할 뿐 모임의 배정 권한을 정하지 않는다. 차량별 명단은 참가자에게 공개하지만 개인 승차 장소는 본인·주최자·배정된 차량 운전자에게만 제공한다.

배정을 바꾸고 싶을 때

이미 배정된 참가자는 주최자에게 변경 의견을 보낸다. 자리 반납이나 개별 이동 희망도 요청이며, 요청만으로 현재 배정이 사라지지 않는다. 주최자가 처리한 뒤 결과와 사유를 확인한다.

공동 이동 조율에서 나가는 기능은 별도다. 배정은 비우되 모임 참가는 유지하며, 다시 조율에 참여하면 배정 필요로 시작한다.

확인한 것과 남은 일

첫 설정 저장, 주최자 최초 배정, 참가자 변경 기본 꺼짐과 허용 종료를 실제 웹·서버에서 확인했다. 배정 해제와 개별 이동 요청 처리도 추가 웹 검사 결과에 포함했다.

다음은 배포용 휴대전화와 실제 푸시 확인이다. 첫 출시 범위에 포함했지만 고객에게 공개하거나 운영 배포를 마친 상태는 아니다. 버스·카풀의 남은 확인과 완료 조건을 따른다.
