F04-12. 클럽 이벤트·캘린더

실제 상세 입구·무료 자동 참가 조건·공통 신청/결제·월/주 달력·통계 산식·반복 초안과 재전송을 구분한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

현재 범위와 실제 입구

현재 회원은 클럽의 모임 목록과 커뮤니티 캘린더에서 모임을 찾는다. 목록·달력의 모임 카드와 게시 알림은 공통 모임 상세로 이어진다. 알림에 모임 번호가 없고 클럽 번호만 있으면 클럽으로 이동한다. 운영진은 관리 화면의 모임 통계, 모임 목록의 반복 모임 버튼을 사용한다. 목록의 만들기는 서버가 제공한 만들기 권한에 따라 표시한다.

클럽 모임은 비공개 클럽 모임 초안으로 작성한다. 운영진의 생성·게시, 회원의 신청, 무료 모임 게시 시 자동 참가, 반복 회차 생성은 서로 다른 조건을 적용한다. 반복 생성은 템플릿과 회차 초안을 한 번에 만드는 기능이다. 이후 회차가 자동 게시되거나 정기적으로 무한 생성되는 기능으로 설명하지 않는다.

일반 모임과 공유하는 작성·생명주기·신청·정원·선입금·일정 변경 동의는 모임 작성, 모임 생명주기, 모임 신청과 참석, 정원과 대기열, 모임 선입금, 일정 변경 동의를 함께 따른다.

목록과 상세의 범위

  • 기본 목록은 숨김이 아닌 모집 중·종료 모임을 페이지 단위로 읽는다. 기본 정렬은 시작 시각 역순이며, 앱의 최근 게시 입구는 게시 시각 역순을 요청한다.
  • 앱은 전체·예정·진행·종료·초안 필터를 제공한다. 초안만 서버 상태 필터를 요청하며 나머지는 내려받은 페이지에서 시각·상태로 분류한다. 결정 대기 중인 모집 모임은 예정으로 취급한다. 초안 탭은 운영진에게만 보이고 권한을 잃으면 전체로 돌아간다.
  • 기본 목록에 취소 모임은 포함되지 않는다. 앱의 종료 판정에 취소 상태가 있다고 해서 이 목록에서 모든 취소 모임을 조회하는 것은 아니다. 필터 결과가 비어 있어도 아직 읽지 않은 페이지의 결과까지 없다고 단정할 수 없다.
  • 별도 예정 목록은 숨김이 아닌 모집 모임 중 미래에 시작하거나 결정 대기 중인 모임을 조회한다. 이 목록과 통계의 ‘예정’ 수치는 기준이 다르다.
  • 목록·달력에서 여는 실제 상세는 공통 모임 상세다. 클럽 전용 간략 상세 응답을 공통 상세의 본문·결제·권한 전체 계약으로 해석하지 않는다.

생성·수정·삭제와 본문 사진

일반 클럽 모임 생성은 현재 유효 운영진과 호스트 제재·구독 조건을 확인한다. 제목은 서버 기준 200자 이내, 정원은 1 이상이다. 날짜 결정이 보류된 경우를 제외하면 시작 시각이 미래이고 종료가 시작보다 뒤여야 한다. 서식 본문, 대표 이미지, 본문 사진, 첨부 장소를 해당 용도와 소유권 규칙에 따라 연결한다.

클럽 전용 수정은 초안에만 허용한다. 날짜 결정을 제거하면 확정 시작·종료 시각, 장소 결정을 제거하면 확정 주소가 필요하다. 수정 때 사진·장소와 선입금·환불 정책도 함께 갱신한다. 유료로 만들거나 전환하려면 활성 선입금과 양수 금액이 필요하며 가격과 선입금 금액이 일치해야 한다. 활성 결제가 있으면 결제 방식·계좌 변경에 제한이 있다.

초안 삭제는 클럽과 운영 권한을 확인한 뒤 공통 초안 삭제 처리를 사용한다. 게시한 모임을 취소하는 동작은 공통 취소·환불 처리로 이어진다. 취소 요청 성공만으로 모든 참가자의 실제 외부 환불이 완료됐다고 쓰지 않는다.

게시와 자동 참가

게시할 때 유효 운영진, 구독, 초안 상태와 선입금 공개 조건을 다시 확인한다. 무료이고 날짜·장소 결정 대기가 없는 클럽 모임만 자동 참가 대상이다. 회원 가입 순으로 기존 참석 행이 있는 회원과 신청 제한 회원을 건너뛰며 정원까지 참석자를 만든다. 정원을 넘는 회원에게 자동으로 대기 신청을 만들지는 않는다.

유료 모임과 결정 대기 모임은 이 자동 참가를 수행하지 않는다. 결정 대기가 없으면 호스트를 제외한 회원에게 게시 알림 확산을 요청한다. 이 요청은 모든 수신자의 알림 저장·푸시 수신 완료를 의미하지 않는다.

신청·대기·참석 취소

현재 목록의 신규 신청은 최신 공통 상세와 행동 가능 여부를 다시 읽고, 동반인·신청 메모 확인 및 일정 변경 동의를 거쳐 공통 신청으로 보낸다. 결과에 따라 참석·대기·승인 대기·결제 대기를 구분하며 결제가 필요하면 상세로 이어진다. 같은 행의 중복 조작은 진행 중에 막는다.

클럽 전용 직접 참석도 서버에 남아 있다. 현재 회원·활성 클럽·구독·신청 제한과 모임 상태를 검사하며, 유료·승인 필요·결정 대기 모임은 이 창구로 신청할 수 없다. 정원과 대기 설정에 따라 참석 또는 대기로 기록하고, 대기 한도를 넘으면 거절한다. 일정 변경 확인이 필요한 요청은 동의한 변경 묶음도 검사한다.

목록에서 이미 참석·대기 중인 회원은 무료 취소가 가능한 경우 클럽 전용 참석 취소를 사용하고, 다른 경우 상세로 이동한다. 취소 때 회원의 기존 상태를 바꾸고 연결된 동반인·신청·이동 조율을 정리한다. 참석자가 빠지면 정원 수와 다음 대기 승격, 대기 순서를 갱신한다. 참석 행을 단순 삭제하는 설명은 맞지 않는다. 참석자 목록은 참석 상태 행을 반환하며 대기자 전체 명단과 다르다.

캘린더 조회와 월·주 이동

구분현재 동작
조회 권한·범위현재 회원과 활성 클럽. 2020~2100년, 1~12월을 허용한다.
날짜 기준모임 시작 시각이 해당 월 시작 이상·다음 달 시작 미만인 모임을 읽는다. 기간이 겹치는 모든 모임 조회가 아니다.
표시 대상숨김이 아닌 모집 중·종료·취소 모임. 날짜 결정 투표가 아직 보류된 모임은 제외한다. 장소 결정 대기만으로 제외하지는 않는다.
반복 표시반복 회차의 부모 연결이 있으면 반복 모임으로 표시한다.
최초 빈 달현재 달이 비어 있으면 첫 목록 페이지 최대 50개에서 가장 이른 시작 월을 후보로 조회한다. 그 달에 표시할 모임이 있을 때만 이동한다. 전체 이력에서 가장 이른 달을 보장하지 않는다.
이전·다음 달선택 방향으로 최대 12개월까지 모임이 있는 달을 찾는다. 모두 비어 있으면 마지막 확인 월에 머문다. 항상 바로 옆 달만 여는 동작이 아니다.
주 보기일요일 시작 한 주를 사용하며 이전·다음은 7일씩 이동한다. 두 달에 걸친 주는 필요한 월을 함께 읽고 모임 번호로 중복을 제거한다.
복귀·실패월·선택 날짜·보기 방식·주 시작을 복원한다. 월별 캐시와 요청 순서를 관리하고, 읽기 실패에는 재시도를 제공한다.

월 보기에서는 선택 날짜의 모임 또는 월 전체 모임을 읽는다. 선택 날짜에 없는 경우와 월 전체가 빈 경우의 안내를 구분한다. 카드에서 공통 상세로 이동한 뒤 기존 달력 위치로 돌아온다.

운영진 통계의 집계 기준

통계는 유효 운영진만 조회한다. 전체·종료·취소·모집 중 모임 수와 이번 달·지난 달 수, 종료 모임의 참석자 수·고유 참석자 수·참석률, 최근 6개월 집계를 제공한다. 통계 화면은 새로고침·오류 재시도를 제공하며 사용자가 기간을 고르는 필터는 없다.

  • 전체 수와 월별 모임 수는 초안·숨김을 제외하는 필터가 없다. 달력에 보이는 모임 수와 일치할 필요가 없다.
  • ‘예정’ 값은 시작 시각이 미래인 건수가 아니라 모집 중 상태의 건수다.
  • 참석자 수는 종료 모임의 참석 상태 기록을 센다. 체크인 완료나 현장 출석 실측 수가 아니다.
  • 참석률은 종료 모임 참석 기록 합계를 종료 모임 정원 합계로 나눈 비율이다. 개별 모임 참석률의 단순 평균이 아니며, 정원 합계가 0이면 0이다.
  • 앱의 ‘모임당 평균 참석’은 종료 모임 참석자 합계를 전체 모임 수로 나눈다. 종료 모임 수를 분모로 쓰는 값과 다르다.
  • 최근 6개월은 이번 달을 포함한다. 월별 모임 수는 시작 월 기준이며, 월별 참석·참석률은 숨김을 포함한 종료 모임을 대상으로 한다.

반복 템플릿과 회차 초안

운영진은 매주·격주·매월 방식으로 회차를 만든다. 주 단위는 요일을 선택하고 중복 요일을 제거한 날짜 순서로 생성한다. 월 단위는 지정 일 또는 말일을 사용하며, 31일처럼 해당 월에 없는 날짜는 그 달 말일로 맞춘다. 시작일 전과 이미 지난 시작 시각은 건너뛴다. 종료일을 지정한 서버 요청에서는 그 날짜를 포함한다.

명시한 회차 수는 1~52회다. 서버는 회차 수와 종료일이 둘 다 없으면 12회로 처리하고, 종료일만 있는 장기 요청도 생성은 최대 100회·탐색은 최대 101주기까지만 한다. 실제 결과 수는 조건에 따라 요청 수보다 적을 수 있으며, 만들 회차가 하나도 없으면 템플릿 저장 전에 거절한다.

템플릿과 각 회차는 초안이다. 유료라면 양수·100원 단위의 가격과 선입금 금액이 같아야 하며 템플릿과 각 회차에 선입금·환불 정책을 연결한다. 사진도 회차에 연결한다. 생성에서 확인하는 운영 권한·호스트 제재와, 각 회차 게시 때 확인하는 구독 조건은 구분한다.

현재 앱 폼은 반복 종류·요일 또는 월 일자·시작일·시작/종료 시각·회차 수·장소·정원·본문/사진·선입금을 받는다. 종료일을 지정하는 입력은 없다. 기본 회차 수는 12다. 목록의 예정 회차 수는 미래 시작인 모집 중 또는 초안 회차 수다.

반복 생성 명령은 전송한 본문과 요청 키를 세션의 Provider 상태에 보관한다. 결과가 불명확하면 같은 본문·키로 재전송하며, 성공 또는 이미 처리됐으나 응답을 재구성할 수 없는 결과는 목록을 다시 읽는다. 이 상태는 기기 디스크에 보존하는 작성 초안과 다르다. 실제 생성 수는 서버 결과와 갱신한 목록으로 판단한다.

상태와 권한

사용자·조건가능한 결과와 제한
현재 회원·활성 클럽기본 목록·캘린더, 조건에 맞는 모임 신청·무료 취소
현재 회원·일반 회원반복 템플릿 서버 조회는 가능하지만 앱의 반복 화면과 통계 경로는 운영진용이다
유효 운영진초안 생성·수정·삭제·게시, 모임 취소, 반복 생성, 통계 조회. 동작별 제재·구독·상태 조건을 따름
무료·결정 완료 모임 게시기존 참석 행·신청 제한을 제외하고 정원까지 자동 참가
유료 또는 결정 대기 모임 게시자동 참가 없음. 결정 대기 중에는 이 게시 알림 확산도 보류
정원 초과직접 신청은 허용된 대기 한도 내 대기 가능. 자동 참가는 초과 회원을 대기로 만들지 않음

현재 제한과 확인 범위

분류확인한 경계영향과 다음 확인
