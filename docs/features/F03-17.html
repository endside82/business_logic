F03-17. 차량 좌석 배치도 운영

운영자가 표준 차량 좌석표를 준비하고, 호스트가 활성 배치도를 골라 지정 자리 차량을 만드는 기능이다.

코드 완료관리자 화면 완료표준 차량 9종

현재 제공하는 운영 기능

업무현재 지원
표준 차량 조회25·28·41·45인승 버스와 7·9·11·12·15인승 승합차
좌석표 확인행·열, 좌석 번호, 일반석·기사석·통로, 선택 가능 여부
배치도 복제좌석표를 복사한 비활성 배치도 생성
이름·설명 수정운영상 구분 정보 수정
사용 시작·중지선택 가능한 좌석이 있을 때만 활성화

서버가 막는 잘못된 상태

  • 통로·기사석뿐인 배치도 활성화
  • 좌석 번호·좌표 중복과 좌석 수 불일치
  • 통로를 선택 가능한 좌석으로 등록
  • 이미 차량이 사용하는 배치도의 좌석표 변경
  • 같은 이름의 배치도 중복 생성

이번 출시 범위가 아닌 것

표준 9종 외 차량의 좌석 위치를 웹에서 직접 그리는 편집기와 참고용 차량 사진은 별도 제품 확장이다. 현재 대절 버스·카풀을 쓰는 데 필요한 조건이 아니며, 이 때문에 기능을 봉인한 것도 아니다.

출시 판단: 차량 배치도에는 추가 구현이 없다. 관리자 화면→호스트 차량 등록→참가자 자리 선택을 서명 앱과 실제 계정으로 확인하면 된다.
