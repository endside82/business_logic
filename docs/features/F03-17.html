차량 좌석 배치도 운영

운영자가 도면의 출처·좌표·실물 대조 결과를 관리하고, 주최자는 실제 이용 차량과 맞는 도면을 골라 좌석을 지정한다. 도면 후보가 있다는 사실과 실제 사용 승인은 다르다.

구현 있음웹 확인실제 환경 확인 대기

운영자가 준비하고 주최자가 사용한다

업무현재 동작
출처·실물 대조차종·연식·인승 사양과 자료 출처를 확인한다. 제조사 도면 후보 4종은 준비 자료이며 실제 차량 대조·사용 승인을 마친 도면이 아니다.
좌표 편집운전석·승객석·통로·빈 위치를 구분하고 행·열 좌표를 반영한다. 운전석과 통로는 승객이 선택할 수 없다.
복제·수정사용 중인 도면을 덮어쓰지 않는다. 복제본은 미확인·비활성으로 시작하고 좌표와 확인 결과를 따로 관리한다.
사용 시작미확인 도면을 운영용으로 활성화하지 않는다. 사용할 실차와 앞쪽 방향·운전석·통로·좌석 위치·승객 정원을 대조한다.
주최자의 도면 변경탑승 명단을 유지하면서 도면을 바꾼다. 기존 좌석 번호를 다른 도면에 자동 배정하지 않으며 세부 좌석은 나중에 지정할 수 있다.
변경 기록 조회주최자가 적은 사유, 전환 전후 도면·배정·좌석 정보를 남기며 관리자는 같은 기록을 조회한다.

실제로 확인한 범위

합성 시험 도면으로 카풀·버스의 배정 방식 전환, 허용된 참가자의 본인 좌석 이동, 관리자 웹의 복제·좌표 편집·사용 시작을 확인했다.

추가 검사에서 다른 버스 도면으로 바꿔도 승객과 배정 식별자는 유지됐고 세부 좌석만 미지정으로 바뀌었다. 변경 사유 ‘시험 버스 좌석 배치 변경’은 저장 전 입력·서버 기록·관리자 표시에서 일치했다. 입력 화면과 관리자 결과를 볼 수 있다.

실제 사용 전에 남은 일

사용할 도면만 실차와 대조하고 배포용 휴대전화에서 좌석표 스크롤·선택을 확인한다. 합성 도면의 저장 성공을 실제 차량 확인으로 세지 않는다. 맞는 도면이 없으면 좌석을 지정하지 않고 차량별 인원 배정을 사용한다.

새 편집기를 만드는 일이 아니라 이미 있는 도면 관리 기능으로 실제 자료를 확인하는 단계다. 차량 조율의 남은 확인과 완료 조건을 따른다.
