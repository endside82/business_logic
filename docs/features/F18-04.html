F18-04. 분쟁 증빙·공개범위·보존

분쟁 케이스에 첨부된 증빙 파일이 누구에게 보이고, 언제까지 보존되며, 언제 삭제되는지를 결정하는 정책 레이어. 공개범위는 운영팀 전용·분쟁 당사자 공개·호스트 공개·요약 공개 네 등급으로 설계되어 있으나, 운영팀 전용 진행 이력은 가리고 증빙은 본인이 제출한 파일에 한해 본인 열람을 허용한다. 다른 사람이 제출한 운영 전용 증빙은 숨긴다. 나머지 세부 등급 구분은 아직 완성 범위가 아니다. 증빙 참조 등록부에 연결된 파일은 사용자가 일반 파일 삭제 API를 호출해도 삭제되지 않는다. 정책상 종결 후 1년을 보존하지만, 자동 파기 시계가 연결된 유형과 아직 연결되지 않은 유형은 구분해야 한다. 진행 중인 케이스에 연관된 사용자는 계정 삭제도 차단된다.

분쟁이 진행 중인 동안에는 계정 삭제와 개인정보 익명화 자체가 차단된다. 운영 이슈·클럽 신고·공개 신고·카풀·데이트 안전신고의 신고자, 플랜 마켓 환불 분쟁의 판매자, 클럽 경고 이의의 당사자, 모임 정산 이의의 호스트, 강퇴·차단 처분의 대상 멤버, 이용자 간 분쟁의 신고자·피신고자 양측 중 하나로 진행 중인 케이스에 연관되어 있으면, 그 케이스가 종결될 때까지 계정을 삭제할 수 없다. 이 판정은 자동으로 이루어지며 사용자에게도 알려져야 한다.

현재 동작은 사건에 접근할 수 있는 사용자의 증빙 목록과 다운로드 자격을 같은 기준으로 확인한다. 운영 전용 증빙이라도 제출자 본인은 볼 수 있고, 상대 당사자나 처리자에게는 이 예외를 적용하지 않는다. 다른 등급의 세부 구분까지 완성됐다고 보지 않는다. 목록에 허용된 파일만 사건 안에서 다운로드할 수 있으며 파일의 미완료·폐기·검사 미통과 상태도 거절한다.

진행 중인 케이스(접수됨·검토 중·상위 이관)에 연관된 사용자는 계정 삭제 요청이 차단된다. 다만 차단 판정이 일부 역할을 놓칠 수 있어, 모임 정산 이의를 낸 사람이 호스트가 아닌 경우와 플랜 마켓 환불 분쟁의 구매자 측은 차단이 잡히지 않을 수 있다(후속 개선 과제). 케이스가 전부 종결(처리 완료·종결)되면 차단이 해제된다.

사용자 시나리오

증빙 조회

케이스 상세에서 증빙 확인

참가자가 케이스 상세를 열면 자신이 볼 수 있는 증빙 목록이 나타난다. 현재는 본인이 제출한 증빙과 사건에서 열람이 허용된 증빙만 확인한다. 다른 사람이 제출한 운영 전용 증빙은 목록·다운로드 모두 거절한다. 당사자·호스트·요약 등급 사이의 세부 구분은 별도 범위이며 모든 등급 처리를 완료했다고 표시하지 않는다.

이 흐름이 남기는 것 — 본인은 제출한 증빙을 다시 확인할 수 있고 상대방의 비공개 증빙이나 운영 내부 메모를 임의로 볼 수 없다.

증빙 보존

진행 중인 케이스의 증빙 — 삭제 불가

케이스가 접수됨·검토 중·상위 이관 상태이면 "증빙 보존 중" 안내 배너가 표시된다. 분쟁 화면에는 삭제 버튼이 없고, 별도 일반 파일 삭제 API를 직접 호출해도 증빙 참조 등록부가 파일을 확인해 삭제를 거절한다. 이 방어는 2026-08-26 기준 18개 증빙 참조 표면에 적용됐다.

계정 삭제 차단

분쟁 중에 계정 삭제 시도

진행 중인 케이스에 연관된 상태에서 계정 삭제를 요청하면 차단된다. 케이스가 모두 종결될 때까지 계정을 삭제할 수 없다는 안내가 필요하다. 이 판정은 자동으로 이루어진다.

이 흐름이 남기는 것 — 분쟁 중 증거를 은닉하거나 책임을 회피하기 위한 계정 삭제를 막는다.

증빙 제출

이의제기 시 파일 첨부

이의제기(F18-03) 시 최대 5개 파일을 함께 제출할 수 있다. 본인 소유 파일만 첨부 가능하고, 이미 다른 케이스에 사용 중이거나 삭제된 파일은 서버가 차단한다. 분쟁 직접 접수(F18-02)에서도 2026-06-06 구현을 확인했으며 최대 5개 파일을 함께 제출할 수 있다.

자동 정리

오래된 종결 케이스 증빙 정리

케이스가 처리 완료 또는 종결된 뒤 1년이 지나면 매일 05:00에 증빙 파일이 자동으로 삭제된다. 파일 일부가 삭제 실패하면 해당 파일만 다음 날 재시도한다 — 케이스 기록 자체는 삭제되지 않는다. 다만 아래 표처럼 모든 증빙 유형이 이 파기 시계를 가진 것은 아니며, 다중 참조 파일과 커밋 경계도 후속 보강 대상이다.

운영자가 알아야 할 것

운영 주의사항
  • 플랜 마켓 환불 분쟁 증빙이 자동 정리되지 않는다. 파일 구조가 달라 자동 정리 대상에서 제외됐다. 이 분쟁의 오래된 증빙 파일은 별도 정리가 필요하다.
  • 계정 삭제가 차단될 때 사용자 안내가 필요하다. "왜 계정 삭제가 안 되는지" 앱이 설명하지 못하면 고객 문의가 집중될 수 있다.
  • 사용자 임의 삭제 방어는 완료됐다. 일반 파일 삭제 API도 증빙 참조가 남아 있으면 거절한다. 남은 문제는 사용자 삭제 버튼이 아니라 파기 배치의 트랜잭션 경계와 한 파일의 다중 참조 처리다.
  • 분쟁 직접 접수의 증빙 첨부를 구현했다 (2026-06-06 확인). 분쟁 직접 접수(F18-02) 화면에서 최대 5개 증빙을 함께 제출할 수 있다. 다만 플랜 마켓 환불 분쟁(F08-14) 접수는 서버 계약 한계로 아직 첨부할 수 없어 서버 후속 작업이 필요하다.

레드 플래그

현재 알려진 미구현·주의 사항
  • 통합 분쟁 접수 증빙 첨부 구현 완료 (2026-06-06 확인). 통합 분쟁 접수 화면에서 최대 5개 증빙을 함께 제출할 수 있다. 다만 플랜 마켓 환불 분쟁 접수 화면은 서버 계약 한계로 아직 첨부할 수 없어 서버 후속 작업이 필요하다.
  • 플랜 마켓 환불 분쟁 증빙은 자동 정리되지 않는다. 이 분쟁의 오래된 증빙 파일이 영구적으로 남는다. 별도 정리 방안이 필요하다.
  • 사용자 임의 삭제 방어는 완료됐다. 18개 증빙 참조 표면이 등록부에 연결되어 일반 파일 삭제 요청을 막는다. 남은 위험은 파기 중간 실패와 다중 참조 파일의 마지막 보존기간 계산이다.

이 기능의 출시 완료 기준

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 역할별 증빙 열람·실제 파일 다운로드·보존/삭제가 현재 지원하는 공개 등급에 맞는다.
  • 운영 전용·제출자 소유·제3자·만료/종결·보존 예외를 확인한다. 설계만 있는 세부 등급을 제공 완료로 세지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 분쟁 해결의 관련 완료 기준도 함께 확인합니다.
