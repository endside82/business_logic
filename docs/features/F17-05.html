F17-05. 회차 관리 (추가·자동생성·일괄·대체·취소)

회차 데이터는 일반 이벤트 위에 만들어진다. 상세의 회차 카드를 누르면 그 회차로 들어갈 수 있지만, 회차를 고치는 일은 정기모임 화면에서만 되고 일반 이벤트 운영 화면에서의 직접 수정은 막혀 있다. 다섯 가지 운영 동작이 있다 — 한 회차 추가, 반복 자동생성, 여러 회차 일괄 추가, 취소된 회차의 대체본 추가, 회차 취소. 이 가운데 호스트 화면에 없는 것은 회차 목록을 자유롭게 한 번에 편집하는 일괄 추가뿐이다.

설계 의도 — 회차는 정기모임만의 영역

회차도 결국 이벤트의 한 형태라 일반 이벤트 화면을 재사용할 여지는 있지만, 일반 이벤트 운영 경로로 회차를 수정하면 모임 본체와 정합성이 깨진다. 그래서 호스트는 정기모임 화면에서만 회차를 손볼 수 있고, 일반 이벤트의 게시/취소/정원 변경 같은 경로는 명시적으로 차단되어 있다.

사용자 시나리오

한 회차 추가

8회 코스의 다음 회차 한 건

호스트가 회차 추가 화면에서 제목·설명·시작/종료 시각을 입력한다. 순번은 자동으로 다음 번호가 붙는다. 고정형은 정원을 본체에서 상속하지만 가격은 코스 전체 결제이므로 세션에 항상 0원으로 저장된다.

이 흐름이 남기는 것 — 고정형 회차에서 이중 과금을 막고 코스 정원만 일관되게 상속.

반복 자동생성

첫 회차를 기준으로 최대 26회 생성

앱에서 매일·매주·격주·매월 중 주기와 생성 횟수(1~26)를 고른다. 서버가 첫 회차 길이를 유지해 제한된 회차 목록으로 확장한 뒤 bulk 생성 경로를 재사용한다.

이 흐름이 남기는 것 — 임의 bulk 편집 화면 없이도 가장 흔한 반복 패턴은 앱에서 바로 만든다.

변동형 회차 추가

매번 다른 정원·가격

변동형 회차는 회차마다 정원·가격을 따로 입력한다. 유료면 환불 정책과 결제기한도 고르며, 서버는 가격을 100원 단위로 절삭하고 CASH 사전결제를 만든다.

이 흐름이 남기는 것 — 변동형 모임의 핵심 자유도. 본체는 공통 정책만, 회차는 자유 운영.

회차 취소

호스트가 회차 카드에서 바로 취소한다

정기모임 상세의 회차 카드에 호스트 전용 "회차 관리" 메뉴가 있고 그 안에서 취소한다 (2026-08-13 반영 — 종전 "앱 카드에 취소 액션 없음" 서술은 해소). 누르면 회차 번호와 함께 취소의 금전 영향을 알리는 확인 창이 먼저 뜬다 — 고정형은 "이 회차만 취소하고 멤버와 출석 기록은 보존된다", 변동형 유료 회차는 "신청자 환불을 시작한다"로 문구가 갈린다. 취소할 수 있는 것은 모임이 초안이거나 모집 중이고 회차가 아직 살아 있을 때뿐이다.

이 흐름이 남기는 것 — 고정형 코스 멤버십은 회차 취소로 흔들리지 않는다. 변동형 유료 회차라면 참가자에게 취소 알림이 가고 결제분이 환불되며, 실패분은 운영 추적 대상으로 남는다.

대체본 추가

취소된 회차를 같은 순번의 대체 회차로 다시 연다

취소된 회차를 고르면 같은 순번의 대체 회차를 만들고 원본 참조를 보존한다. 호스트 화면도 회차 추가 화면이 대체 모드로 동작해 제공된다(2026-08-18 확인 — 종전 "앱 화면 없음" 서술은 해소). 대체 사실은 참가자에게 알림으로도 나간다.

이 흐름이 남기는 것 — 원본과 대체를 한 순번으로 묶어 두어, 출석·정산이 회차를 잃지 않는다.

회차 카드에서 할 수 있는 것

카드를 누르면 그 회차로 들어가고, 호스트는 메뉴로 운영한다

회차 카드를 누르면 그 회차의 모임 상세로 이동한다(2026-08-13 반영 — 종전 "읽기 전용" 서술은 해소). 취소된 회차를 눌렀을 때 같은 순번의 대체 회차가 있으면 그쪽으로 보낸다 — 사용자가 실제로 가야 할 날짜는 대체본이기 때문이다. 호스트에게는 같은 카드에 출석 확정·대체 회차 만들기·회차 취소 세 가지가 조건에 따라 메뉴로 열린다.

남은 공백 — 회차로 들어간 뒤의 모임 상세 화면에는 "정기모임 몇 회차인지"를 알려 주는 표기가 아직 없다. 서버는 순번과 모임 이름을 함께 내려주지만 화면이 읽지 않는다. 호스트에게만 "정기모임에서 회차 관리" 버튼이 보여 문맥을 되찾을 수 있고, 일반 참가자에게는 단서가 없다.

화면에서 사용자가 인지하는 것

영역사용자가 보는 것그 자리에 둔 이유
회차 순번"1회차·2회차·3회차" 같은 표기가 모든 회차 카드 상단에 노출.코스에서 자기 위치를 사용자가 직관적으로 인지하게 한다.
대체 회차 이력같은 순번의 취소 원본과 활성 대체 회차가 함께 보존된다. 기본 목록은 취소 원본을 숨기고, 호스트 상세는 이력을 포함해 불러온다.원본과 대체를 한자리에서 확인할 수 있다(2026-08-18 확인 — 종전 "이력 화면 없음" 서술은 해소).
변동형 정원·가격회차 카드마다 다른 값으로 노출.변동형의 자유도가 카드 단계에서 노출되어야 사용자가 "이번 달은 가격이 다르네"를 인지.
취소 회차 노출목록은 기본적으로 활성 회차만 보여 주고, 호스트 상세는 취소 원본까지 포함해 불러온다.참가자는 살아 있는 회차만 보고 호스트는 이력을 함께 본다(2026-08-18 확인 — 종전 "후속 배선" 서술은 해소).
일반 이벤트 운영 차단호스트가 일반 이벤트 화면에서 회차 운영 버튼을 눌러도 거절.운영 경로 분리로 모임 본체와 회차 정합성 보호.

운영자가 알아야 할 것

회차 운영 규칙
  • 고정형 회차 취소 시 멤버 본체는 그대로 — 자동 참석 명단만 갱신. 다른 회차에는 그대로 참여.
  • 변동형은 회차마다 정원·가격이 독립적 — 회차별로 다른 가격을 받을 수 있다.
  • 1~99원은 절삭 후 무료가 된다 — 서버가 100원 단위로 내림하므로 유료로 보이게 입력해도 사전결제가 생성되지 않는다.
  • 회차 시간 겹침 자동 검출 없음 — 호스트가 같은 시간대에 두 회차를 만들 수 있음. 1차는 호스트 자율.
  • 회차를 새로 추가하면 참가자에게 알림이 간다(2026-08-26 반영 — 종전 "알림 종류 자체가 없다" 서술은 해소) — 고정형은 참여 중인 멤버에게, 변동형은 기존 회차 참석자에게 보낸다. 한 번에 여러 회차를 만들어도 알림은 한 건만 나가고, 호스트가 하루에 여러 번 회차를 더해도 푸시에는 발송 빈도 상한이 걸린다. 취소된 회차를 대신하는 대체 회차 알림과는 따로 둔다 — 대체는 "가려던 날이 옮겨졌다"는 통지이고 추가는 "없던 날이 생겼다"는 통지라, 읽고 나서 하는 행동과 사용자가 켜고 끄는 단위가 다르다.
  • 일반 이벤트 운영 화면 우회 차단 — 회차에 대한 모든 변경은 정기모임 화면에서만 가능.

가격과 환불의 실제 경계

세션 이벤트는 정기모임 본체의 안전한 파일 키를 상속한다. 단건/대체 생성 응답은 새 표시 URL로 바꾸지만, 정기모임 상세의 회차 요약 객체 자체에는 별도 썸네일 필드가 없다.

레드 플래그

자주 발생하는 케이스
  • 임의 일괄 편집 화면은 1차 미신설 — 단건 추가와 반복 자동생성은 앱에서 되고, 대체 회차도 회차 카드 메뉴에서 만든다. 회차 목록을 자유롭게 한 번에 편집하는 화면만 후속으로 빠졌다.
  • 회차 시간 겹침 미검증 — 호스트가 실수로 같은 시간에 두 회차를 만들 수 있음.
  • 1~99원 유료 오인 — 100원 절삭 뒤 0원이 되지만 앱이 최소 유료 금액을 별도로 안내하지 않는다.
  • 회차로 들어가면 몇 회차인지 알 수 없다 — 카드에서 회차로 이동하는 길은 열렸지만, 도착한 모임 상세 화면이 정기모임 순번을 표시하지 않아 참가자가 문맥을 잃는다.
