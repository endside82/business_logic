게시글·모임 투표

게시글에서 회원 의견을 모으거나, 모임 참가자에게 질문한다. 무료 클럽 모임은 일정이나 장소를 투표로 정할 수도 있다. 이 경우 선택한 후보가 확정되면 참가자로 자동 등록된다.

첫 출시 포함 · 실제 배포 전

세 가지 투표의 서버 처리와 앱 화면이 로컬 기본 브랜치에 반영됐다. 관리자 서버의 데이터베이스 설치 정의도 맞췄다. 두 서버의 운영 기본 설정에 세 종류 투표를 포함했다.

임시저장한 결정 투표의 후보·마감 수정과 투표 없이 진행을 앱에서 제공한다. 저장 실패 재시도·권한 변경·잘못된 직접 링크를 검사했다. 실제 휴대전화 이용 확인과 운영 배포는 남아 있다. 다음 할 일은 투표 기능의 공개 준비에서 확인한다.

어떤 투표를 쓰는가

종류만들고 관리하는 사람투표할 사람과 결과
게시글 투표게시판에 글을 쓸 권한이 있는 회원이 첨부한다. 글 작성자와 유효한 클럽 운영진이 관리한다.글을 볼 수 있는 현재 클럽 회원이 의견을 낸다. 모임 참가 여부는 바뀌지 않는다. 게시글당 최대 5개다.
모임 참가자 투표주최자 또는 공지 발송 권한이 있는 공동주최자가 만든다.실제로 참석 확정된 사람이 투표한다. 대기자와 비회원 동반자는 투표할 수 없다. 진행 중인 투표는 모임당 최대 5개다.
일정·장소 결정 투표주최자가 무료 클럽 모임을 만들 때 일정 또는 장소 중 하나를 고른다. 주최자·유효한 공동주최자·클럽 운영진이 후보를 관리하고 확정한다.주최자를 제외한 현재 클럽 회원이 투표한다. 확정된 후보를 고른 사람 중 참가 자격을 유지한 회원이 참가자로 바뀐다.

역할 제한을 받은 운영진과 공동주최자는 정지된 운영 권한을 쓸 수 없다. 상세한 범위는 역할 제한이 적용되는 권한을 따른다.

투표하고 고치는 규칙

  • 선택지 2~10개를 둔다. 질문은 100자, 선택지 이름은 80자까지다. 여러 항목 선택과 익명 여부를 만들 때 정한다.
  • 참여자는 마감 전에 선택을 바꾸거나 모두 취소할 수 있다. 결과는 투표 전에도 보인다. 복수 선택의 비율은 참여한 사람 수를 기준으로 하므로 합계가 100%를 넘을 수 있다.
  • 표가 남아 있으면 질문·기존 선택지·익명 여부·복수 선택 설정을 바꾸거나 투표를 삭제할 수 없다. 선택지 추가와 허용 기간 안의 마감 연장만 가능하다.
  • 일반 투표는 마감일을 생략하고 관리자가 직접 마감할 수 있다. 만들 때 마감일을 정한다면 생성 시점에서 최소 1시간 뒤, 최대 30일 안이어야 한다. 예약 게시글은 예약 공개 시각을 기준으로 계산하며, 나중에 연장해도 최초 기준의 30일을 넘기지 않는다.
  • 임시저장 모임이나 예약 게시글의 투표는 부모 글·모임이 공개된 뒤에 시작한다. 모임 취소 후에는 새 표를 받지 않는다.
  • 익명 투표에서는 주최자와 운영진도 선택지별 참여자 명단을 볼 수 없다. 익명이 아니면 투표를 볼 수 있는 사람이 해당 명단을 열람할 수 있다.

투표로 일정이나 장소를 정하는 모임

발행 전 수정: 임시저장 모임 상세의 ‘후보·마감 수정’에서 내용을 고친다. 클럽 운영 권한도 있는 주최자는 ‘투표 없이 진행’에서 사용할 후보를 직접 고를 수 있다. 선택한 일정·장소 저장과 투표 제거는 함께 처리하며 모임은 임시저장 상태로 남는다. 새 일정·장소를 쓰려면 후보를 먼저 수정한다. 공동주최자의 투표 편집 권한만으로는 투표 제거를 허용하지 않는다.

  1. 주최자가 무료 클럽 모임에서 일정 또는 장소 후보 2~10개를 입력한다. 유료 모임·독립 모임·정기모임에는 적용하지 않는다. 일정과 장소를 동시에 투표로 정하지 않는다.
  2. 모임을 공개하면 클럽 회원에게 투표 시작을 알린다. 확정 전에는 일반 참가 신청을 받지 않고 ‘투표하기’로 안내한다.
  3. 마감 때 1표 이상 받은 단독 1위가 있고 시작까지 1시간 이상 남았다면 자동 확정한다. 주최 측은 허용된 후보를 직접 골라 확정할 수도 있다.
  4. 동률·표 없음이면 자동 취소하지 않고 주최자와 공동주최자에게 후보 선택을 요청한다. 후보가 모두 지나면 주최자가 모임을 취소해야 한다.
  5. 확정 시 주최자와 선택된 후보의 투표자를 참가자로 등록한다. 탈퇴·참가 제한·참가 이탈 기록이 있는 사람 등은 제외한다. 필요하면 정원을 늘리며 대기자로 돌리지 않는다.

투표 마감은 가장 이른 후보 시작보다 최소 2시간 전이어야 한다. 확정 후 다른 후보로 바꾸는 것은 현재 모임 시작 3시간 전까지만 가능하며, 다른 일정 변경 동의 절차나 체크인이 진행된 경우에는 제한된다.

후보를 다시 확정해도 기존 참가자는 유지한다. 새 후보를 고른 회원은 자격을 확인해 추가하지만, 이미 참가를 취소한 회원을 강제로 다시 넣지 않는다. 후보 밖 일정으로 옮기려면 일반 일정 변경 절차를 이용한다.

회원에게 먼저 알려야 할 것

  • 투표가 참가로 이어진다. 익명으로 투표했어도 확정 뒤 참가자 명단에서는 이름이 보일 수 있다. ‘누구에게도 참여 사실이 공개되지 않는다’고 안내하면 안 된다.
  • 익명 결정 투표에서는 운영자가 개별 투표자를 골라 자동 참가에서 제외할 수 없다. 회원 탈퇴·참가 제한 같은 공통 자격 검사는 그대로 적용한다.
  • 확정 전 일정은 개인 일정과 일정 파일 내보내기에 넣지 않는다. 클럽 달력에서는 날짜를 정하는 투표 모임을 숨기고, 날짜가 이미 정해진 장소 투표 모임은 표시할 수 있다.
  • 모임별 마일리지 점수는 투표 확정 때가 아니라 모임 공개 때고정한다.

누가 어떤 알림을 받는가

  • 게시글 투표는 투표 전용 시작·마감 알림을 보내지 않는다.
  • 참가자 투표는 시작 때 작성자를 제외한 참석자에게, 마감 때 표를 낸 사람에게 알린다. 앱의 ‘이벤트 알림’ 설정을 따른다.
  • 결정 투표는 시작 때 주최자를 제외한 클럽 회원에게 기존 모임 공개 알림을 보낸다. 확정 결과는 참가 전환 여부에 맞춰 안내하며 ‘이벤트 알림’ 설정을 따른다.
  • 주최자의 조치가 필요할 때는 주최자·공동주최자에게 알리고 ‘모임 운영 알림’ 설정을 따른다. 참가자 알림을 끈다고 이 요청까지 꺼지는 것은 아니다.

시작 알림은 기존 클럽 알림 설정을 따른다. 자세한 구분은 투표 알림의 수신자와 설정에 있다. 알림 코드가 있다는 사실만으로 실제 휴대전화 수신을 확인한 것은 아니다.

공개 전에 남은 일

  • 배포용 앱: 운영자가 주최자·공동주최자·운영진·일반 회원·대기자 시험 계정으로 만들기, 선택 변경, 마감, 자동 참가, 재확정, 취소와 권한 제한을 확인한다.
  • 운영 배포: 고객 앱과 두 서버의 버전을 맞춰 배포한다. 기존 환경에 별도 출시 목록이 설정돼 있다면 투표를 포함했는지 확인한다.
  • 휴대전화 알림: 알림을 눌렀을 때 투표·모임 화면과 참가 결과가 맞는지 확인한다. 관리자 업무는 같은 운영자가 게시글·모임·신고 메뉴에서 처리한다.
  • 익명 안내: 익명 투표와 확정 뒤 참가자 명단의 차이를 최종 확인한다. 투표·표는 회원 데이터 내보내기에 포함하지 않는다.

기존 175개 기능 목록과 별도로 관리한다. 이 문서를 추가해 기능 수나 검사 통과 수를 늘리지 않는다.
