F12-02. 알림 그룹 보기 · 미읽음 배지

읽지 않은 알림 수는 각 탭 상단의 알림 아이콘에서 확인한다. 알림 목록에서는 유형별 그룹 보기로 내용을 모아 본다. 2026-11-02 메뉴 개편으로 알림은 상단에서 여는 화면이다.

상단 알림 배지

각 탭 첫 화면에 검색·알림·전체 메뉴가 같은 순서로 놓입니다. 로그인한 회원은 알림 목록과 같은 상태에서 읽지 않은 수를 받아 배지로 봅니다. 수가 0이면 배지를 숨깁니다. 비로그인 상태에서는 수를 조회하지 않고 알림을 열 때 로그인으로 안내합니다.

구현 근거는 AppTopBarActions의 unreadCountNotifierProvider와 Badge.count입니다. 이전의 ‘하단 탭 배지 미구현’ 설명을 대체합니다.

그룹 보기와 읽음 처리

알림 목록에서 그룹 보기로 전환해 같은 유형의 알림을 모아 확인합니다. 개별 알림을 열면 해당 업무 화면으로 이동합니다. 읽음·삭제·새 알림 이후 상단 수와 목록의 상태가 일치하는지 확인합니다.

실제 푸시 수신과 앱이 다시 열릴 때의 갱신은 기기·계정·서버 환경에 따라 확인합니다. 배지가 구현됐다는 사실만으로 운영 푸시 확인을 완료 처리하지 않습니다.

확인할 상황

  • 새 알림을 받은 뒤 상단 배지와 목록의 수가 일치하는가.
  • 읽음·삭제 뒤 수가 갱신되고 0이면 배지가 사라지는가.
  • 로그아웃·계정 전환 뒤 이전 회원의 수가 남지 않는가.
  • 알림에서 대상 화면으로 이동하고 원래 탭으로 돌아오는가.

현재 앱 메뉴 · 검색·알림·전체 메뉴 입구

이 기능의 출시 완료 기준

2026년 11월 2일 갱신한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 그룹 목록·개별 읽음·전체 읽음 후 미읽음 집계가 실제 미읽음 대상과 일치한다.
  • 동시 수신·그룹별 차감·재진입·계정 전환 뒤 목록과 상단 알림 배지가 일치하는지 확인한다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 알림의 관련 완료 기준도 함께 확인합니다.
