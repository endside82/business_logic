F02-03. 홈 카드 진입

구역별 카드와 더보기 목적지, 추천 상세 중간 단계·보조 추천·출발 경로별 복귀를 구분한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

결론

홈의 카드와 ‘더보기’는 서로 다른 목적지로 간다. 이벤트·클럽·플랜 상세로 이동하는 기본 카드뿐 아니라 내 일정·사람·찜·최근 본 목록도 실제 홈 흐름에 포함된다. 추천 카드는 중간의 추천 상세를 거치므로 모든 이벤트 카드가 바로 같은 상세를 연다고 설명하지 않는다.

추천 상세의 중간 단계

추천 상세는 해당 이벤트의 실제 상세와 별도 추천 목록을 동시에 요청하고 둘 다 끝난 뒤 표시한다. 실제 상세가 실패하면 전체 오류와 다시 시도가 나오며, 보조 추천만 실패하면 본문은 표시하고 보조 구역을 숨긴다.

‘이벤트 상세 보기’를 누르면 일반 이벤트 상세를 위에 쌓는다. 이 버튼은 신청·결제 확정이 아니다. 추천 상세에서 제시하는 자리 안내는 이벤트 정원과 현재 참가 수를 사용한다. 홈 카드의 전체 추천 점수를 그대로 전달받아 같은 이유를 재현하는 구조는 아니다.

‘비슷한 추천 이벤트’는 현재 이벤트의 유사도 검색이 아니라 일반 추천 목록 최대 6개에서 현재 이벤트를 빼고 최대 5개를 고른다. 별도의 이벤트 유사 검색 창구가 있다고 해서 이 화면이 그것을 호출한다고 설명하지 않는다. 보조 카드를 누르면 다른 추천 상세 경로로 이동한다.

권한·실패·복귀

카드 목록에 있었다는 사실이 현재 상세 열람·참가·구매 권한을 보장하지 않는다. 상세는 현재 공개 상태와 회원 권한을 다시 확인한다. 계정 변경·목록 생성 이후 비공개·삭제·마감 등으로 이동이 거절될 수 있다.

추천 목록의 카드는 상세를 위에 쌓아 목록으로 돌아올 수 있게 한다. 반면 추천 상세의 보조 카드는 새 추천 상세 경로로 바꾸므로, 추천 목록에서 출발해 보조 카드까지 선택한 경우에도 원래 목록 스택이 그대로 유지된다고 보장하지 않는다. 홈의 카드 이동·추천 목록에서의 이동·추천 상세 안의 이동을 각각 확인한다.

찜 해제는 조회나 단순 화면 이동이 아니라 회원의 위시리스트 변경이다. 성공·실패·늦은 응답·목록 반영은 위시리스트의 별도 계약을 따른다. 일반 이벤트 상세의 본문·참가·관리 행동은 이벤트 상세에서 확인한다.

수용 기준과 검증 근거

  • AC-01 기본 카드: 예정·내 일정·찜·최근 본 카드는 해당 식별자의 일반 이벤트 상세로 이동한다.
  • AC-02 추천 카드: 홈 추천·추천 목록·추천 상세 보조 카드의 각 이동 방식을 구분한다.
  • AC-03 예정 더보기: 이벤트 탭을 날짜순으로 열고 기존 정렬 변경과 필터 보존을 확인한다.
  • AC-04 다른 유형: 클럽·플랜·사람 카드가 각 목적지로 가고 목록 권한을 상세 권한으로 대체하지 않는다.
  • AC-05 플랜 더보기: 마켓 공개 범위를 적용하고 플랜 마켓을 현재 탭 위에 연다.
  • AC-06 이유·찜: 추천 이유 열기와 찜 해제를 카드 상세 이동과 구분한다.
  • AC-07 추천 상세 실패: 본문 실패와 보조 추천 실패, 두 요청의 대기 범위를 구분한다.
  • AC-08 추천 후보: 보조 목록은 일반 추천에서 현재 이벤트를 제외한 최대 5개임을 확인한다.
  • AC-09 일반 상세: 중간 추천 상세의 버튼이 일반 상세를 열며 참가·결제를 직접 확정하지 않는다.
  • AC-10 왕복: 홈 출발·추천 목록 출발·보조 추천 선택·다른 탭 더보기의 복귀와 갱신을 각각 확인한다.
