F12-01. 알림 목록 · 읽음 관리

상단 알림 아이콘에서 내 알림을 확인하고 읽음·삭제로 정리합니다. 알림에서 업무 화면으로 이동하고 실패·복귀 결과를 확인합니다.

상단에서 여는 알림함

각 탭 첫 화면의 알림 아이콘에서 내 알림을 최신순으로 읽습니다. 아래로 내려 다음 알림을 커서로 받고, 새로고침으로 목록과 배지를 다시 읽습니다. 추가 조회 실패 때는 기존 목록과 재시도를 유지합니다.

읽음과 업무 화면 왕복

한 건을 누르면 그 알림만 읽음 처리하고 해당 업무 화면으로 이동합니다. ‘모두 읽음’은 계정의 알림에 적용합니다. 임시로 줄인 수는 요청 실패 시 복구하며, 동시에 받은 새 알림은 후속 조회로 반영합니다.

선입금·환불·안전 체크인·분쟁과 통합 이동 알림의 목적지가 연결되어 있습니다. 필요한 식별자가 없으면 열 수 없다는 안내, 미공개 기능이면 공개 범위 안내로 구분합니다. 실제 목적지의 행동·결과·복귀는 별도 여정으로 확인합니다.

삭제와 남은 제약

스와이프 삭제 성공 후 목록에서 제외하고 성공 안내를 표시합니다. 영구 삭제이며 Undo는 없습니다. 현재 삭제 실패에는 오류 안내와 스와이프한 항목을 명시적으로 복구하는 처리가 없습니다. ‘실패하면 원래 목록으로 자동 복구한다’고 안내하지 않습니다.

그룹 카드의 집계·읽음 후 갱신과 배지의 1,000건 초과 차단 필터 한도는 그룹 보기 · 미읽음 배지를 따릅니다.

확인 범위

2026년 11월 22일 서버·앱 소스 대조입니다. 실제 OS·기기·외부 발송 결과와 코드 구현을 구분합니다.

알림함 기록과 휴대전화 수신

알림함에 기록이 생겼다는 사실만으로 휴대전화에 표시됐다고 판단하지 않습니다. 발송 작업은 저장해 복구하며, 공급자 수락·대기·실패를 별도로 확인합니다.

알림 기록·발송 수락·실제 수신을 구분합니다에서 재처리와 실제 수신의 경계를 확인합니다.

이 기능의 출시 완료 기준

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 첫 출시 포함 여부와 구현·검사 현황은 위 상태표를 따릅니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 알림 목록·읽음·전체 읽음 결과가 저장된 알림과 일치하고 대상 화면을 연다.
  • 삭제/권한 회수된 대상·페이지 변경·늦은 응답·계정 전환에서 이전 알림을 노출하지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 알림의 관련 완료 기준도 함께 확인합니다.
