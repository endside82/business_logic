175개 기능 카탈로그

전 기능을 한 화면에서 검색·필터링한다. 키워드는 ID·이름·주 사용자·검산 포인트 전부에서 찾는다. 영향 영역(알림·돈·캘린더·위치·신뢰)으로도 좁힐 수 있어 “돈이 움직이는 기능만”과 같은 질문에 즉시 답할 수 있다.

전체 표시 중

“첫 출시” 열은 이 기능이 첫 출시에 고객에게 열리는지만 나타낸다 — 판정 근거와 열린 항목은 첫 출시 현황, 기능별 확인 수준은 기능별 출시 상태에서 본다. “PRD 상태”는 문서 작성 수준이며 구현 완료와 무관하다(PRD 문서 상태표).
도메인 셋에 걸쳐 있어 단일 기능 번호를 갖지 않는 흐름은 아래 표에 없다 — 사적 모임 전 과정이 그 예이며 기능 수 175에 포함하지 않는다.

불러오는 중…

ID 도메인 기능명·검산 포인트 주 사용자 영향 첫 출시 PRD 상태 시나리오

읽는 법

  • ID — F도메인번호-순번 형식. 다른 문서·이슈에서 이 ID로 참조한다.
  • 검산 포인트 — 시나리오 작성 시 절대 빠뜨리면 안 되는 조건 키워드.
  • 영향 — 이 기능이 변경되면 같이 바뀌는 횡단 영역. 회귀 검토의 기준.
  • 시나리오 수 — 해당 기능 문서에 등록된 시나리오·수용 조건 수. 과거 집계 방식이 달라 상대적 복잡도를 보는 참고값이며 테스트 통과 건수가 아니다.
