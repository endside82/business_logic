F14-01 이벤트 위치 공유와 조회

시작 2시간 전부터 종료 전까지의 역할별 동의·좌표 쓰기·조회와 GPS·목록 갱신을 구분한다. 2026-11-22 소스 대조이며 새 제품 실행과 구분합니다.

현재 역할과 입구

이벤트의 위치 공유 화면은 이벤트 정보·개인정보 상태를 읽고 공유 시작, 지도·참석자 위치, 내 공유 상태, 개인정보 설정을 제공한다. 최초 위치 GET이 동의 필요 오류를 반환하면 공유 시작 패널을 보여 준다. 동의 전 조회 오류가 시작 버튼까지 막는 구조로 설명하지 않는다. 진입 라우트도 이벤트 위치 조회 권한을 검사한다.

공유 가능 시간과 역할

서버의 공유 시간은 상태 OPEN, 유효한 시작·종료 시각, 시작 2시간 전 이상·종료 시각 미만이다. 이벤트의 위치 공유 설정도 켜져 있어야 한다. 호스트도 시간 밖에 공유하거나 조회할 수 없다. 앱의 EventMoment도 OPEN·일정 확정·같은 시간 경계를 적용한다.

동의 시작은 호스트·활성 공동호스트·ATTENDING 참석자를 허용한다. 좌표 갱신은 호스트 또는 ATTENDING 참석자만 허용하고 본인의 동의가 필요하다. 따라서 참석 행이 없는 공동호스트의 동의 성공이 좌표 등록 성공을 보장하지 않는다.

위치 목록 조회는 호스트·활성 공동호스트·클럽 관리자 또는 ATTENDING 참석자를 허용한다. 일반 참석자는 본인의 공유 동의도 필요하다. 역할 확인 뒤 이벤트 공유 설정이 꺼져 있으면 빈 목록을 반환하고, 켜져 있으면 시간 경계를 검사한다. 동의한 현재 호스트·활성 공동호스트·ATTENDING 참석자의 활성 좌표 중 차단 관계를 제외한다. expiresAt이 null인 기존 자료는 만료 필터를 통과한다.

동의와 좌표 등록의 분리

동의 POST는 본문 없이 200으로 끝난다. 좌표 등록 POST는 latitude·longitude·선택 accuracy를 받는다. 좌표는 유한값·허용 범위여야 하고 (0,0)은 거절한다. accuracy가 있으면 유한한 0 이상 값이어야 한다. 서버는 선택 expiryMode·customHours도 받지만 현재 앱은 좌표와 accuracy만 보낸다.

첫 좌표의 기본 만료는 등록 시각에서 2시간 뒤이며 이벤트 종료를 넘지 못한다. 활성 공유의 평소 GPS 갱신은 기존 만료를 유지한다. 다른 만료 방식과 연장은 공유 만료와 연장을 따른다.

앱은 GPS 서비스·권한·유효 좌표를 먼저 확인한 뒤 동의 API와 좌표 API를 순서대로 호출한다. 동의 성공과 좌표 전송 성공은 별개다. 좌표 전송에 실패한 상황을 지도 공유 성공으로 표시하지 않는다. 개인정보 상태 재조회가 서버 동의 상태를 다시 반영한다.

앱의 갱신과 중단

위치 목록은 30초 간격으로 조회하고 내 GPS는 공유 중 60초 간격으로 갱신한다. GPS 취득에는 높은 정확도와 12초 제한을 사용하며 연속 2회 취득 실패 시 주기 갱신을 멈춘다. 백그라운드 전환·화면 해제·동의 철회·시간 종료는 관련 갱신을 중단하고 복귀 시 현재 이벤트·개인정보 상태를 확인한다.

목록 조회 실패는 이전 좌표를 비운 뒤 오류로 전환한다. 요청 순서 표식과 사람 탐색 변경 구독으로 늦은 응답과 차단 변경을 처리한다. 지도 위치 조회와 참석자 거리 조회의 권한은 다르며, 거리 조회 실패를 빈 부가 정보로 취급하는 현재 화면 동작을 거리 0이나 참석자 없음으로 해석하지 않는다.

열람 기록과 데이터 정리

허용된 위치 목록에서 타인의 좌표를 반환할 때 대상자의 열람 기록을 남긴다. 본인 좌표는 기록하지 않는다. 반복 조회도 별도 행이므로 열람 횟수는 서로 다른 사람 수가 아니다. 만료된 좌표와 30일을 넘긴 공유 자료·열람 기록을 정리하는 예약 작업이 있다. 정리 전이라도 조회 필터로 만료 위치를 제외한다.

수용 기준과 검증 근거

  • AC-01 공유 시간: OPEN 이벤트에서 시작 2시간 전 이상·종료 전만 공유하고 호스트도 같은 시간 제한을 받는다.
  • AC-02 첫 진입: 동의 필요 조회 오류는 공유 시작 패널로 이어지고 시작 절차를 막지 않는다.
  • AC-03 동의와 좌표: 동의 API와 좌표 API의 권한·성공을 각각 판정하고 좌표 오류를 공유 성공으로 표시하지 않는다.
  • AC-04 위치 목록: 현재 자격·동의·만료·차단을 적용하고 일반 참석자의 본인 동의를 확인한다.
  • AC-05 만료 유지: 평소 GPS 갱신은 활성 공유의 만료를 늘리지 않고 이벤트 종료를 넘기지 않는다.
  • AC-06 갱신 중단: 화면 수명·동의·시간·GPS 오류에 따라 갱신을 중단하며 조회 오류 뒤 오래된 좌표를 남기지 않는다.
  • AC-07 열람 기록: 반환한 타인의 위치별 기록을 남기며 반복 열람과 고유 열람자를 구분한다.

이 기능의 출시 완료 기준

현재 제한과 확인 범위를 함께 판정한다.

2026년 10월 13일 정리한 판정 조건입니다. 아래 목록 자체는 검사 통과 기록이 아닙니다. 현재 공개 범위와 실행 확인은 출시 상태와 근거를 따릅니다. 위의 날짜별 기존 분류는 현재 운영 설정이나 검사 통과를 대신하지 않습니다. 후속 기능은 첫 출시에서 신규 이용 제한을 확인하고, 기능을 열 때 아래 결과를 검증합니다.

  • 동의한 참가자가 정해진 모임과 시간 범위에서만 위치를 공유하고 허용된 참가자만 본다.
  • 동의 전·비참가자·권한 거절·탈퇴/차단·다른 모임 직접 접근에서 좌표를 노출하지 않는다.

기능 본문에 남은 미구현·결함은 해결 증거 또는 명시적인 공개 범위 결정 없이 완료 처리하지 않습니다. 함께 적용하는 권한·실패·복구 확인과 버전·환경·결과·승인 기록을 갖춘 뒤 판정합니다. 위치 & 길찾기의 관련 완료 기준도 함께 확인합니다.
