F16-08. 검토 대기열·운영 현황·감사 기록

클럽 마일리지 관리자가 검토할 항목, 운영 현황, 회원별 상세와 감사 기록을 보는 운영 화면이다. 플랫폼 시스템 관리자는 별도 화면에서 원장과 잔액의 어긋남 같은 이상 사건을 조회·재검사·정정·종결한다. 핵심 화면과 복구 흐름은 첫 출시 범위다. 반복 수동 적립 한 종의 탐지·검토·선택 회수도 2026-09-06 구현·검증·로컬 통합을 마쳤지만 별도 운영 출시 전이다.

현재 상태 — 클럽 운영과 플랫폼 복구 화면 완료

검토 대기열, 클럽 운영 현황, 회원 상세, 감사 기록과 플랫폼 이상 사건의 조회·확인·재검사·정정·종결을 실제 서버 데이터로 왕복했다. 플랫폼 운영자는 클럽의 일상적인 적립·사용·제안 승인을 대신하지 않고, 이상 사건의 근거가 있을 때만 예외 정정을 수행한다.

운영 원칙 — 처리 결과와 근거를 함께 남긴다

모든 적립·사용·정정·정책 변경은 변경 전후 내용과 담당자를 감사 기록에 남긴다. 이상을 발견해도 시스템이 잔액을 자동으로 고치지는 않는다. 운영자가 대상과 근거를 확인하고 정정한 뒤 다시 검사해 정상 여부를 확인해야 사건을 종결한다.

이상 사건 복구플랫폼 시스템 관리자사건을 조회·확인하고, 근거가 있을 때 정정한 뒤 재검사하여 정상으로 확인된 건을 종결한다.

반복 수동 적립 검토 — 구현 완료, 별도 출시 전

같은 클럽에서 같은 운영자가 같은 회원에게 7일 안에 수동 적립을 3건 이상 주면 일일 점검이 검토 항목을 만든다. 같은 요청을 다시 보낸 기록과 이미 검토한 묶음은 중복 등록하지 않는다. 탐지는 부정행위 확정이 아니며, 담당자가 당시 점수·사유·시간·일괄 작업 근거를 보고 판단한다.

담당자의 선택권한처리 결과
정상으로 판정마일리지 검토 권한점수를 바꾸지 않고 사유와 함께 검토를 종결한다.
부정으로 판정검토 권한과 점수 집행 권한담당자가 고른 적립 기록만 정정한다. 선택하지 않은 적립은 유지한다.
회수할 잔액 부족점수 집행 담당자 후속 처리부족한 건만 자동 회수 검토로 넘긴다. 함께 선택한 다른 회수 가능 건은 처리한다.
처리 응답 유실재시도 시 현재 권한 재확인보관한 같은 요청으로 결과를 다시 확인하며 회수·감사·알림을 중복 반영하지 않는다.
핵심 검토와 추가 탐지의 범위를 구분한다
  • 반복 수동 적립 검토는 구현·실제 앱 왕복·전체 회귀를 마쳤다. 별도 출시 값(MILEAGE_ADVANCED_REVIEW)을 켜기 전에는 탐지와 전용 처리 화면이 닫히지만 핵심 검토 대기열은 유지한다. 한 화면이 호스트 제안과 이 검토를 함께 보여 주기 때문에, 화면째 닫지 않고 이 유형만 숨긴다.
  • 반복 사용·대량 사후 검토·등급 이상 세 유형은 이번 제품 범위 밖이다. 완료한 기능이나 출시만 기다리는 기능으로 세지 않는다.
  • 잔액 부족으로 자동 회수하지 못한 건에는 전용 해결 버튼이 없다. 클럽 운영자가 수동 정정·사용으로 처리한 뒤 메모를 남기고 항목을 닫는다.
  • 플랫폼 이상 사건은 자동으로 잔액을 고치지 않는다. 영향 대상을 확인한 뒤 사람이 근거를 남겨 정정하고 재검사한다.

검증 범위와 배포 준비는 마일리지 후속 구현 검증 기록을 따른다.
