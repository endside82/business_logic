F16-05. 적립 규칙·등급·배지·사용 사유 관리

클럽 정책 담당자가 기본 적립 규칙, 등급, 배지와 점수 사용 사유를 관리한다. 이 네 가지는 출시 범위로 코드·화면 검증을 마쳤다. 사진 승인 적립도 심사·재심·회수와 운영 화면까지 구현됐고 현재 기본 브랜치 전체 회귀도 통과했다. 역할별 앱↔서버 흐름·빈 데이터베이스 설치와 별도 출시 설정이 남았다. 시즌과 이벤트별 규칙은 실제 운영 기능이 끝나지 않아 계속 닫혀 있다.

현재 상태 — 핵심 정의 관리 완료

클럽 공통 적립 규칙과 등급·배지·사용 사유는 실제 서버와 이어지는 화면 왕복을 마쳤다. 등급 기준을 바꾸면 기존 회원 등급을 자동으로 다시 계산하고, 사용 중인 등급은 이유와 함께 삭제를 막는다.

사진 승인 규칙은 사진 심사 상태기계와 함께 구현됐다. 다만 운영 기본 목록에 MILEAGE_PHOTO가 없어서 현재 화면에서는 선택할 수 없다. 현재 전체 회귀는 통과했다. 역할별 앱↔서버 흐름과 빈 데이터베이스 설치를 확인한 뒤 별도로 출시한다.

설계 의도 — 마일리지가 "돈처럼 보이지 않게"

등급 이름에 "원·캐시·포인트" 같은 금전성 단어를 막는 것은 의도된 안전장치다. 마일리지가 현금처럼 보이면 법적·세무적 문제와 사용자 오해를 부른다. 사용 사유를 삭제하지 않고 사용 중지만 하는 것도 과거 거래의 사유 기록을 보존하기 위해서다.

관리 대상과 규칙

대상핵심 규칙
적립 규칙체크인·후기의 점수와 사용 여부를 설정한다. 후기는 모임 종료 후 며칠 안에 쓰면 적립할지를 1일부터 현재 후기 작성 상한까지 정한다(현재 최대 7일). 같은 활동 규칙을 다시 저장하면 기존 규칙을 갱신한다. 사진 승인 적립은 코드가 완료됐지만 MILEAGE_PHOTO 출시 전에는 선택지에서 숨긴다.
등급클럽당 최대 10개. 기준 점수는 등급이 높아질수록 커져야 하며 중복할 수 없음. 이름에 금전성 단어 금지
배지 정의클럽당 최대 50개. 사용 시작·중지 가능. 회원 화면에는 사용 중인 배지만 노출
사용 사유점수를 사용할 때 고르는 사유와 기본값. 과거 기록을 보존하기 위해 삭제하지 않고 사용 중지만 한다.

운영진이 할 수 있는 동작

동작누가무엇이 일어나는가
적립 규칙 관리정책 담당체크인·후기의 자동 적립 규칙을 만들고 본다. 같은 활동 규칙을 다시 저장하면 기존 규칙을 갱신한다.
등급 관리정책 담당등급을 만들고 고치고 지운다. 개수·금전성 단어·기준 점수 제약을 어기면 거절된다.
배지 관리정책 담당배지를 만들고 고친다. 클럽당 50개 한도를 넘을 수 없다.
사용 사유 관리정책 담당사용 사유와 기본값을 만들고 고친다. 더 쓰지 않는 항목은 과거 기록을 남긴 채 사용 중지한다.

현재 출시에서 닫힌 세부 기능

  • 사진 승인 적립 — 승인·반려·재심·적립·승인 취소와 회수, 클럽 운영진 심사 화면까지 코드가 완료됐고 현재 기본 브랜치 회귀를 통과했다. 역할별 앱↔서버 흐름과 출시 설정이 남아 선택지에서 숨긴다.
  • 시즌 — 일부 등록·조회 틀만 있고 자동 시작·종료, 순위·종료 기록과 실패 복구가 없어 실제 운영할 수 없다.
  • 이벤트별 적립 규칙 — 현재는 클럽 공통 규칙만 적용한다. 이벤트별 규칙을 언제 고정하고 변경·취소·재처리할지부터 정해야 한다.
  • 클럽별 후기 작성 기간 — 지금 클럽이 정할 수 있는 것은 후기에 점수를 줄 인정 기간이다. 후기 자체를 쓸 수 있는 기간은 모든 클럽에 공통으로 7일이며, 클럽별로 바꾸는 기능은 후기 도메인의 별도 제품 결정이다.

사진 승인 적립은 역할별 앱↔서버 흐름과 빈 데이터베이스 설치를 확인한 뒤 출시 설정을 바꾸면 된다. 나머지 세 기능은 제품 범위와 운영 흐름을 확정하고 구현·검증한 뒤 따로 출시한다.
