F16-05. 적립 규칙·등급·배지·사용 사유 관리

클럽 정책 담당자가 기본 적립 규칙, 등급, 배지와 점수 사용 사유를 관리한다. 이 네 가지는 출시 범위로 코드·화면 검증을 마쳤다. 사진 승인 적립도 심사·재심·회수와 운영 화면까지 구현됐고 전체 회귀·빈 데이터베이스 대조도 통과했다. 역할별 앱↔서버 흐름과 별도 출시 설정은 남았다. 시즌과 이벤트별 점수 설정도 2026-09-06 구현·검증·로컬 통합을 마쳤으며 운영 배포 전이다.

현재 상태 — 핵심 정의 관리 완료

클럽 공통 적립 규칙과 등급·배지·사용 사유는 실제 서버와 이어지는 화면 왕복을 마쳤다. 등급 기준을 바꾸면 기존 회원 등급을 자동으로 다시 계산하고, 사용 중인 등급은 이유와 함께 삭제를 막는다. 이 네 가지를 만들고 고치는 권한은 클럽 소유자에게 고정되어 있어 운영진에게 위임되지 않는다.

사진 승인 규칙은 사진 심사 상태기계와 함께 구현됐다. 다만 운영 기본 목록에 MILEAGE_PHOTO가 없어서 현재 화면에서는 선택할 수 없다. 현재 전체 회귀는 통과했다. 빈 데이터베이스 대조는 완료됐으며 역할별 앱↔서버 흐름을 확인한 뒤 별도로 출시한다.

설계 의도 — 마일리지가 "돈처럼 보이지 않게"

등급 이름에 "원·캐시·포인트" 같은 금전성 단어를 막는 것은 의도된 안전장치다. 마일리지가 현금처럼 보이면 법적·세무적 문제와 사용자 오해를 부른다. 사용 사유를 삭제하지 않고 사용 중지만 하는 것도 과거 거래의 사유 기록을 보존하기 위해서다.

관리 대상과 규칙

대상핵심 규칙
적립 규칙체크인·후기의 점수와 사용 여부를 설정한다. 후기는 모임 종료 후 며칠 안에 쓰면 적립할지를 1일부터 현재 후기 작성 상한까지 정한다(현재 최대 7일). 같은 활동 규칙을 다시 저장하면 기존 규칙을 갱신한다. 사진 승인 적립은 코드가 완료됐지만 MILEAGE_PHOTO 출시 전에는 선택지에서 숨긴다.
이벤트별 점수와 상한호스트가 공개 전 체크인·후기 점수를 정한다. 기본 상한은 클럽 점수의 3배이며 정책 담당자가 별도 상한을 지정하거나 기본값으로 되돌린다. 공개할 때 점수·사용 여부·후기 인정 기간을 고정한다.
등급클럽당 최대 10개. 기준 점수는 등급이 높아질수록 커져야 하며 중복할 수 없음. 이름에 금전성 단어 금지
배지 정의클럽당 최대 50개. 사용 시작·중지 가능. 회원 화면에는 사용 중인 배지만 노출
사용 사유점수를 사용할 때 고르는 사유와 기본값. 과거 기록을 보존하기 위해 삭제하지 않고 사용 중지만 한다.

운영진이 할 수 있는 동작

동작누가무엇이 일어나는가
적립 규칙 관리정책 담당체크인·후기의 자동 적립 규칙을 만들고 본다. 같은 활동 규칙을 다시 저장하면 기존 규칙을 갱신한다.
이벤트별 점수 설정이벤트 호스트공개 전에는 상한 안에서 점수를 바꾸거나 클럽 기본값을 선택한다. 공개 뒤에는 고정한 기준을 조회하며 회원도 신청 전에 같은 점수와 후기 인정 기간을 확인한다.
등급 관리정책 담당등급을 만들고 고치고 지운다. 개수·금전성 단어·기준 점수 제약을 어기면 거절된다.
배지 관리정책 담당배지를 만들고 고친다. 클럽당 50개 한도를 넘을 수 없다.
사용 사유 관리정책 담당사용 사유와 기본값을 만들고 고친다. 더 쓰지 않는 항목은 과거 기록을 남긴 채 사용 중지한다.

후속 기능별 출시 경계

  • 사진 승인 적립 — 승인·반려·재심·적립·승인 취소와 회수, 클럽 운영진 심사 화면까지 코드가 완료됐고 현재 기본 브랜치 회귀를 통과했다. 역할별 앱↔서버 흐름과 출시 설정이 남아 선택지에서 숨긴다.
  • 시즌 — 자동 시작·마감·공동 순위·종료 기록·실패 복구는 구현·검증 완료다. 핵심 마일리지와 별도 설정으로 출시한다.
  • 이벤트별 적립 규칙 — 공개 시 고정한 점수를 사용하며 이후 클럽 규칙의 점수 변경을 소급하지 않는다. 현재 클럽 규칙을 끄면 긴급 중지로 적용한다. 이벤트 취소 시 체크인·후기 적립을 회수하고 실패한 처리는 이어서 재시도한다. 사진·수동 적립·호스트 제안은 이 취소 회수에 포함하지 않는다.
  • 클럽별 후기 작성 기간 — 지금 클럽이 정할 수 있는 것은 후기에 점수를 줄 인정 기간이다. 후기 자체를 쓸 수 있는 기간은 모든 클럽에 공통으로 7일이며, 클럽별로 바꾸는 기능은 2026-09-05 만들지 않기로 결정했다(요구가 확인되면 재검토).

이벤트별 규칙에는 별도 출시 스위치가 없다. 기존 공개 모임의 확정 점수를 준비한 뒤 핵심 마일리지가 열린 환경에 코드를 배포하면 함께 적용된다. 확정 기록이 누락된 모임은 현재 클럽 점수로 임의 대체하지 않고 적립을 막아 운영 확인 대상으로 남긴다. 제도 도입 전 모임은 소급 적립하지 않는다.

근거는 마일리지 후속 구현 검증 기록을 따른다.
