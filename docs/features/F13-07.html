F13-07. 계정 즉시 비활성화 (탈퇴)

즉시 탈퇴는 의무 점검·필요한 보관금 포기 동의·최종 확인 뒤 계정을 사용할 수 없게 하는 흐름이다. 30일 유예 삭제 예약과 달리 성공하면 세션을 종료하고 계정은 탈퇴 진행 상태가 된다. 다시 로그인해 취소하거나 계정을 복원하는 기능은 없다. 활동 정리, 계정 비활성화, 유예 만료 뒤 파기, 파일 소거, 잔액 환급은 서로 다른 완료 단계다. 최종 탈퇴가 막히더라도 앞서 항목별로 끝낸 활동 정리가 모두 되돌아오는 것은 아니다.

실제 진입과 복귀

  • 전체 메뉴 → 설정 → 계정 → 데이터 내보내기·탈퇴에서 아래 계정 탈퇴를 선택한다. 삭제 진행 배너는 같은 프라이버시 화면으로 연결된다.
  • 삭제 대기·승인 상태이면 즉시 탈퇴 버튼 대신 진행 이유를 안내한다. 대기 요청은 위의 삭제 취소로 거둘 수 있고 승인은 취소할 수 없다.
  • 정지·차단 중에는 즉시 탈퇴를 닫고 삭제 요청을 안내한다. 제한 세션의 삭제 요청과 실제 자동 파기 가능 여부는 계정 삭제 요청과 취소를 따른다.
  • 점검 실패에서는 안내 후 멈춘다. 차단 창은 항목별 이유·건수와 상세 최대 3건을 보이며 해결 경로가 있으면 창을 닫고 이동한다. 클럽 폐쇄 가입비 환불은 고객센터 입구도 제공한다.
  • 최종 확인에서 취소하면 탈퇴를 요청하지 않고 현재 계정을 유지한다. 탈퇴 성공 후에는 인증 경계가 화면을 바꾸므로 이전 로그인 화면 상태로 돌아오는 흐름이 아니다.

점검·동의·최종 확인

  1. 서버는 현재 금융·활동·소유권 의무를 읽어 차단 항목과 자동 정리 가능한 항목을 구분한다. 끝난 결제 이력만 있다는 이유로 탈퇴를 막는 것은 아니다.
  2. 차단이 없고 보관금 포기 대상이 있으면 서버 안내와 모임별 금액·조건을 표시하고 동의하고 계속을 받는다. 대상이 없으면 이 창과 동의 본문은 생략한다.
  3. 최종 확인은 복구할 수 없다는 안내와 자동 처리 목록을 함께 보여준다. 비밀번호 재입력이나 외부 소셜 제공자 연결 해제를 이 확인 단계에 추가하지 않는다.
  4. 서버는 안내 버전·모임·금액이 현재 포기 대상 전체를 덮는지 확인한다. 대상 변경으로 동의가 부족하면 다시 점검·동의하고, 구체적인 차단 항목이 생겼으면 그 이유를 보여준다.
  5. 실제 탈퇴는 활동 정리 뒤 회원 잠금을 잡고 제재·삭제 예약·새 의무·남은 활동을 다시 판정한다. 미리보기 통과는 최종 탈퇴 성공 보장이 아니다.

자동 정리와 실패의 경계

  • 신청·직접 참석·정기모임 등록·무료 개최, 클럽 소속, 공동 호스트·호스팅 권리, 판매·제공 상품, 큐레이터 자리·데이트 상태 등 해당되는 항목을 담당 기능의 처리로 정리한다.
  • 항목별 독립 처리이므로 뒤 단계의 실패가 앞 단계의 취소·클럽 나가기·판매 내리기를 모두 되돌리지 않는다. 앱은 서버에서 일부 정리가 가능했던 실패 응답을 받으면 관련 계정 자료를 다시 읽도록 표시한다.
  • 클럽 탈퇴의 가입비 환불 실패는 해당 클럽을 차단 항목으로 올려 탈퇴를 멈춘다. 판매·큐레이터 등 남은 항목은 잠금 뒤 다시 판정한다. 걷지 못한 일부 신청·참석·등록·무료 개최는 후속 정리 대상으로 구분한다.
  • 돈 의무에는 정산·환불·출금·미수금·유료 개최·클럽 소유권·제공자 배정 등이 포함된다. 사유별 해결 경로를 따르고, 보관금 포기 동의 하나로 모든 금융 의무를 면제하지 않는다.

보관금 포기 동의는 해당 참가비를 탈퇴 후 받을 수 없다는 별도 안내다. 지갑 유료 잔액 환급이나 아래의 선입금 보류와 혼동하지 않는다.

탈퇴를 마친 회원에게 돌아갈 포인트 선입금 취소 환불, 탈퇴 호스트에게 지급할 포인트 선입금, 반려·예약 복원된 계정 폐쇄 환급은 지갑에 넣지 않고 별도 보류금으로 기록하며 운영 경보를 남긴다. 운영자는 새 계좌의 재지급을 예약하거나 외부 지급 증빙으로 종결한다. 재지급 예약 상태는 송금 완료가 아니다.

보류금과 연결된 원출금의 늦은 지급 증빙이 미검토로 남아 있으면 재지급·외부 종결을 막는다. 거래별로 미지급을 확인하거나, 다른 미검토 증빙이 없고 금액·원출금이 일치할 때 원출금 지급으로 종결한다. 중복 지급·회수·손실과 재지급 반환의 상세 운영은 별도 돈 처리 기능의 검증 범위이며, 탈퇴 성공만으로 끝났다고 판정하지 않는다.

응답 유실과 기기 정리

탈퇴 요청은 해당 계정의 세션이 먼저 종료돼도 응답을 기다리는 경로로 보낸다. 성공 응답을 받으면 그 계정의 기록을 정리한다. 요청 전 ‘탈퇴 요청 중’ 표식을 남기며, 서버에 전달됐는지 확정할 수 없는 통신 오류나 오류 번호 없는 서버 실패에서는 표식을 유지한다.

같은 계정으로 다시 로그인하면 표식만 거두고 기존 기록은 살린다. 다른 계정으로 로그인하거나 표식이 30일 지나면 이전 계정 기록을 정리한다. 기기 저장소 오류에서는 표식·정리 자체가 실패할 수 있으며, 모든 기록이 지워졌다는 화면 안내만으로 증명하지 않는다.

수용 기준과 검증 범위

  • AC-01 입구와 차단: 설정에서 진입하고 삭제 진행·제재 상태에서는 즉시 탈퇴를 시작하지 않는다.
  • AC-02 점검 실패: 오류 또는 차단 결과에서 탈퇴 요청을 보내지 않고 사유·해결 경로를 제공한다.
  • AC-03 포기 동의: 대상과 금액·안내 버전을 확인하며 동의 취소는 최종 확인·탈퇴 요청으로 이어지지 않는다.
  • AC-04 최종 확인: 자동 처리 목록·복구 불가 안내 뒤 동의한 경우만 요청한다.
  • AC-05 재판정: 정리 중 제재·예약·새 의무·동의 대상 변경이 생기면 현재 판정에 맞게 막거나 재확인한다.
  • AC-06 부분 처리: 최종 탈퇴 실패 뒤 이미 정리된 활동과 앱의 재조회 결과를 확인한다.
  • AC-07 성공: 계정 이용·재로그인을 막고 현재 세션 및 그 계정의 기기 기록을 정리한다.
  • AC-08 응답과 계정 경계: 성공 응답 전 세션 종료·응답 유실·다른 계정 로그인에서 옛 결과가 새 계정을 지우지 않는다.
  • AC-09 유예 만료: 기본 30일 뒤 파기 대상·현재 의무 재판정·실패 후속을 구분한다.
  • AC-10 돈과 파일: 보관금 포기·유료 잔액 환급 예약·무료 잔액 소멸·탈퇴 후 보류금의 증빙·재지급·실제 송금·파일 소거를 따로 확인한다.
