릴리즈 준비 체크리스트

릴리즈 직전 한 번 더 보는 17개 항목. 모두 “예”라고 답할 수 있어야 릴리즈 승인. 한 줄이라도 “모르겠다”가 나오면 발견된 시점이 가장 싸다.

2026-09-04 — 이 체크리스트가 답하지 않는 것

아래 17개 항목은 릴리즈 직전에 무엇을 확인해야 하는가를 정리한 점검표다. 지금 그중 무엇이 통과했고 무엇이 남았는지는 여기서 알 수 없다. 현재 판정과 남은 항목은 첫 출시 현황에서, 기능별 상태는 기능별 출시 상태에서 본다. 현재 판정은 내부 시연 가능, 외부 고객 공개·전 기능 공개·실제 결제 보류다. 제공자 기능 구현 당시의 전체 회귀 뒤 앱과 사용자용 API에 E2E 보강이 들어갔고, 이어 마일리지 사진 심사 코드가 사용자용 API·앱·관리자 API에 추가됐다. 포인트 결제·환불과 제공자 배정 8개 E2E, 사진 심사 사용자 API 141건·앱 83건·최초 설치 SQL 일치 검사 5건은 통과했지만 현재 소스 전체를 한 번에 검증한 결과는 아니다. 원격보다 앞선 사용자용 API 5개·앱 6개·관리자 API 2개 커밋을 고정하고 전체 회귀를 다시 실행한 뒤 이 체크리스트를 적용한다.

2026-09-04 앱 검증 수준 기준

과거 확장 대상 53개에는 실행 대기가 없다. 별도로 포인트 결제·환불 7개와 제공자 배정 생명주기 1개를 실제 앱과 로컬 API로 실행해 서버 저장 상태까지 확인했다. 이 8개는 시드 계정을 사용한 “로컬 서버 E2E”이고, 신규 계정·실제 외부 서비스·서명 기기 검증은 별도 축이다. 그 뒤 추가된 마일리지 사진 심사는 앱 단위·위젯·경로 83건을 통과했지만 아직 앱↔서버 E2E 등급으로 올리지 않는다.

1. 기능 범위

  • 이번 릴리즈에 포함되는 기능 ID를 175개 인벤토리 기준으로 표시했다
  • 제외되는 기능과 이유를 명시했다
  • P0/P1/P2 우선순위를 정했다

2. 사용자 흐름

  • 신규 사용자 가입·온보딩 흐름이 깨지지 않는다
  • 홈·검색에서 핵심 콘텐츠로 진입할 수 있다
  • 이벤트 신청·클럽 가입·플랜 구매·데이팅 매칭 중 릴리즈 대상 흐름이 QA됐다
  • 게스트 동반 예매 대상 릴리즈라면 신청·체크인·노쇼·환불에서 owner와 guest attendance row가 분리된다

3. 상태와 권한

  • 권한 없는 사용자의 버튼 노출·비활성·에러 정책이 정해졌다
  • 이미 취소·만료·삭제·차단된 대상을 사용자가 클릭했을 때 보일 안내 화면이 정해졌다
  • 멀티 디바이스·중복 클릭 케이스가 QA됐다

4. 돈과 알림

  • 결제 성공·실패·환불 후의 잔액·거래내역이 모두 같은 값으로 맞물려 있다 (한 곳만 다른 값을 보여주면 안 된다)
  • 정산의 작성중·진행중·완료·취소됨 상태가 분리되어 보인다
  • 알림 수신자·딥링크·카테고리 설정·방해금지 정책이 QA됐다

5. 개인정보와 안전

  • 위치 공유의 동의·중지 동선이 명확하다
  • 실제 GPS 주기 업로드 완료, live 지도 키 readiness, staging 실증 완료를 검증 없이 완료로 쓰지 않는다
  • 데이팅 차단·신고가 관련 화면에 즉시 반영된다
  • 데이터 내보내기·계정 삭제·비활성화 문구가 검토됐다

릴리즈 차단 조건

아래 한 줄이라도 해당되면 릴리즈 보류
  • 돈이 빠진 뒤 기능 성공/실패가 사용자에게 불명확함
  • 작성중 정산이 미리보기 수위(총액·상태·내 분담금)를 넘겨 항목 상세·영수증·타인 몫이 보이거나, 작성중 상태에서 결제·이의제기·알림이 발생함
  • 공유 중지 후 위치 마커가 남음
  • 차단된 사용자가 채팅·게시판에서 여전히 보임
  • 마지막 로그인 수단 해제가 가능함 (계정 잠김)
  • 비로그인 사용자가 결제 직전 화면까지 진입함
