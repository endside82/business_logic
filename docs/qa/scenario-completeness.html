기능별 시나리오와 검증 근거

175개 기능 정본, 별도 상세 시나리오, 코드 위치와 문서가 가리키는 검사 파일을 연결합니다. 파일 미연결은 구현·테스트 부재의 증거가 아니며, 과거 실행 분류는 현재 후보 통과와 다릅니다.

정의·연결·실행·공개를 구분합니다

2026-11-22 현재 문서 대조입니다. 시나리오와 검증 근거 정본 (로컬 근거)에서 집계·판정 기준을 설명합니다. 출시 완료 기준과 아래 파일 연결 유무를 같은 완료율로 계산하지 않습니다.

175개 기능 정본과 상세 문서 117개 기능을 구분합니다. 상세 제목 1,276개와 등록 확인 항목 1,654개는 서로 다른 집계이며 실제 통과 수가 아닙니다. 별도 상세 문서가 없는 58개 기능은 해당 PRD의 수용 조건을 읽습니다. 시나리오 커버리지에서 집계 기준을 확인합니다.

검색한 자동 테스트 파일 –개, 통합·E2E 파일 –개 중 상세 문서가 직접 가리키는 기능은 각각 –, –입니다. 기능 번호를 발견한 –·–은 연결 후보입니다. 파일 존재·번호 일치·문서 링크만으로 기대 결과의 단언이나 최신 실행 성공을 증명하지 않습니다.

기존 상태표에는 자동 검사 –, 로컬 서버 –, 신규 계정 – 분류가 있습니다. 과거 분류를 현재 후보의 기능별 통과로 읽지 않습니다. 코드·파일 연결·과거 실행은 독립적인 근거로 표시합니다.

변경에 맞는 검토 순서

  1. 현재 작업과 출시 상태표의 연결 항목을 읽고 실제 결함·미실행·결정 대기를 구분합니다.
  2. 기능 정본과 기존 코드·테스트 단언·실행 기록을 먼저 찾습니다. 파일 미연결을 이유로 시험을 새로 만들거나 제품을 다시 실행하지 않습니다.
  3. 변경이 무효화한 근거와 남은 질문에 맞춰 필요한 검사만 고릅니다. 결과·권한·저장 상태에는 소스와 실행 근거를, 배치·잘림 같은 질문에는 필요한 화면 근거를 씁니다.
  4. 실제 검사를 했다면 버전·조건·기대 결과·관측 결과를 연결합니다. 외부 연동과 공개 판정은 릴리즈 증거 확인을 따릅니다.

코드 위치 교정 결과

문서에 적힌 코드 위치 –개를 모두 대조했다. 파일·처리 함수·요청 방식·전체 호출 주소가 일치하는 코드를 찾아 링크를 교정했다. 단순히 옛 줄 번호 근처에 다른 코드가 있다는 이유로 정상 판정하지 않는다.

교정 결과기록 수이제 어떻게 확인하는가
현재 코드로 연결 완료–아래 기능의 확인한 코드 보기를 열면 처리 함수·호출 주소와 해당 위치로 바로 이동하는 링크를 볼 수 있다. 현재 서버의 처리 함수·주소와 줄 위치를 대조한 링크다. 관련 요구사항 문서의 과거 확인 날짜와 구분한다.
철회된 기능으로 분리–타 사용자 가용시간 조회의 철회 안내를 따른다. 같은 파일을 가리켰던 두 기록이며, 복구할 코드나 출시를 막는 결함이 아니다.
위치를 확정하지 못한 기록–이번 교정 범위에 남은 위치 확인 작업이다. 기능 전체의 미구현·테스트 누락 건수와는 다르다.

기록 수는 기능 수나 파일 수가 아니다. 여러 문서가 같은 코드를 가리킬 수 있다. 같은 기능 안의 중복 링크는 한 번만 보여 준다. 코드 링크는 확인한 버전에 고정해 이후 줄 이동으로 엉뚱한 위치가 열리지 않게 했다. 저장소 접근 권한이 필요할 수 있다.

단순한 줄 이동 외에 바로잡은 내용
  • 회원 추방: 현재 사용하는 요청과 기존 호환용 요청이 서로 다른 함수라는 점을 구분했다.
  • 가상계좌 입금 통지: 공급자별 수신 주소와 기존 호환용 주소를 각각 연결했다. 처리 함수가 없다는 옛 설명도 정정했다. 실제 결제사 연동·출시 승인을 뜻하지는 않는다.
  • 반복 모임: 한 섹션에 섞여 있던 이후 회차 수정과 취소의 위치를 각각 연결했다.
이후 코드가 이동하거나 계약이 바뀌면

문서 생성기는 줄 번호를 그대로 믿지 않고 저장된 처리 함수·요청 방식·주소로 다시 찾는다. 같은 기능의 위치만 이동했다면 새 위치를 계산한다. 함수나 주소가 바뀌어 일치하지 않으면 생성을 중단해 개발자가 변경 내용을 확인하도록 한다.

이번 완료 범위는 코드 위치 교정이다. 모든 동작·권한·오류 처리에 대한 테스트나 상세 계약 전체의 재검증으로 세지 않는다.

도메인별 현황

자동 테스트와 통합·E2E 수치는 시나리오 문서가 해당 파일을 직접 지목한 기능 수다. 기능 번호만 발견된 파일은 포함하지 않는다.
