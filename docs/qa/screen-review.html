화면 검수는 출시 승인이 아닙니다

모든 사진은 시험 계정의 로컬 웹 실행 결과입니다. 예시 사진은 AI로 만들고 실제 파일 업로드 경로로 등록했습니다. 세션을 준비해 시작했으므로 실제 로그인 검증도 아닙니다. 구현·자동 테스트·실제 환경의 출시 판단은 기능별 출시 상태를 따릅니다.

촬영한 이용 흐름과 다음 행동

이 표는 촬영을 시작한 묶음의 요약이며 전체 업무 목록이 아닙니다. 빠진 영역과 세부 업무는 21개 업무 영역의 전체 촬영 현황에서 확인합니다.

카풀은 어디까지 확인됐나요?

좌석 비지정 방식은 운전자 제안 → 주최자 승인 → 탑승자 자리 확정 → 주최자 명단 반영까지 확인했습니다. 탑승자의 내 자리와 주최자의 탑승자 명단에서 결과를 비교할 수 있습니다.

지정 좌석 표시를 수정하고 선택까지 확인했습니다

서버의 응답 변환을 수정한 뒤 회원의 2번 내 좌석과 탑승 2/7명, 주최자의 1번 수아·2번 민준 명단을 확인했습니다. 앱을 다시 열어도 유지됩니다. 서버 이동 검사 116개와 앱 검사 76개도 통과했습니다.

다음 코드 보완은 픽업 경로·차량 제목의 운전자 이름 표시, 승인 대기 안내, 취소 버튼 문구입니다. 별도로 승객이 탄 운행 취소·승차 장소·자리 반납·신고·관리자 배치도 편집을 추가 촬영해야 합니다. 서명한 휴대전화 앱의 검사는 아직 남아 있습니다.
