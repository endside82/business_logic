도착·권한·복구의 기준

  • 독립 이벤트는 해당 모임, 외부 클럽 모임은 클럽 소개로 도착한다. 링크를 열었다는 이유로 가입·참가 신청을 자동 실행하지 않는다.
  • 미로그인·신규 가입·인증번호 확인·온보딩·프로세스 종료를 각각 구분한다. 수동 입력이나 원래 링크 재탭을 자동 복원 성공으로 세지 않는다.
  • 호스트·활성 공동주최자와 수신 가능한 회원의 경계를 지킨다. 삭제·취소·회전된 링크·만료 전달표·강퇴·제재·차단·계정 전환 뒤 옛 목적지와 권한을 재사용하지 않는다.
  • 응답 유실·재시작 뒤 같은 공유 요청과 성공 영수증을 확인한다. 새 식별자로 중복 발송하거나 확정되지 않은 결과를 성공으로 표시하지 않는다.
  • QR 이미지 저장·읽기나 화면 배치처럼 시각 증거가 필요한 질문과, API 권한·소켓·저장소·서버 상태를 확인할 질문을 구분한다.

자료 내보내기·보존·탈퇴는 현재 데이터 내보내기 계약과 계정 삭제 계약을 따른다. 과거 공유 구현 기록의 자료 포함 설명이 최신 개인정보 결정과 다르면 최신 정본을 우선한다.
