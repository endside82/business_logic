모임 공유·설치 후 복원

링크나 QR을 받은 사람이 설치·가입을 마친 뒤 원래 모임 또는 클럽 소개로 도착하게 하는 계획입니다. 2026년 10월 23일 문서 대조 기준, 주요 구현은 10월 21일 각 제품 main에 병합했습니다. iOS 자동 설치 복원 개발과 운영·기기·스토어 검증·공개 판단이 남았습니다.

현재 완료된 범위와 한계

주소·로그 보호, 공통 링크 수신·가입 복원, 공유 메뉴·QR, 설치 안내 웹·Android 전달표, 회원 지정 전달과 클럽 단체 채팅의 주요 코드를 구현했습니다. 수동 링크 입력·클럽 공유 UUID 저장, iOS 의존성 충돌과 캘린더 가드도 보완했습니다.

10월 21일 최신 main 통합 기준으로 앱 관련 회귀 612건·가드 4종·Android debug·iOS 시뮬레이터 빌드를 통과했습니다. 공개 API 전체 단위·구조 13,221건과 전용 MySQL 73건, 관리자 단위 16건·DB 21건, 실시간 394건 통과·12건 건너뜀, 소개 웹 단위 91건·브라우저 18건의 기록이 있습니다. 서로 다른 범위의 검사 수를 합산하거나 최신 전체 앱 통과로 확대하지 않습니다.

기존 실패 시험도 남아 있습니다. 10월 23일 앱 S1e2a의 전체 시험에는 기준선과 같은 12파일 37건 실패, 관리자에는 분쟁 그래프 골든 1건 실패가 기록돼 있습니다. 현재 검사 기록과 남은 실패에서 표적 검사와 전체 검사 결과를 구분합니다.

실기기 검사만 남은 상태는 아닙니다. iOS 자동 설치 복원 공급자 선정·SDK 본 연동도 미완료입니다. 실제 API·소켓 통신 검사는 두 휴대전화의 화면 검사를 대신하지 않습니다. 전체 신규 공유 기능의 첫 출시 편입은 미정입니다.
