프로필의 클럽 글과 정기모임 후기 이름 링크는 첫 출시 구현에 반영했습니다. Android 서명 시험 앱의 Google·메일·지도·실제 FCM은 기록된 일부 범위까지 확인했습니다. 운영 환경·파일 저장소·실기기·iOS·동일 출시후보의 전체 이용·복구·스토어 공개 조건은 남아 있습니다.

전체 현황·다음 할 일이 현재 우선순위와 실행 흐름의 안내입니다. 외부 서비스 가입·계약과 출시 준비의 부분 성공을 전체 기능 통과로 확대하지 않습니다. 이 문서의 완료 조건 추가는 제품 테스트 재실행이나 출시 승인이 아닙니다.

완료를 판정하는 단계

단계완료라고 적을 수 있는 근거별도로 남는 것
구현 반영필요한 서버·앱·관리자 경로가 기본 브랜치에 있고 공개 범위·권한·데이터 정의가 일치한다.작업 브랜치·계획서·화면 사진만으로 완료하지 않는다. 알려진 미연결·결함은 별도 표시한다.
자동 검사 통과검사한 소스·명령·환경·대상·결과가 남고 수정 이후 필요한 검사가 통과한다.모사 공급자와 실제 공급자, 특정 기능 검사와 전체 회귀를 구분한다.
사용 흐름 확인회원·주최자·운영자가 화면에서 행동하고 서버 저장 결과까지 대조한다.로컬 웹·시험 계정·에뮬레이터 결과를 실기기나 운영 배포 결과로 바꾸지 않는다.
출시 환경 확인동일 출시후보의 서명 앱·실제 서버·대상 기기·실제 외부 서비스로 정상/실패/회수를 확인한다.키 발급·가입·기동만 끝난 상태, 미실행·실행 차단은 통과가 아니다.
공개 승인첫 출시 범위의 필수 결과, 운영 복구·고객 안내·스토어 자료와 운영자의 공개 결정을 같은 버전에 연결한다.후속 범위는 계속 제한한다. 스토어 제출·승인·실제 공개는 각각 기록한다.

과거 관문 문서의 “완료 13개”는 정책 결정 12개와 코드 완료 1개를 뜻하는 당시 분류입니다. 서명 출시후보·실환경 증거·승인까지 모두 닫힌 관문 수나 현재 공개 완료 수로 읽지 않습니다. 과거 검사 이후 소스가 바뀌면 변경 영향을 다시 연결합니다.

첫 출시와 후속 공개의 경계

범위이번에 완료해야 할 결과
첫 출시 150개 기능의 전부/일부 범위134개 포함·16개 일부 포함입니다. 이메일·Google, 클럽·모임·정산·주최자 직접 송금, 이동 조율, 후기·프로필 탐색, 투표·마일리지·스탬프·운영 권한을 각 공개 범위대로 확인합니다. 숫자는 제공 범위이며 완료 수가 아닙니다.
후속 24개 번호 기능과 별도 후속 기능플랫폼 결제·출금·개인 구독·마켓·데이트·제공자 거래의 새 이용은 막고 필요한 환불·해지·신고 등 기존 의무 처리 경로를 유지합니다. 실제 거래와 해당 운영 조건을 확인한 뒤 각각 공개합니다.
Google Calendar10월 13일 선택 전송·프리미엄 자동 전송 코드는 반영됐습니다. Android 에뮬레이터 실계정 확인 기록이 있습니다. 운영 OAuth·물리 기기·iOS·Google 권한 철회 확인 뒤 후속 공개합니다. 첫 출시 내부 일정·일회성 파일 내보내기의 완료와 구분합니다.
제품에서 제외한 1개옛 타인 가용시간 공개 조회입니다. 비공개 본인 가용시간은 유지합니다. 재도입은 새 제품 결정 대상입니다.

일부 포함 기능은 포함한 부분만 첫 출시 통과 대상으로 삼습니다. 계좌 소액 인증·후속 PG 계약을 주최자 직접 송금의 선행 조건으로 추가하지 않습니다. 최초 빈 설치에는 과거 데이터 이관을 요구하지 않으며, 실제로 유지할 기존 자료가 있을 때만 필요한 보강·복구를 확인합니다.

함께 적용하는 권한·실패·복구 확인

  • 화면과 저장 결과: 성공 문구만 보지 않고 다시 조회한 상태·명단·건수·금액·기간이 기대한 결과와 같은지 확인합니다.
  • 권한과 회수: 본인/타인·회원/비회원·주최자/참가자·운영 권한을 구분합니다. 차단·탈퇴·제재·비공개 전환 후 기존 화면과 직접 링크에서도 제한이 적용돼야 합니다.
  • 중복과 경합: 상태를 바꾸는 기능은 연속 누름·응답 유실 후 재시도·동시 처리에서 중복 등록/차감/환불/적립을 만들지 않아야 합니다. 단순 읽기에는 해당 쓰기 조건을 억지로 붙이지 않습니다.
  • 실패와 복귀: 빈 상태·권한 거절·외부 오류·시간 초과를 구분하고 사용자가 다시 시도하거나 이전 화면으로 돌아갈 수 있어야 합니다. 계정 전환 후 이전 응답·비공개 정보를 남기지 않습니다.
  • 날짜와 금액: 해당 기능의 시간대·만료·마감 경계, 반올림·부분 환불·포인트/현금 구분을 확인합니다. 실제 돈 이동은 공급자/은행 기록과 대조합니다.
  • 외부 서비스: 실제 메일·푸시·지도·파일·결제를 사용한 범위와 모사 응답·에뮬레이터 범위를 기록합니다. 제공하지 않는 연동을 이 기능의 필수 조건으로 만들지 않습니다.
  • 운영: 사람이 판단하는 조치는 대상·사유·권한·감사 기록과 실패 재처리 결과를 남깁니다. 운영자 한 사람이 역할별 계정과 메뉴를 바꿔 확인할 수 있습니다.

조건을 충족하지 못하면 실패, 아직 실행하지 않으면 미실행, 준비물이 없어 실행할 수 없으면 실행 차단으로 적습니다. 해당하지 않는 검사는 이유와 공개 범위를 기록해 해당 없음으로 둡니다. 보류나 해당 없음을 통과 건수에 더하지 않습니다.

본문에 남은 제한의 완료 처리

기본 브랜치에 기능이 있다는 표시는 모든 화면과 예외가 완성됐다는 뜻이 아닙니다. 다음과 같은 본문 한계는 개별 조건과 함께 확인합니다. 해결 증거가 없으면 완료로 바꾸지 않고, 첫 출시 영향·기존 대체 경로·후속 공개 범위를 명시적으로 판정합니다.

  • 알림 미읽음 집계와 하단 배지: 집계 결과와 하단 표시 연결을 구분합니다.
  • 경고 이의제기의 동시 중복 제출: 진행 중 1건 제한의 경합 확인을 별도로 남깁니다.
  • 경고 통계의 운영 화면: 서버 집계가 있다고 화면까지 제공한다고 표시하지 않습니다.
  • 분쟁 증빙의 공개 범위: 본인 제출 증빙의 열람·다운로드와 나머지 세부 등급 구현을 구분합니다.
  • 기간권 판매 운영: 기존 구매·보유·환불 구현과 아직 남은 편성·판매 경로를 구분합니다.
  • Google Calendar의 후속 보완: Google 권한 철회·운영·기기 확인이 남았습니다. 업무 실패 격리는 출시 뒤 구조 개선으로 다룹니다.

공개 승인까지의 실행 순서

전체 현황판의 출시 네 단계를 따릅니다. 환경 입력 준비 → 배포본 제작·설치 → 실제 이용 → 복구·공개 판단 순서입니다. 로고·안내 문안은 환경 준비와 병행해 적용 전에 확정합니다.

같은 버전의 앱·공개 API·관리자 API·관리자 웹·실시간과 홈페이지의 안내·링크 설정을 기록합니다. 기존 검사 후 바뀐 코드·설정의 영향을 확인하고, 문서만 바뀌었다면 제품 전체 검사를 반복하지 않습니다.

첫 출시 필수: 프로필 글과 후기 이름 링크

프로필 글: 서로 가입 범위가 다른 두 계정·두 클럽·21개 이상 글로 20개 단위 페이지를 확인합니다. 최신순·전체 건수·원문 이동/복귀·마지막 페이지 소멸·접근 거부·차단·클럽 탈퇴·작성 글 숨김/삭제·계정 전환을 확인합니다. 글 제목뿐 아니라 총건수도 같은 열람 권한을 적용해야 합니다. 작성자가 클럽을 나간 경우와 보는 사람이 클럽을 나간 경우를 혼동하지 않습니다.

후기 이름: 작성자와 평가 대상이 다른 후기를 준비해 두 이름의 실제 목적지를 각각 확인합니다. 기록된 평가 대상을 현재 호스트로 대체하지 않습니다. 이름이나 유효한 식별자가 없으면 링크로 만들지 않고, 프로필 복귀·차단 뒤 후기 목록·건수·평균을 다시 확인하면서 펼침·페이지·스크롤 상태를 점검합니다.
