상태를 읽는 기준

  • 일부만 포함: 기능 안에서 제공할 부분과 막아 둘 부분이 다르다. 범위 설명에서 구분한다.
  • 이용 확인: 개발용 환경에서 앱을 사용하고 서버 결과를 확인한 기록이다. 새 계정으로 시작했는지, 준비된 계정을 썼는지 구분한다.
  • 자동 검사만 확인: 프로그램의 자동 검사 기록만 있다. 실제 고객의 전체 이용이 통과했다는 뜻은 아니다.
  • 공통 출시 준비: 배포할 버전·외부 서비스·휴대전화 검사·장애 복구·스토어 자료와 공개 승인을 준비한다.
  • 문서 검토 후보: 아직 사실 확인이 끝나지 않은 문장 수다. 확인된 결함 수와 다르며 기능의 검사 범위를 펼치면 볼 수 있다.

상세 근거는 기능별 시나리오 완성도, 문서 작성 상태는 기능 문서 점검 상태에서 확인한다.
