이 표는 구현률 표가 아니라 첫 출시에서 열어 둘 범위를 보여 준다. 임의의 “전체 코드 몇 퍼센트”는 제거했다. 현재 로컬 기본 브랜치에서는 사용자용 API 8b64e1f7 7,374+869건, 앱 2986a7f1 3,153건, 관리자 API ece0d58e 1,276건을 2026-09-05 오후 확정 커밋 트리에서 실행해 실패 0을 확인했고, 관리자 웹 Playwright 248개 시나리오는 0f9e6355 기록이다(현재 끝 커밋 2083aeb8). 첫 출시 범위의 알려진 코드·화면 차단 항목은 0건이지만, 원격 고정·빈 데이터베이스 설치·Node 24.14 이상 관리자 웹·서명 앱·외부 서비스 증명이 남아 공개 출시 판정은 보류다.

2026-09-04 봉인 기능 감사의 W1은 관리자 웹 22개 돈 조치 키 보존과 서버 등록부, 등록부 원문 보존 수명주기, 정기모임 서버 간 명령 결박까지 반영돼 코드로 종결됐다. W2 안전한 데이트 수동 승인은 작업 브랜치에만 있어 현재 기능 행을 완료로 올리지 않는다. W3 직접 송금·이동 책임 안내와 W4 사진 승인 적립은 코드 공백이 해소되고 현재 회귀를 통과했지만 역할별 흐름·승인·출시 설정이 남았다. 자세한 브랜치와 검토 상태는 W1~W4 실행 현황, 기능별 출시 판단은 첫 출시 현황의 단계별 구현 상태에서 확인한다.

열 읽는 법

  • 첫 출시 — 운영 배포의 출시 범위 설정과 결제 출시 스위치에서 그대로 읽은 값이다. “일부 출시”는 기능 안에서 일부 경로만 열린다는 뜻이며, 어떤 경로가 닫히는지는 행을 펼치면 나온다.
  • 확인 수준 — “자동 회귀”는 단위·위젯·서버 테스트 근거, “로컬 서버 E2E”는 미리 준비한 계정으로 실제 앱 화면과 API를 왕복하고 저장 상태를 다시 읽은 근거, “로컬 신규 계정”은 격리된 환경에서 계정 생성부터 시작한 근거다. 어느 등급도 실제 외부 서비스나 서명 앱까지 통과했다는 뜻은 아니다.
  • 알려진 문제 — 출시 차단, 화면 연결만 남은 작업, 출시 전 결정, 출시 후 개선으로 분류된 고객 기능의 미해결 항목 수다. 후속 출시 계획·폐기 설계·문서 작업은 이 수에 넣지 않는다. 내용과 다음 행동은 행을 펼치거나 첫 출시 현황에서 본다.
  • 미판정 — PRD 쪽에 “소스와 대조한 뒤 확정”으로만 남아 있는 갭 후보 수다. 결함 수가 아니라 아직 판정하지 않은 검토 항목의 수이며, 클수록 그 기능의 문서를 신뢰하기 전에 소스를 다시 열어 봐야 한다는 뜻이다.
