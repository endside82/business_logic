과거 고정 소스에서 상태 변경까지 확인한 범위

2026년 9월 4일 포인트 결제·환불은 당시 이벤트 화면에서 신청→결제→취소를 수행하고 신청·결제·지갑·원장을 다시 조회하는 7개 시나리오를 통과했다. 제공자 배정은 호스트 생성→제공자 수락→호스트 확정→정리의 네 상태를 역할별 화면과 서버 재조회로 확인했다. 화면 진입이나 빈 상태 확인으로 끝내지 않는다. 미리 준비한 계정을 썼으므로 두 기능의 확인 수준은 “로컬 서버 E2E”이며, 외부 서비스나 새 계정 생성 검증은 아니다.

사진 심사 적립은 서버의 승인·재심·취소·회수·동시 승인 상한과 앱 자동 검사를 통과해 첫 출시 기본 목록에 포함했다. 회원·운영진의 반려·재심·승인·취소와 점수 회수는 이후 로컬 앱에서 확인했다. 실제 사진 파일 업로드·열람·서명 실기기·외부 알림은 별도 미확인이다.
