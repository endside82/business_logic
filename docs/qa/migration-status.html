열의 의미와 한계

‘작성 계보’는 기능 목록에 남긴 기존 문서 분류입니다. ‘코드 완료’, ‘첫 출시’와 같은 문구가 포함돼 있어도 현재 운영 공개나 이번 실행 통과를 새로 선언하는 값이 아닙니다. 소스 참조 등록값은 코드 연결의 개수이며 검토 항목 등록값은 기능 목록에 기록한 조건의 수입니다. 이를 자동으로 미판정 후보·고유 결함·사용자 피해 순위로 환산하지 않습니다.

조회·권한·금전·미검증 조건의 실제 구분은 각 정본을 따릅니다. 등록값이 크다는 이유만으로 새 개발 작업이나 반복 회귀를 만들지 않습니다. 기능별 출시 상태와 첫 출시 현황도 해당 근거 범위를 따로 확인합니다.
