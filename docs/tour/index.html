촬영 날짜와 환경을 함께 확인합니다

2026-11-23 촬영본은 운영 API에 연결한 Android 에뮬레이터의 앱 화면입니다. 기본 390×844 화면을 780×1688 PNG로 직접 촬영했습니다. 물리 기기·Play 배포본 검증이나 기능 전체 통과·출시 완료를 뜻하지 않습니다. 2026년 9~10월 촬영본은 과거 기록으로 구분하며, 현재 앱 입구와 각 이용 흐름의 기능 정본을 함께 읽습니다.

가입·복구의 이전 이메일 링크·미인증 제한 화면은 과거 기록입니다. 현재는 번호 확인·가입·세션·선택형 온보딩 계약을 따릅니다. 사진이나 코드 설정만으로 번호 메일·푸시의 실제 수신을 확인했다고 판단하지 않습니다.

사진과 확인 기록을 읽는 방법

과거 예시로 촬영한 비용·참가자·금액은 설명을 위한 가상 자료입니다. 실제 은행 거래를 보낸 기록이 아닙니다. 현재 모임 정산 계약에서는 실제 수취인·납부·확인·반환을 구분합니다.

새 촬영본은 운영 API에서 조회한 사진을 앱이 표시한 화면입니다. 과거 촬영본도 원래 설명·확인 범위와 함께 보존합니다. 과거 표지·활동 소재의 출처는 가상 예시 사진 안내에 있습니다.

자료가 없다는 이유로 모든 화면을 새로 촬영하지 않습니다. 화면 배치·잘림·표시 상태 등 실제 시각 질문이 있으면 해당 장면을 고르고, 요청·권한·저장 상태는 적합한 소스와 실행 근거로 확인합니다.
