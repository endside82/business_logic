다음에는 어떤 업무를 촬영하나요?

비어 있는 업무와 운영자의 처리 장면부터 채웁니다. 각 항목은 아래의 필요한 장면까지 이어서 촬영하며, 대표 화면 한 장으로 완료하지 않습니다.

  1. 카풀 승차 안내: 픽업 경로·차량 제목의 운전자 이름, 승인 대기 안내와 취소 버튼 문구를 보완하고 재촬영. 지정 좌석 표시·선택은 수정하고 재검사 완료. 승차 장소·자리 반납·승객이 탄 운행 취소·신고와 관리자 배치도 편집은 추가 확인.
  2. 모임 비용 나누기: 비용 입력·분담액·입금 신고·주최자 확인·마감.
  3. 클럽 기금, 클럽 가입 승인, 현장 출석, 활동 후기: 회원의 행동과 운영자의 처리 결과를 한 쌍으로 촬영.
  4. 지갑·결제, 콘텐츠 판매, 데이트, 제공자 거래: 열 수 있는 화면과 제한된 단계를 구분하고, 필요한 가상 거래·상대 계정을 준비.
  5. 장소·길찾기, 사진 심사, 대화: 사진 저장소·지도·상대 수신 환경을 확인한 뒤 실제 결과까지 촬영.

승차 안내·관심인 갱신·제보 검토함·장소 확인 문제는 막힌 이유와 다음 행동을 남깁니다. 해결된 지정 좌석 표시 문제는 완료된 재검사로 분리합니다.
