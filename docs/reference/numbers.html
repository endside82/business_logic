참가비 환불과 별도 정산 선입금

참가비 취소·환불 · 참가비 선입금 · 모임 정산 선입금

항목현재 값과 적용 조건
환불 정책 6종STANDARD·STRICT·FLEXIBLE·FULL·NON_REFUNDABLE·CUSTOM. 실제 비율·시간 구간·수수료는 현재 카탈로그와 모임에 저장된 정책을 따른다. 옛 템플릿 숫자를 모든 모임의 고정값으로 인용하지 않는다.
참가자 귀책남은 시간을 시간 단위로 내림해 해당 구간을 찾는다. 원금에 비율을 적용한 금액과 유료 몫을 각각 내림하며, 고정 수수료는 유료 반환분 안에서만 공제한다.
예외 귀책호스트 귀책·불가항력·합의·일정 변경 거절은 해당 계산에서 100%·수수료 0원. 취소 모임은 호스트 귀책으로 처리한다. 노쇼 일반 환불과 사후 조정은 별도다.
반환 한도와 시점유료·무료별 남은 원금 한도를 지킨다. 전체 신청 취소는 원 결제와 일행 추가 건을 함께 계산한다. 지갑 반환·외부 결제 취소·호스트 은행 반환은 서로 다른 결과이며 취소 접수만으로 즉시 입금을 보장하지 않는다.
모임 정산 선입금의 공개 제한현재 MEETING_PREPAYMENT는 닫혀 있다. 참가비 은행 수납과 다른 기능이다. 구현된 요청은 금액 1 이상, POINT 또는 BANK_TRANSFER이며 MIXED 선택 계약이 아니다.
정산 선입금의 환불 입력비어 있지 않은 시간별 규칙, 시간 0 이상·비율 0~100. 5% 단위 강제나 7·3·1일 고정 정책이 아니다. 현재 공개 기능으로 소개하지 않는다.

결제수단과 완료등록 최대 5개. 자동충전 성공과 원 구매 성공은 별도다. 중복 요청의 성공 재반환·처리 중 오류는 각 명령 계약에 따르며 모든 두 번째 요청을 무조건 거절한다고 안내하지 않는다.
