# Unit-backed 기능별 커버리지 인덱스

> **2026-11-22 부분 동기화:** 알림 여섯 기능·데이터 내보내기·이벤트 상세의 시나리오·도식 수를 현재 참고 자료와 맞췄다. 나머지 행과 전체 합계는 후속 대조 중이다. 이 수는 등록된 문서 항목 수이며 실행 시험 통과 수가 아니다.

<!-- release-document: reference -->
> **문서 구분: 기능·설계·절차 참고 문서.** 본문의 요구사항·과거 확인은 현재 미구현 목록이 아닙니다. 현재 작업 순서는 [앞으로 할 일](../../docs/plan/NEXT_WORK.md)을 따릅니다.


이 문서는 전체 175개 기능 중 unit 근거를 보유한 117개 하위 집합 각각에 대해 원문 시나리오와 도식이 몇 개 있는지 확인하는 검산표다. 표의 합계는 시나리오 1011개·도식 508개이며, 나머지 58개 no-unit 기능은 source-first PRD와 실제 소스로 검산한다. 기능 카드 상세화를 진행할 때 이 표를 체크박스로 복사해서 쓰면, 특정 unit-backed 기능만 설명하고 예외 시나리오를 빼먹는 일을 줄일 수 있다.

## 카드화 우선순위 제안

기능 카드 상세화는 모든 기능을 한 번에 하지 말고, 아래 기준으로 우선순위를 둔다.

| 우선순위 | 기준 | 해당 예시 |
|---|---|---|
| P0 | 돈, 안전, 계정 삭제, 위치 공유처럼 사용자 피해가 큰 기능 | 결제/환불, 모임 정산, 데이팅 차단, 위치 opt-in/out, 계정 삭제 |
| P1 | 주요 전환율과 직접 연결되는 기능 | 이벤트 신청, 클럽 가입, 플랜 구매, 온보딩 |
| P2 | 운영/CS 문의가 많이 생길 기능 | 알림 설정, 데이터 내보내기, 리뷰/신고, 대기열 |
| P3 | 조회 중심이거나 실패 영향이 작은 기능 | 목록 조회, 통계, 단순 상세 |
