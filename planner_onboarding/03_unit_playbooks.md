# 21개 업무 영역 검토 안내

<!-- release-document: reference -->
> 2026-11-22 현재 기능·정책 정본을 대조한 기획용 안내다. 문서 대조와 제품 실행·외부 연동·공개 확인은 구분한다. 실행 순서는 [앞으로 할 일](../../docs/plan/NEXT_WORK.md)을 따른다.

기존 파일 경로는 유지하며 전체 21개 영역으로 확장했다. 각 항목은 기능 정본으로 들어가기 전에 구분할 사용자·업무·결과다. 상세 수치·기한·권한 표를 이 안내에 복제하지 않는다. 원천 메모 유무는 기능 범위를 제한하지 않는다.

## 01. 인증 & 온보딩

정본: [인증 & 온보딩](../prd/01_domain_prds/01_인증_and_온보딩_prd.md).

| 검토 항목 | 내용 |
|---|---|
| 사용자와 경로 | 신규·기존 회원. 이메일·활성 소셜 경로 → 세션 확인 → 필요한 첫 이용 설정 → 원래 목적지 |
| 구분할 결과 | 온보딩을 건너뛸 수 있다. 로그인 성공이 모든 프로필·관심사·주소 입력 완료는 아니다. |

| 사용자와 경로 | 비로그인·로그인 이용자. 홈 → 구역별 콘텐츠/더보기 → 상세 → 홈 복귀 |
| 구분할 결과 | 일부 구역 실패와 전체 실패를 나누고 로그인·관계 변경 뒤 갱신 범위를 확인한다. |

| 구분할 결과 | 승인·결제·실제 참석·체크인은 다르다. 정원·대기열·게스트·교통편·일정 변경은 해당 조건을 따른다. |

| 구분할 결과 | 클럽장과 위임자의 명령 권한은 다르다. 가입비·기부·기금·회원 개인 지갑·스탬프를 합치지 않는다. |

## 기획 검토를 마칠 때

대상 기능 ID와 기준 버전, 실제 입구, 허용·차단 조건, 성공·부분 처리·결과 불명, 재조회와 복귀를 [기능 카드](06_feature_card_template.md)에 남긴다. 이미 확인한 근거를 재사용하며 이번에 확인하지 않은 실행·외부 전달을 완료로 쓰지 않는다. 같은 설명이 있는 기능 정본·정책·QA·공개 문서도 함께 대조한다.
