# 새 기획자 온보딩 문서 꾸러미

<!-- release-document: reference -->
> 2026-11-22 현재 기능·정책 정본을 대조한 기획용 안내다. 문서 대조와 제품 실행·외부 연동·공개 확인은 구분한다. 실행 순서는 [앞으로 할 일](../../docs/plan/NEXT_WORK.md)을 따른다.

이 폴더는 **21개 업무 영역·175개 기능**을 사용자 행동과 정책의 관점에서 읽는 안내다. 기능 인벤토리와 시나리오 인덱스도 175개 전체를 다룬다. 별도 `units/` 자료가 있는 117개와 없는 58개는 문서의 원천 차이이며, 제품 범위·완성도·공개 여부의 구분이 아니다.

## 문서 작성 기준

기능 내용은 [기능 PRD](../prd/02_feature_prds/), 공통 규칙은 [공통 정책](../prd/03_policy_prds/)을 우선한다. [작성·검수 기준](../prd/FEATURE_PRD_STANDARD.md)에 따라 사용자 행동·권한·상태·결과·복구를 본문에 쓰고 기술 계약을 중복 복사하지 않는다. 영문 상태는 해당 업무를 식별할 필요가 있을 때만 병기한다.

등록 확인 항목 수·상세 시나리오 제목 수·시험 통과 수·실제 기기 확인 수는 다르다. 최신 집계는 위 커버리지 안내에서 확인한다. 문서 링크·탐색 맵·화면 모형은 실제 앱 업무 성공을 증명하지 않는다. 변경 없는 근거는 재사용하고, 문서 변경은 내용·연결·파생 문서 일치로 검사한다.
